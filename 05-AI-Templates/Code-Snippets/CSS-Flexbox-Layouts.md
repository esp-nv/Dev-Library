### 📄 Шаблон 3: `Code-Snippets/CSS-Flexbox-Layouts.md`
*Твоят бърз "пищов" за уебlayout. Центриране на елементи и адаптивни кутии, без да препрочиташ цялата документация.*

```markdown
### [КОНТЕКСТ ЗА МОДИФИКАЦИЯ]
- Използвай го за бързо подреждане на карти, менюта или центриране на съдържание в HTML.
- Модифицирай: `flex-direction` (row за хоризонтално, column за вертикално) и размерите.

### 🛠️ ГОТОВ КОД (CSS)
```css
/* Родителски контейнер */
.main-container {
    display: flex;
    flex-direction: row;      /* Подрежда елементите в линия */
    flex-wrap: wrap;          /* Ако не стига мястото, пренася на нов ред */
    justify-content: center;  /* Центрира елементите хоризонтално */
    align-items: center;      /* Центрира елементите вертикално */
    gap: 20px;                /* Разстояние между кутиите */
    padding: 15px;
}

/* Деца елементи (напр. карти с продукти или бутони) */
.child-card {
    flex: 1 1 300px;          /* Расте и се свива, но се стреми да е около 300px */
    max-width: 400px;         /* Ограничава максималния размер на голям екран */
    box-sizing: border-box;   /* Включва padding-а в общия размер */
}
```
