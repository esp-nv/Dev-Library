## 2. ЛОГИЧЕСКИ СТЪПКИ ПРИ РАЗРАБОТКА

• Стъпка 1: Бекенд Ядро (Data & Domain) -> Създаване на Entity модел, регистриране в DbContext и прилагане на миграция.
• Стъпка 2: Слой за трансфер (Application & DTOs) -> Изграждане на Request/Response DTOs с валидации и контролер/услуга за обработка на логиката.
• Стъпка 3: Фронтенд интерфейс (UI Layout) -> Семантичен HTML. При Bootstrap се ползват само вградени класове (d-flex, container, row). При чист CSS се предоставя модулен Flexbox блок.
• Стъпка 4: Асинхронно свързване (The Bridge) -> Интеграция чрез Fetch API и async/await (за Web API) или стандартна форма (за MVC). Задължително се прихващат HTTP кодове за грешки (400, 401, 404, 500) за визуализация пред потребителя.

## 3. ДИНАМИЧНИ ИЗИСКВАНИЯ ЗА СИГУРНОСТ

• Приложи САМО АКО [Ниво на сигурност] е "Екипно": Задължителни Guard Clauses на бекенда, забрана на CORS за неоторизирани домейни, сигурност срещу XSS/CSRF и пълна изолация на Entity моделите чрез DTO-та.
• Приложи САМО АКО [Ниво на сигурност] е "Базово за учене": Фокус върху образователни бележки за HTTP методите и статус кодовете. Спестяване на сложна JWT архитектура в полза на по-прости сесии или LocalStorage.
