
### 🌐 2. Уеб приложение (Web-Steps.md)

В уеб светът се разделя на Front-end (клиент) и Back-end (сървър), а комуникацията става чрез заявки.
1. • **Етап 1**: API / Backend Договори (Contracts) (Дефиниране на контролери в .NET и какви данни ще си прехвърляме).
2. • **Етап 2**: База данни и Модели (Свързване със SQL Server/Entity Framework и миграции).
3. • **Етап 3**: Front-end Етап (HTML layout, CSS Flexbox/Grid стилизиране и JavaScript за динамика).
4. • **Етап 4**: Интеграция (Fetch/Axios) (Свързване на JS фронт-енда с .NET бек-енда).
