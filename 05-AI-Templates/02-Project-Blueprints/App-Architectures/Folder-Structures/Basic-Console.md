# 💻 Шаблон: Базово Конзолно / Алгоритмично Приложение

```text
MyProject/
│── Contracts/                       # Базови интерфейси (IEngine.cs)
│── Models/                          # Обикновени данни и обекти (DataModel.cs)
│── Core/                            # Чиста бизнес логика (CalculationEngine.cs)

```

```text
[Потребителски вход] ──> [Валидация] ──> [Интерфейс: IEngine] ──> [Изчисления] ──> [xUnit Тест]
```
