# 🏢 Шаблон: Професионална Организация на Хранилище (Workspace & Assets)

Този шаблон дефинира как се организират извън-програмните документи, архитектурните схеми, историческите дневници и статичните клиентски файлове (Front-End) в репозитория.

```text
ProjectRoot/
│
├── 📂 docs/                           # ЦЕНТРАЛНА ПАПКА ЗА ДОКУМЕНТАЦИЯ
│     ├── 📂 Architecture/             # ASCII диаграми, ERD схеми, Miro бордове
│     │     └── 📂 Images/             # Снимки, скрийншотове на схеми, графики
│     ├── 📂 ProjectChecklist/         # Специфични за проекта чеклисти
│     │     └── [year-month-day-summary].md
│     ├── 📂 DevelopmentLog/           # Дневник на разработката (Dev Log по часове)
│     │     └── [year-month-day-summary].md
│     └── 📂 HistoricalNotes/          # Важни решения, изследвания, архитектурни промени
│           └── [year-month-day-summary].md
│
├── 📂 src/ (или Core/)                # ОСНОВЕН СОРС КОД НА ПРИЛОЖЕНИЕТО
│     │
│     └── 📂 wwwroot/ (или public/)     # СТАТИЧНИ КЛИЕНТСКИ ФАЙЛОВЕ (FRONT-END)
│           ├── 📂 assets/             # Изображения, лога, икони за сайта
│           ├── 📂 css/                # Лични CSS стилове (main.css, layout.css)
│           ├── 📂 js/                 # Клиентски JavaScript / TypeScript скриптове
│           └── 📂 lib/                # Външни библиотеки (напр. Bootstrap, FontAwesome, jQuery)
│                 └── 📂 bootstrap/    # Специфични за Bootstrap CSS/JS компилирани файлове
│
├── 📂 Common/                         # Споделени системни кодове в корена
│     ├── 📂 Enum/                     # Глобални енумерации
│     ├── 📂 Error/                    # Глобални изключения и Error Handling логика
│     └── 📂 Constants/                # Системни константи и стрингове
│
├── 📝 README.md                       # Главното упътване за стартиране на проекта
└── 📂 Tests/                          # Всички автоматизирани тестови проекти (xUnit/NUnit)
```

### 🤖 Указание за AI при работа с тази структура:
* **За Документи:** Всички анализи, дневници и исторически бележки, които генерираш, трябва да се адресират към съответната подпапка в `docs/`.
* **За Front-End:** Когато разделяш интерфейсната логика, поставяй чистия CSS в `wwwroot/css/`, чистия JS в `wwwroot/js/`, а когато се използва външна библиотека като Bootstrap, я реферирай от папка `wwwroot/lib/bootstrap/`.
