### [ФОРМАТ НА ОТГОВОРА]
1. **Готов код:** Чист, структуриран и подготвен за Code Review (с необходимите XML/документационни коментари над методите).
2. **Описание за Pull Request (PR):** Дай ми кратко описание (2 изречения) на промените, което директно да копирам в GitHub, когато предавам кода на екипа.
3. **Урокът/Обяснението:** Кратко обяснение на логиката за моето учене.
4. **Git Commit съобщение:** Дай ми готово съобщение за commit, спазващо стандарта Conventional Commits (напр. `feat(core): implement calculation logic`), което директно да копирам при качването в GitHub.
