## 💻 Изисквания към кода (Генериран от AI)

### 🔴 Приложи СЛЕДНИТЕ СЕКЦИИ САМО АКО [Тип проект] е "Стаж" или "Работа в екип":
> * **Git клон (Branch):** Спри се на конвенцията `feature/JIRA-ID-кратко-описание`.
> * **Code Review стандарти:** Напиши кода спрямо SOLID принципите. Сложи силни валидации (Guard Clauses) в началото на методите. Използвай Dependency Injection.
> * **Pull Request описание:** Генерирай кратък PR шаблон в края на отговора си (Цел, Промени, Как е тествано).

### 🟢 Приложи СЛЕДНИТЕ СЕКЦИИ САМО АКО [Тип проект] е "Личен":
> * **Фокус:** Наблегни на образователни коментари (Clean Code обяснения). Обясни *защо* избираш този подход пред алтернативен.
> * **Опростяване:** Спести излишната архитектурна сложност (overengineering), ако задачата може да се реши по-просто и четимо.

### 🔵 Общи правила (Важат винаги):
* **C# / .NET:** Използвай модерни C# синтаксиси (File-scoped namespaces, Pattern matching, Primary constructors ако е приложимо).
* **Front-End:** Използвай семантичен HTML, чист и модулен CSS/Flexbox и модерен, асинхронен JavaScript (ES6+, async/await).
* **Грешки:** Кодът задължително трябва да включва адекватен Error Handling (try-catch, глобални филтри или подходящи HTTP статус кодове).
