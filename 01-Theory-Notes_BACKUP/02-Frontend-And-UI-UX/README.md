# 🎨 02. Фронтенд и UI/UX Дизайн (Frontend & UI/UX Engineering)

Добре дошли в **Домейн 02** на **Dev-Library**. Този сектор обхваща целия визуален и клиентски слой на модерните уеб приложения — от дизайн системи, семантичен HTML5, CSS3/Sass, Responsive дизайн, Tailwind CSS и Bootstrap 5 до строго-типизиран TypeScript, JavaScript и съвременни SPA рамки (**React / Next.js, Vue 3, Angular**).

## 🧭 Карта на Подмодулите

* **[01. HTML5, CSS3, Sass/SCSS & Методологии (`HTML5-CSS3-And-SASS/`)](HTML5-CSS3-And-SASS/README.md)**
  * *Обхваща:* Семантична структура на DOM, CSS Box Model, типография, Flexbox оформление, Sass/SCSS архитектура (променливи, миксини, `@use`/`@forward`), BEM методология и изпитни шаблони.
  1. **[01-00. Intro to HTML5 & CSS3 Architecture](HTML5-CSS3-And-SASS/01-00-Intro.md):** Как браузърът парсва HTML и CSS до Render Tree.
  2. **[01-01. HTML5 Семантика & CSS3 Основи](HTML5-CSS3-And-SASS/01-01-00-HTML5-And-CSS3-Basics.md):** Тагове, селектори, специфичност и каскадност.
  3. **[01-02. CSS Box Model & Типография](HTML5-CSS3-And-SASS/01-02-00-CSS-Box-Model-And-Typography.md):** `border-box`, Margin Collapse, `rem`/`em` и шрифтови системи.
  4. **[01-03. CSS Layout: Flexbox](HTML5-CSS3-And-SASS/01-03-00-CSS-Layout-Flexbox.md):** Главна и напречна ос, подравняване и гъвкави контейнери.
  5. **[01-04. Sass & SCSS Архитектура](HTML5-CSS3-And-SASS/01-04-00-Sass-And-SCSS-Architecture.md):** Модулен CSS, променливи, Nesting и Mixins.
  6. **[01-05. CSS Методологии & Сравнение на Рамки](HTML5-CSS3-And-SASS/01-05-CSS-Methodologies-And-Frameworks-Comparison.md):** BEM срещу Utility-First срещу Component-Based.

* **[02. Адаптивен Дизайн, Уеб Форми & CSS Рамки (`Responsive-Forms-And-Frameworks/`)](Responsive-Forms-And-Frameworks/README.md)**
  * *Обхваща:* Mobile-First подход, Media Queries, достъпни HTML5 форми и вградена валидация, **Tailwind CSS (Utility-First)** и **Bootstrap 5 (12-колонна мрежа и компоненти)**.
  1. **[02-00. Intro to Responsive Design & UI Frameworks](Responsive-Forms-And-Frameworks/02-00-Intro.md):** Стратегии за изграждане на адаптивни интерфейси.
  2. **[02-01. Responsive Web Design & Media Queries](Responsive-Forms-And-Frameworks/02-01-00-Responsive-Design-And-Media-Queries.md):** Breakpoints, `clamp()`, флуидни размери и Viewport единици.
  3. **[02-02. Уеб Форми & Валидация](Responsive-Forms-And-Frameworks/02-02-00-Working-With-Forms-And-Validation.md):** Достъпни формуляри, ARIA атрибути и клиентска валидация.
  4. **[02-03. Tailwind CSS (Utility-First)](Responsive-Forms-And-Frameworks/02-03-00-Tailwind-CSS-Utility-First.md):** Бързо стилизиране, конфигурация и JIT компилатор.
  5. **[02-04. Bootstrap 5 Grid & Компоненти](Responsive-Forms-And-Frameworks/02-04-00-Bootstrap-5-Grid-And-Components.md):** Responsive Grid система и готови UI елементи.

* **[03. TypeScript Language (`TypeScript-Language/`)](TypeScript-Language/README.md)**
  * *Обхваща:* Статична типова система, Structural Typing, Type Narrowing и Type Guards (`val is T`), Utility Types, обектно-ориентиран TypeScript, Generics с ограничения (`extends`) и декоратори.
  1. **[02-00. TypeScript срещу JavaScript (Архитектурно сравнение)](TypeScript-Language/02-00-TypeScript-vs-JavaScript.md):** Компилатор `tsc`, Type Erasure, `tsconfig.json` и кодов одит.    
        * **[02-00-TypeScript-vs-JavaScript](02-00-TypeScript-vs-JavaScript.md)**
  2. **[02-01. Basic Types, Interfaces & Type Aliases](TypeScript-Language/02-01-00-Basic-Types-And-Interfaces.md):** Примитиви, `unknown` срещу `any`, `never` и `interface` срещу `type`.
  3. **[02-02. Advanced Types, Guards & Utility Types](TypeScript-Language/02-02-00-Advanced-Types-And-Guards.md):** Unions, Intersections, `satisfies`, `as const`, `Partial`, `Pick` и `Omit`.
  4. **[02-03. OOP in TypeScript & SOLID](TypeScript-Language/02-03-00-OOP-In-TypeScript.md):** Класове, `#private` полета, `abstract`, `override` и Structural Typing.
  5. **[02-04. Mastering Generics & Conditional Types](TypeScript-Language/02-04-00-Mastering-Generics.md):** Типови шаблони `<T>`, `keyof` ограничения и филтриране с `never`.
  6. **[02-05. Decorators, ES Modules & Async TypeScript](TypeScript-Language/02-05-00-Decorators-Modules-And-Async.md):** AOP декоратори, `reflect-metadata`, `.d.ts` и `Promise<T>`.

* **[04. UI/UX Design, Figma & Accessibility (`UI-UX-Design-And-Figma/`)](UI-UX-Design-And-Figma/README.md)** *(Планирано разширение)*
  * *Обхваща:* Дизайн системи, визуална йерархия, психология на цветовете, Wireframing във Figma и стандарти за достъпност (WCAG 2.2).

* **[05. JavaScript (ES6+) & Модерни SPA Рамки (`JavaScript-And-SPA-Frameworks/`)](JavaScript-And-SPA-Frameworks/README.md)** *(Планирано разширение)*
  * *Обхваща:* Event Loop, Closures, Async/Await, DOM манипулации и реактивни компонентни рамки (**React / Next.js**, **Vue 3**, **Angular 18+**).
