# 🧪 05. QA и Автоматизирано Тестване (QA Automation & SDET)

Добре дошли в **Домейн 05** на **Dev-Library**. Този сектор обхваща пълния инженерен цикъл по осигуряване на качеството на софтуера (Quality Assurance & SDET) — от фундаменталните принципи на тестването, техниките за тестов дизайн и управлението на проекти в **Jira / MS Project**, през многоезичното модулно тестване (**NUnit, JUnit 5, Vitest, pytest**), до **Web UI & Mobile** автоматизация (**Selenium, Playwright, Appium**) и **API / Load** тестове (**Postman, RestSharp, REST Assured, Grafana K6**).

## 🧭 Карта на Подмодулите

* **[01. Пълен Курс по QA Automation & SDET (`01-QA-Automation/`)](01-QA-Automation/README.md)**
  * *Обхваща:* SDLC/STLC, тестова пирамида, Black-Box/White-Box техники (EP, BVA, Decision Tables), JQL и CI/CD конвейери, Mocking с тестови двойници, Page Object Model (POM), Auto-Waiting и натоварващи тестове.
  1. **[01-00. Intro to QA Engineering & Testing Pyramid](01-QA-Automation/01-00-Intro-To-QA-Engineering.md):** Ролята на QA/SDET инженера, 7-те принципа на ISTQB и тестовата пирамида.
  2. **[01-01. SDLC, STLC & Видове Тестване](01-QA-Automation/01-01-00-SDLC-STLC-And-Testing-Types.md):** Жизнен цикъл на дефекта (Bug Lifecycle), Smoke vs. Regression и ISO 25010.
  3. **[01-02. Test Design Техники, Jira, CI/CD & MS Project](01-QA-Automation/01-02-00-Test-Design-Jira-And-MS-Project.md):** EP, BVA, Decision Tables, State Transition, JQL заявки и Critical Path.
  4. **[01-03. Unit Testing & Mocking (C#, Java, TypeScript & Python)](01-QA-Automation/01-03-00-Multi-Language-Unit-Testing.md):** AAA шаблон, F.I.R.S.T. принципи, 5-те вида тестови двойници и Code Coverage.
  5. **[01-04. Selenium WebDriver, DOM Locators & POM](01-QA-Automation/01-04-00-Selenium-WebDriver-And-POM.md):** W3C WebDriver протокол, CSS срещу XPath локатори, Explicit Waits и Page Object Model.
  6. **[01-05. Playwright (Auto-Waiting), AJAX/jQuery & Mobile Appium](01-QA-Automation/01-05-00-Playwright-AJAX-And-Appium.md):** WebSocket/CDP архитектура, Actionability проверки, Network Mocking и Appium 2.0.
  7. **[01-06. REST API, GraphQL, Contract & Load Testing (K6 & JMeter)](01-QA-Automation/01-06-00-API-And-Performance-Testing.md):** Идемпотентност, Pact договори, p95/p99 латентност и Stress/Spike/Soak тестове.

* **[02. Security & Penetration Testing (OWASP Top 10)](Security-And-Penetration-Testing/README.md)** *(Планирано разширение)*
  * *Обхваща:* Тестване за сигурност, OWASP Top 10 уязвимости (XSS, SQL Injection, CSRF, Broken Access Control) и автоматизирано сканиране с OWASP ZAP.
