## 1. ПРОГРАМНИ ЕЗИЦИ (КАК МИСЛЯТ И КЪДЕ СЕ ПОЛЗВАТ ДНЕС)

| Критерий | C# (.NET 8/9) | Java 21+ | TypeScript 5+ | JavaScript (ES6+) | Python 3.12+ | PHP 8.3+ |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **Типизация** | Строга (проверява грешки преди пускане) | Строга (идентична с C#) | Строга (само при писане; изчезва в браузъра) | Динамична (грешките гърмят в браузъра) | Динамична, но силна (`"5" + 2` гърми) | По избор (`strict_types=1` го прави строг) |
| **Синтаксис** | Скоби `{}` и `;`; модерен LINQ | Скоби `{}` и `;`; по-описателен | Скоби `{}`; описва форми на обекти | Скоби `{}`; без типове | **Без скоби `{}`** — ползва 4 интервала отстъп | Скоби `{}` и `$` пред променливите |
| **Скорост** | 🚀 Много висока (компилиран) | 🚀 Много висока (JVM + Virtual Threads) | ⚡ Бърз (работи като JS в V8) | ⚡ Бърз в I/O (Event Loop) | 🐢 По-бавен при тежки сметки | ⚡ Бърз за уеб заявки (OPcache) |
| **Къде се търси най-много?** | Корпоративен бекенд, Cloud, Unity игри | Банки, финтех, големи Enterprise системи | Всеки модерен Frontend, Node.js и Playwright | Малки скриптове и браузърни добавки | AI / Machine Learning, QA, FastAPI, скриптове | Уеб сайтове, онлайн магазини (Laravel, WP) |

## 2. FRONTEND РАМКИ & CSS ИНСТРУМЕНТИ (КАК СЕ СТРОИ ИНТЕРФЕЙСЪТ)

### 📊 А. SPA Рамки (React / Next.js срещу Vue 3 срещу Angular)

| Критерий | React 19 + Next.js | Vue.js 3 | Angular 18+ |
| :--- | :--- | :--- | :--- |
| **Какво представлява?** | Библиотека за UI (Next.js добавя рутиране и SSR). | Прогресивна рамка с чисти `.vue` файлове. | Пълна корпоративна платформа „всичко в едно“. |
| **Крива на учене** | 🟡 Умерена (JSX + Hooks искат свикване). | 🟢 **Най-лесна** (най-близка до чист HTML/CSS/JS). | 🔴 По-стръмна (изисква TypeScript, RxJS, DI). |
| **Управление на данни** | `useState`, Zustand, Redux Toolkit. | **Signals / `ref()`** и **Pinia** (много интуитивно). | **Angular Signals** и RxJS потоци. |
| **Кога се избира?** | Най-търсен на пазара; стартъпи, SaaS и SEO сайтове. | Бърза разработка, ясен код и средни/големи проекти. | Огромни банкови и вътрешни системи (с .NET/Java). |

### 📊 Б. CSS Подходи (Pure CSS / SCSS срещу Tailwind CSS срещу Bootstrap 5)

| Инструмент | Как се пише? | Основно предимство днес | Кога да го избереш? |
| :--- | :--- | :--- | :--- |
| **Pure CSS3 / SCSS** | Отделни `.css` / `.scss` файлове с класове. | 100% контрол над дизайна; променливи и миксини. | Изпити, дизайн системи и пълна свобода без рамки. |
| **Tailwind CSS** | Готови малки класове директно в HTML (`flex p-4`). | **Най-бързо писане на уникален дизайн**; малък CSS. | Всички модерни React, Next.js, Vue и Laravel проекти. |
| **Bootstrap 5** | Готови компоненти (`btn btn-primary`, `modal`). | Пускаш работещ интерфейс за 5 минути без дизайнер. | Админ панели, вътрешни системи и бързи прототипи. |

## 3. BACKEND РАМКИ & API ПРОТОКОЛИ (REST, GRAPHQL, GRPC)

### 📊 А. Сървърни уеб рамки

| Рамка (Език) | Архитектурен стил | Главно предимство в продукция |
| :--- | :--- | :--- |
| **ASP.NET Core (C#)** | Вграден DI, Middleware, Minimal APIs / MVC. | Топ производителност, сигурност и интеграция с Azure. |
| **Spring Boot 3 (Java)** | Анотации (`@RestController`, `@Service`), вграден DI. | Индустриален стандарт за мащабируеми микросървиси. |
| **NestJS (TypeScript)** | Архитектура 1:1 с Angular и ASP.NET Core. | Позволява един и същ език (TS) на Frontend и Backend. |
| **FastAPI / Django (Python)** | FastAPI = скорост + автоматичен Swagger; Django = „батерии в кутия“. | Най-бързо пускане на AI/Data API-та и админ панели. |
| **Laravel (PHP 8.3+)** | Елегантен MVC, Eloquent ORM, вградени опашки. | Най-продуктивната рамка за уеб платформи и e-commerce. |

### 📊 Б. Комуникационни протоколи (Как си говорят клиентите и сървърите)

| Протокол | Формат на данните | Основна разлика | Къде се използва днес? |
| :--- | :--- | :--- | :--- |
| **REST API** | JSON по HTTP (`GET`, `POST`, `PUT`, `DELETE`). | Всеки ресурс си има собствен URL (`/api/users/1`). | **90% от уеб и мобилните приложения** (универсален стандарт). |
| **GraphQL** | JSON по **1 общ URL** (`POST /graphql`). | Клиентът сам избира точно кои полета да получи (няма излишни данни). | Сложни фронтенди и мобилни приложения с много свързани данни. |
| **gRPC** | Двоичен (**Protobuf** по HTTP/2). | **5–10 пъти по-бърз от JSON**, но не се чете с просто око. | Вътрешна комуникация между микросървиси в бекенда. |

## 4. БАЗИ ДАННИ, КЕШ & ОПАШКИ (КЪДЕ И КАК ЖИВЕЯТ ДАННИТЕ)

| Технология | Тип хранилище | Къде държи данните? | За какво се използва в реални проекти? |
| :--- | :--- | :--- | :--- |
| **PostgreSQL / SQL Server** | Релационна (Таблици и SQL) | На диск (SSD) с индекси | **Основна база данни** за пари, поръчки, потребители и строги връзки. |
| **MongoDB** | Документна NoSQL (JSON / BSON) | На диск (SSD) | Продуктови каталози с различни характеристики, логове и IoT данни. |
| **Redis** | Key-Value кеш | **Директно в RAM** (`< 0.5ms`) | Кеширане на чести заявки, потребителски сесии и Rate Limiting. |
| **Apache Kafka** | Event Streaming брокер | Разпределен лог на диск | Пренос на милиони събития в секунда между микросървиси без загуба. |

## 5. QA AUTOMATION & PERFORMANCE (КОЙ ИНСТРУМЕНТ ЗА КОЙ ТЕСТ)

| Инструмент | Какво тества? | Главна разлика спрямо конкурентите | Кога да го избереш? |
| :--- | :--- | :--- | :--- |
| **Playwright** | Модерен Web UI & API | **Вграден Auto-Waiting**, Trace Viewer и светкавична скорост. | **Нови проекти** — най-търсеният UI инструмент днес. |
| **Selenium WebDriver** | Web UI (W3C стандарт) | Поддържа всички езици и стари браузъри; изисква ръчни `WebDriverWait`. | Поддръжка на съществуващи корпоративни C# / Java тестови рамки. |
| **Appium 2.0** | Мобилни приложения | Използва WebDriver протокола за Android и iOS екрани. | Автоматизация на нативни и хибридни мобилни приложения. |
| **Postman / RestSharp** | REST & GraphQL API | Postman = визуален + Newman CLI; RestSharp/REST Assured = чист код. | Проверка на бизнес логика и договори без стартиране на браузър. |
| **Grafana K6** | Натоварване (Load/Stress) | Пише се на JavaScript, харчи **минимална RAM** (написан на Go). | Модерни CI/CD тестове за издръжливост при хиляди потребители. |

## 6. DEVOPS, КОНТЕЙНЕРИ, ОБЛАК & GIT КЛИЕНТИ

| Инструмент | Роля в разработката | Защо е задължителен днес? |
| :--- | :--- | :--- |
| **Git CLI / GitHub Desktop / TortoiseGit** | Контрол на версиите | CLI = пълна мощност; GitHub Desktop = чист визуален преглед; TortoiseGit = иконки в Windows Explorer. |
| **Docker** | Контейнеризация | Опакова кода и базата данни заедно — решава проблема *„На моя компютър работи“*. |
| **Kubernetes (K8s)** | Оркестрация на контейнери | Автоматично рестартира и мащабира стотици Docker контейнери при висок трафик. |
| **GitHub Actions** | CI/CD автоматизация | Автоматично пуска Unit, Playwright и K6 тестове при всеки `git push` или Pull Request. |
| **AWS / Microsoft Azure** | Облачна инфраструктура | Хостинг на сървъри, бази данни и файлове в глобални дейта центрове. |
