# 📘 Глава 01-01: Типове данни, Условни конструкции и Цикли (Control Flow)

**Статус:** Архитектурен справочник (Основи) | **Цел:** Управление на паметта (Stack/Heap) и потока на изпълнение

---

## ⚡ 1. КАКЪВ ПРОБЛЕМ РЕШАВАТ ТИПОВЕТЕ И КОНТРОЛЪТ НА ПОТОКА?
Всяка програма в C# се свежда до две фундаментални операции: **съхранение на данни** в точния размер памет и **вземане на решения** как тези данни да се обработят. Неправилният избор на тип води до загуба на точност (напр. при парични сметки) или излишен разход на RAM, а лошо структурираните условия и цикли превръщат кода в бавен и нечетим лабиринт.

## 📊 2. МАТРИЦА НА ТИПОВЕТЕ ДАННИ В ПАМЕТТА (Value vs Reference)

| Категория | Типове в C# | Къде се пазят? | Кога се използват? | Капан / Внимание |
| :--- | :--- | :--- | :--- | :--- |
| **Цели числа** | `byte`, `int`, `long` | **Stack** (Value) | Броячи, индекси, ID-та (`int` по подразбиране). | Делението `5 / 2` връща `2`, а не `2.5`! |
| **Дробни (Научни)** | `float`, `double` | **Stack** (Value) | Физика, координати, среден успех (`double`). | Имат закръгляне в двоична бройна система (`0.1 + 0.2 != 0.3`). |
| **Дробни (Финансови)** | `decimal` (`10.5m`) | **Stack** (Value) | **Пари, цени, заплати, данъци.** | По-бавен и заема 16 байта, но гарантира 100% точност. |
| **Логически / Символ** | `bool`, `char` (`'a'`) | **Stack** (Value) | Флагове за състояние и единични символи. | `char` се пази като числов Unicode код под капака. |
| **Текстови / Обекти** | `string`, масиви, класове | **Heap** (Reference) | Текст и сложни структури от данни. | `string` е **Immutable** (всяка промяна създава нов обект). |

## 🧠 3. АНАТОМИЯ НА УСЛОВНИТЕ КОНСТРУКЦИИ (Decision Making)

* **`if - else if - else`:** Използва се за сложни логически диапазони (`grade >= 5.50 && isPresent`).
  * ⚡ **Short-Circuit правило:** При `A && B`, ако `A` е `false`, C# **не проверява** `B`. При `A || B`, ако `A` е `true`, C# **не проверява** `B`.
* **`switch - case`:** Използва се при проверка на **една променлива** срещу много конкретни константни стойности (дни от седмицата, команди). Под капака компилаторът го оптимизира в бърза Jump Table.
* **Модерен `switch` expression (C# 8+):**
  ```csharp
  string status = grade switch
  {
      >= 5.50 => "Отличен",
      >= 3.00 => "Преминал",
      _       => "Непреминал" // Default случай
  };
  ```

### 🔀 Схема на потока при взимане на решения

```text
                  [ ВХОДНИ ДАННИ (Input) ]
                             │
              ┌──────────────┴──────────────┐
              ▼                             ▼
   [ IF - ELSE IF - ELSE ]           [ SWITCH - CASE ]
   (Сложни диапазони, &&, ||)     (Една променлива, точни стойности)
              │                             │
      ┌───────┴───────┐             ┌───────┼───────┐
      ▼               ▼             ▼       ▼       ▼
   (True)          (False)       Case 1  Case 2  Default
      │               │             │       │       │
      ▼               ▼             └───────┼───────┘
 [Вложен IF]     [Следващ Else]             ▼
  (Под-условие)                     [ ИЗХОД / РЕЗУЛТАТ ]
```

### 1️⃣ Конструкцията `if - else if - else` и вложени условия
Използва се, когато проверяваме сложни логически изрази, диапазони или комбинации от различни променливи.

* **Къде какво се подава:** В скобите `if (условие)` се подава израз, който задължително връща **`bool`** (`true` или `false`).
* **Логически оператори:**
  * `&&` (**И / AND**): И двете страни трябва да са `true`. *(Short-Circuit: ако лявата е `false`, дясната не се проверява).*
  * `||` (**ИЛИ / OR**): Поне едната страна трябва да е `true`. *(Short-Circuit: ако лявата е `true`, дясната не се проверява).*
  * `!` (**НЕ / NOT**): Обръща стойността (`!isValid`).

```csharp
char category = 'S'; // Вход 1: Категория (S - Студент, R - Редовен)
double grade = 5.80; // Вход 2: Успех

// ВЪНШЕН IF: Проверява първото главно условие
if (category == 'S' && grade >= 2.00 && grade <= 6.00) 
{
    // ВЛОЖЕН IF (Nested): Изпълнява се САМО ако външният if е true
    if (grade >= 5.50 || category == 'V') 
    {
        Console.WriteLine("Одобрен за пълна стипендия!");
    }
    else
    {
        Console.WriteLine("Одобрен за стандартно обучение.");
    }
}
else if (category == 'R') // Проверява се само ако горният if е false
{
    Console.WriteLine("Редовен потребител.");
}
else // Изпълнява се, ако НИТО ЕДНО условие по-горе не е вярно
{
    Console.WriteLine("Невалидни входни данни.");
}
```

### 2️⃣ Класически `switch - case` (Старият вариант)
Използва се за сравнение на **една конкретна променлива** (напр. `char`, `int`, `string`) срещу фиксирани константи.

* **Къде какво се подава:** Променливата влиза в скобите `switch (променлива)`, а след `case` се пишат само константи.
* **Как се правят `OR` и `AND` тук:**
  * **Логическо `OR` (ИЛИ):** Изреждаш няколко `case`-а един под друг без `break` между тях (т.нар. *fall-through*).
  * **Логическо `AND` (И):** Добавяш ключовата дума `when` след `case` (C# 7+).
  * **Задължителен `break`:** Всеки блок с код трябва да завършва с `break;` или `return;`.

```csharp
char gradeLetter = 'B'; // Входна променлива
int attendance = 95;    // Допълнителна променлива за условие

switch (gradeLetter) // <-- ТУК подаваме променливата, която ще тестваме
{
    case 'A':
    case 'B': // Логическо OR: Важи за 'A' ИЛИ 'B'
        Console.WriteLine("Отлично представяне!");
        break; // Задължителен изход от switch блока

    case 'C' when attendance >= 90: // Логическо AND: 'C' И присъствие >= 90%
        Console.WriteLine("Преминава с бонус за присъствие.");
        break;

    case 'C':
    case 'D':
        Console.WriteLine("Преминава стандартно.");
        break;

    default: // Еквивалент на 'else' (ако никой case не съвпадне)
        Console.WriteLine("Невалидна оценка или скъсан.");
        break;
}
```

### 3️⃣ Модерен `switch` expression (Новият вариант – C# 8 / 9+)
По-кратък, по-безопасен и връща директно резултат (стойност), без да пишеш `case` и `break` на всеки ред.

* **Къде какво се подава:** Променливата се пише **отляво** преди думата `switch` (`променлива switch { ... }`).
* **Директни думи `and`, `or`, `not`:** В новия синтаксис можеш да комбинираш диапазони и символи директно с думите **`and`** и **`or`**.

```csharp
char symbol = 'e'; // Входен символ за анализ

// Променливата се подава ОТЛЯВО, а резултатът се записва директно в променлива:
string result = symbol switch
{
    // Логическо OR директно с думата 'or':
    'a' or 'e' or 'i' or 'o' or 'u' => "Малка гласна буква",

    // Логическо AND за диапазон от символи в Unicode таблицата:
    >= 'A' and <= 'Z'               => "Главна латинска буква",

    // Комбинация от диапазон с 'and':
    >= '0' and <= '9'               => "Цифра от 0 до 9",

    // Всичко останало (еквивалент на default):
    _                               => "Специален символ или интервал"
}; // <-- Задължителна точка и запетая накрая, защото това е израз!
```

### ⚡ Бързо правило: Кога кой да избереш?
* Използвай **`if - else`**, когато сравняваш **различни** променливи (напр. `age > 18 && hasTicket`).
* Използвай **новия `switch` expression**, когато преобразуваш **една** променлива (напр. `char` или `int`) в конкретен резултат или текст.
* Използвай **стария `switch - case`**, когато за всеки `case` трябва да изпълниш **повече от 1 ред код** (напр. да извикаш методи, да печаташ и да променяш списъци).

## 🔄 4. НАВИГАТОР НА ЦИКЛИТЕ И ВЛОЖЕНИТЕ ЦИКЛИ

| Тип цикъл | Кога да го избереш? | Минимум изпълнения | Специфика под капака |
| :--- | :--- | :--- | :--- |
| **`for`** | Когато знаеш **точния брой** завъртания или ти трябва индекс (`i`). | **0 пъти** | Пълен контрол върху стъпката (`i++`, `i += 2`, `i--`). |
| **`while`** | Когато въртиш **до настъпване на събитие** (напр. `input != "End"`). | **0 пъти** | Проверява условието *преди* влизане в тялото. |
| **`do - while`** | Когато кодът трябва да се изпълни **поне веднъж** (напр. меню за избор). | **1 път** | Проверява условието *след* изпълнение на тялото. |
| **`foreach`** | Когато обхождаш **всички елементи** на колекция само за четене. | **0 пъти** | Забранява промяна (добавяне/триене) на колекцията вътре! |

### 🏗️ Вложени цикли (Nested Loops)
* **Как работят:** За **всяка една стъпка** на външния цикъл, вътрешният цикъл се завърта **от начало до край**.
* **Приложение:** Обхождане на 2D матрици (`ред` и `колона`), генериране на комбинации, таблица за умножение.
* **Контрол на потока:** `break` прекратява **само най-вътрешния** цикъл, в който се намира (не излиза от всички цикли едновременно).


### 🔀 Схема на потока при различните цикли

```text
   [ FOR / WHILE ] (Проверка ПРЕДИ входа)       [ DO - WHILE ] (Проверка СЛЕД входа)
                     │                                             │
                     ▼                                             ▼
          ┌──► ( Условие? ) ──(False)──► [КРАЙ]             [ ИЗПЪЛНИ КОДА ] ◄──┐
          │          │                                             │            │
          │       (True)                                           ▼            │
          │          │                                      ( Условие? ) ──(True)
          │          ▼                                             │
          └── [ ИЗПЪЛНИ КОДА ]                                  (False)
                                                                   │
                                                                   ▼
                                                                [КРАЙ]
```

### 2️⃣ Как се пишат и кое къде се подава (4-те модела)

#### 🔹 `for` цикъл (Броячен цикъл)
В скобите `for (1. Начало; 2. Условие; 3. Стъпка)` се подават **3 части**, разделени с `;`:
1. **Начало:** Създава брояча (изпълнява се **само веднъж** в началото).
2. **Условие:** Проверява се **преди всяка стъпка**. Докато е `true`, цикълът върти.
3. **Стъпка:** Променя брояча **в края** на всяко завъртане.

```csharp
// Отпечатва четните числа от 0 до 10
for (int i = 0; i <= 10; i += 2) 
{
    Console.Write(i + " "); // Изход: 0 2 4 6 8 10
}
```

#### 🔹 `while` цикъл (Цикъл с предусловие)
В скобите `while (условие)` се подава **само логически израз (`bool`)**. Променливата се създава *преди* цикъла и се обновява *вътре* в тялото му.

```csharp
string command = Console.ReadLine(); // 1. Начална стойност ПРЕДИ цикъла

while (command != "Stop")            // 2. Условие за продължаване
{
    Console.WriteLine($"Обработвам: {command}");
    command = Console.ReadLine();    // 3. ЗАДЪЛЖИТЕЛНО обновяване (иначе става безкраен цикъл!)
}
```

#### 🔹 `do - while` цикъл (Цикъл с постусловие)
Тялото `do { ... }` се изпълнява **винаги поне 1 път**, а условието `while (условие);` се проверява накрая (завършва с `;`).

```csharp
int number;
do
{
    Console.Write("Въведи положително число: ");
    number = int.Parse(Console.ReadLine());
} while (number <= 0); // Повтаря, докато потребителят не въведе валидно число > 0
```

#### 🔹 `foreach` цикъл (Обхождане на колекции)
В скобите `foreach (Тип променлива in колекция)` подаваш колекцията отдясно, а отляво получаваш **копие** на текущия елемент (само за четене).

```csharp
string[] names = { "Иван", "Мария", "Георги" };

foreach (string name in names) // Минава автоматично от първия до последния елемент
{
    Console.WriteLine(name);
    // name = "Нов"; -> ГРЕШКА! Не можеш да променяш елемента в foreach
}
```

### 3️⃣ Управление на потока: `break` срещу `continue`

* **`break` (Авариен изход):** Прекратява цикъла **напълно и веднага**. Програмата продължава на първия ред *след* затварящата скоба `}` на цикъла.
* **`continue` (Прескачане на стъпка):** Спира **текущото** завъртане и скача директно към следващата итерация (при `for` изпълнява стъпката `i++`, при `while` отива директно на проверката).

```csharp
for (int i = 1; i <= 5; i++)
{
    if (i == 2) continue; // Прескача 2 (не го печата, отива на i = 3)
    if (i == 4) break;    // Прекъсва цикъла напълно при 4 (5 изобщо не се стига)
    
    Console.Write(i + " "); // Изход: 1 3
}
```

### 🏗️ 4️⃣ Вложени цикли (Nested Loops) – Схема и работа под капака

**Златно правило:** За **всяко 1 завъртане** на външния цикъл, вътрешният цикъл се завърта **от начало до край**. Ако външният върти \(N\) пъти, а вътрешният \(M\) пъти, кодът вътре се изпълнява \(N \times M\) пъти (времева сложност \(O(n^2)\)).

```text
[ ВЪНШЕН ЦИКЪЛ: row = 1 ] ──► Вътрешен: col = 1, col = 2, col = 3 (Пълен цикъл!)
[ ВЪНШЕН ЦИКЪЛ: row = 2 ] ──► Вътрешен: col = 1, col = 2, col = 3 (Пълен цикъл!)
```

```csharp
// Пример: Отпечатване на правоъгълник от звездички (2 реда по 3 колони)
for (int row = 1; row <= 2; row++)          // Външен цикъл: отговаря за РЕДОВЕТЕ
{
    for (int col = 1; col <= 3; col++)      // Вътрешен цикъл: отговаря за КОЛОНИТЕ
    {
        Console.Write("* ");                // Изпълнява се общо 2 * 3 = 6 пъти
    }
    Console.WriteLine();                    // Минава на нов ред след края на вътрешния цикъл
}
```

* ⚠️ **Капан при вложени цикли:** Ключовата дума `break;` вътре във вътрешния цикъл прекратява **само вътрешния цикъл**, а външният продължава да си върти! Ако искаш да излезеш и от двата наведнъж, използвай `return;` (ако си в метод) или булев флаг `bool isFound = true;`.

## 🚨 5. КРИТИЧНИ JUNIOR КАПАНИ

### 🛑 Капан 1: Целочислено деление (Integer Division)
* **Проблем:** `double result = 5 / 2;` записва `2.0` вместо `2.5`.
* **Причина:** И двете числа (`5` и `2`) са `int`, затова C# първо ги дели целочислено и чак после превръща резултата в `double`.
* **Решение:** Направи поне едното число дробно: `double result = 5.0 / 2;` или `(double)a / b`.

### 🛑 Капан 2: Arrow Anti-Pattern (Дълбоко влагане на `if`)
* **Проблем:** 5 нива на вложени `if` блокове един в друг, които правят кода невъзможен за четене и поддръжка.
* **Решение:** Използвай **Guard Clauses** (обърни проверката и излез рано с `return` или `continue`).

### 🛑 Капан 3: `int.Parse()` върху потребителски вход
* **Проблем:** Програмата гърми с `FormatException`, ако потребителят въведе текст вместо число.
* **Решение:** Използвай `if (int.TryParse(input, out int number))` за безопасна проверка без хвърляне на грешки.
