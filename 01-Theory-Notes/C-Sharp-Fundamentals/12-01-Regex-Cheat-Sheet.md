## 🔤 1. СИМВОЛНИ КЛАСОВЕ И ДИАПАЗОНИ

| Символ | Какво съвпада? | Отрицание (Всичко освен...) | Пример за съвпадение |
| :--- | :--- | :--- | :--- |
| **`.`** | Всеки символ (без нов ред `\n`) | — | `c.t` ➔ `"cat"`, `"c9t"`, `"c-t"` |
| **`\d`** | Цифра (`0-9`) | **`\D`** (не-цифра) | `\d{3}` ➔ `"123"` |
| **`\w`** | Буква, цифра или `_` (`a-z, A-Z, 0-9, _`) | **`\W`** (интервали, пунктуация) | `\w+` ➔ `"User_99"` |
| **`\s`** | Празно място (интервал, таб `\t`, нов ред) | **`\S`** (видим символ) | `\s+` ➔ `"   "` |
| **`[abc]`** | Един от изброените (`a`, `b` или `c`) | **`[^abc]`** (нито един от тях) | `[aeiou]` ➔ малка гласна |
| **`[a-z]`** | Диапазон от малки латински букви | **`[^a-z]`** | `[A-Za-z]` ➔ всяка латинска буква |
| **`[а-яА-Я]`** | Всички букви на кирилица | **`[^а-яА-Я]`** | `[А-Я][а-я]+` ➔ `"Иван"` |

## 🔢 2. КВАНТИФИКАТОРИ (БРОЙ ПОВТОРЕНИЯ)

| Greedy (Алчен) | Lazy (Мързелив) | Значение | Пример (Символи и Дати) |
| :--- | :--- | :--- | :--- |
| **`*`** | **`*?`** | **0 или повече** пъти | `ab*` ➔ **`a`**, *`ab`*, <u>`abbb`</u> |
| **`+`** | **`+?`** | **1 или повече** пъти | `\d+` ➔ **`7`**, *`420`*, <u>`1928`</u> |
| **`?`** | **`??`** | **0 или 1** път (незадължителен) | `https?` ➔ **`http`**, *`https`* |
| **`{n}`** | — | **Точно `n`** пъти | `\d{4}` ➔ **`1928`**, *`2025`* <br> `dd-MMM-yyyy` ➔ **`13/Jul/1928`**, *`09-12-2025`* |
| **`{n,}`** | **`{n,}?`** | **Поне `n`** пъти | `\w{3,}` ➔ **`Jul`**, *`Dec`*, <u>`SoftUni`</u> |
| **`{n,m}`** | **`{n,m}?`** | **Между `n` и `m`** пъти | `\d{1,2}` ➔ **`9`**, *`13`*, <u>`30`</u> *(ден/месец)* |

> 💡 **Златно правило:** Винаги добавяй **`?`** след `*` или `+` (напр. `".*?"`), когато търсиш текст между два разделителя, за да спреш на *първия* затварящ символ!

## ⚓ 3. КОТВИ, ГРУПИ И LOOKAROUND

| Синтаксис | Име | Какво прави? | Пример |
| :--- | :--- | :--- | :--- |
| **`^`** / **`$`** | Начало / Край | Огражда целия стринг (или ред при `Multiline`) | `^\d+$` ➔ стрингът е *само* цифри |
| **`\b`** | Граница на дума | Отделя цяла дума от пунктуация/интервали | `\bcat\b` ➔ `"cat"`, но не `"scatter"` |
| **`(a\|b)`** | Алтернатива (OR) | Съвпада с `a` ИЛИ `b` | `(cat\|dog)` ➔ `"cat"` или `"dog"` |
| **`(...)`** | Номерирана група | Записва съвпадението в `Groups` | `(\d+)-(\w+)` |
| **`(?<name>...)`** | Именувана група | Записва в `Groups["name"]` (най-чисто!) | `(?<price>\d+\.\d{2})` |
| **`(?:...)`** | Незаписваща група | Групира без да заема място в `Groups` | `(?:Mr\|Mrs)\.\s+(?<name>\w+)` |
| **`\k<name>`** | Backreference | Търси същия текст, уловен в група `name` | `(?<w>\w+)\s+\k<w>` ➔ повтаряща се дума |
| **`(?=...)`** | Positive Lookahead | Трябва да е **последвано от** `...` (без да го взима) | `\d+(?=\s*лв)` ➔ взима само числото |
| **`(?!...)`** | Negative Lookahead | **НЕ** трябва да е последвано от `...` | `\d+(?!\s*USD)` |
| **`(?<=...)`** | Positive Lookbehind | Трябва да е **предшествано от** `...` (без да го взима) | `(?<=@)\w+` ➔ взима името след `@` |
| **`(?<!...)`** | Negative Lookbehind | **НЕ** трябва да е предшествано от `...` | `(?<!-)\b\d+\b` ➔ само положителни числа |

## 💻 4. ГОТОВИ C# ШАБЛОНИ ЗА ИЗПИТА (`System.Text.RegularExpressions`)

```csharp
// 1. ВАЛИДАЦИЯ (Връща true/false)
bool isValid = Regex.IsMatch(input, @"^[A-Z][a-z]+\$");

// 2. ИЗВЛИЧАНЕ НА ЕДИН ЗАПИС С ИМЕНУВАНИ ГРУПИ
Match m = Regex.Match(input, @"Name:\s*(?<name>[A-Za-z]+),\s*Age:\s*(?<age>\d+)");
if (m.Success)
{
    string name = m.Groups["name"].Value;
    int age = int.Parse(m.Groups["age"].Value);
}

// 3. ИЗВЛИЧАНЕ НА ВСИЧКИ СЪВПАДЕНИЯ В ТЕКСТ
MatchCollection allMatches = Regex.Matches(input, @"#(?<tag>\w+)");
foreach (Match item in allMatches)
{
    Console.WriteLine(item.Groups["tag"].Value);
}

// 4. ЗАМЯНА ПО ШАБЛОН (Почистване на излишни интервали)
string clean = Regex.Replace(input, @"\s+", " ").Trim();

// 5. РАЗДЕЛЯНЕ ПО МНОЖЕСТВО РАЗДЕЛИТЕЛИ
string tokens = Regex.Split(input, @"[,;|\s]+");
```

## 🎯 5. НАЙ-ЧЕСТИ ИЗПИТНИ ШАБЛОНИ (COPY-PASTE)

* **Дата във формат `dd-MM-yyyy` или `dd/MM/yyyy` (напр. `09-12-2025` или `09/12/2025`):**
  * 🎯 `^(?<day>\d{2})([-./])(?<month>\d{2})\1(?<year>\d{4})$`
  * *Забележка:* `\1` (Backreference) гарантира, че двата разделителя са еднакви (няма да пусне `09-12/2025`).
* **Дата с трибуквен месец `dd-MMM-yyyy` (напр. `13/Jul/1928` или `30-Dec-1994`):**
  * 🎯 `\b(?<day>\d{2})([-.\/])(?<month>[A-Z][a-z]{2})\1(?<year>\d{4})\b`
* **Цяло или дробно число (вкл. отрицателно, напр. `-42.50`):**
  * 🎯 `^-?\d+(\.\d+)?$`
* **Пълно име (две думи с главна буква, напр. `John Smith`):**
  * 🎯 `\b[A-Z][a-z]+ [A-Z][a-z]+\b`
* **Валиден имейл (базов изпитен, напр. `valid123@email.bg`):**
  * 🎯 `^(?<user>[a-zA-Z0-9._-]+)@(?<host>[a-zA-Z0-9.-]+\.[a-zA-Z]{2,})$`
* **Всички специални символи (не-букви и не-цифри):**
  * 🎯 `[^\w\s]`

> ⚠️ **Уловка от презентацията (.NET срещу Regex101):** При шаблон с именувана и неименувана група, например `@"(?<Name>[A-Za-z]+)\s+(\d+)"`:
> * В **Regex101 (PCRE)** групите се броят по ред: `Groups` е `Name`, а `Groups` е числото.
> * В **C# (.NET)** именуваните групи **не изместват** номерацията на неименуваните: `Groups["Name"]` е името, а **`Groups`** (първата неименувана!) е числото.

## 🧩 6. СПЕЦИАЛНИ .NET КОНСТРУКЦИИ И ЗАМЕСТВАНИЯ (ОТ MICROSOFT DOCS)

| Синтаксис | Какво прави? | Пример |
| :--- | :--- | :--- |
| **`\p{IsCyrillic}`** | Съвпада с всяка буква на **кирилица** | `\p{IsCyrillic}+` ➔ `"София"` |
| **`\p{Lu}`** / **`\p{Ll}`** | Всяка **главна** (`Lu`) / **малка** (`Ll`) Unicode буква | `\p{Lu}\p{Ll}+` ➔ `"Иван"`, `"John"` |
| **`(?i)`** / **`(?-i)`** | Включва / изключва **Case-Insensitive** режим вътре в шаблона | `(?i)admin(?-i)` ➔ `"Admin"`, `"ADMIN"` |
| **`$1`** / **`${name}`** | Вмъква уловената група при `Regex.Replace` | `Regex.Replace("Иван Петров", @"(\w+) (\w+)", "$2 $1")` ➔ `"Петров Иван"` |
| **`$&`** | Вмъква **цялото** намерено съвпадение при `Regex.Replace` | `Regex.Replace("100 лв", @"\d+", "[$&]")` ➔ `"[100] лв"` |
