## 🔍 1. ОСНОВНИ МЕТОДИ НА `string` (ВРЪЩАТ НОВ СТРИНГ!)

| Категория | Метод / Синтаксис | Какво прави? | Пример |
| :--- | :--- | :--- | :--- |
| **Проверка** | `string.IsNullOrEmpty(s)` | Проверява дали е `null` или `""` | `""` ➔ `true`, `" "` ➔ `false` |
| **Проверка** | `string.IsNullOrWhiteSpace(s)` | Проверява дали е `null`, `""` или само интервали | `"   "` ➔ `true` *(Най-безопасно!)* |
| **Търсене** | `s.Contains("abc")` | Връща `true`, ако поднизът се съдържа | `"SoftUni".Contains("Uni")` ➔ `true` |
| **Търсене** | `s.StartsWith("A")` / `s.EndsWith("Z")` | Проверява началото / края на текста | `"test.cs".EndsWith(".cs")` ➔ `true` |
| **Индекси** | `s.IndexOf("a")` / `s.LastIndexOf("a")` | Първи / последен индекс на срещане (или `-1`) | `"banana".IndexOf("a")` ➔ `1` |
| **Изрязване** | `s.Substring(startIndex, length)` | Изрязва `length` символа от `startIndex` | `"SoftUni".Substring(4, 3)` ➔ `"Uni"` |
| **Почистване** | `s.Trim()` / `TrimStart()` / `TrimEnd()` | Маха празните места (или подадени символи) | `"  hi  ".Trim()` ➔ `"hi"` |
| **Замяна** | `s.Replace("стар", "нов")` | Заменя всички срещания с нов текст | `"a-b".Replace("-", "_")` ➔ `"a_b"` |
| **Регистър** | `s.ToUpper()` / `s.ToLower()` | Превръща всички букви в главни / малки | `"Abc".ToUpper()` ➔ `"ABC"` |
| **Разделяне** | `s.Split(' ', StringSplitOptions.RemoveEmptyEntries)` | Разделя текста на масив `string[]` | `"a  b".Split(' ', ...)` ➔ `["a", "b"]` |
| **Съединяване** | `string.Join(", ", collection)` | Слепва елементи от колекция с разделител | `string.Join("-", new[] {1, 2})` ➔ `"1-2"` |

## 🚀 2. МЕТОДИ НА `StringBuilder` (ПРОМЕНЯТ ДИРЕКТНО В ПАМЕТТА!)

| Метод | Действие в буфера | Пример |
| :--- | :--- | :--- |
| **`new StringBuilder()`** | Създава празен динамичен буфер | `var sb = new StringBuilder();` |
| **`sb.Append(val)`** | Добавя текст в края на буфера | `sb.Append("Hello");` |
| **`sb.AppendLine(val)`** | Добавя текст + нов ред в края | `sb.AppendLine("Line 1");` |
| **`sb.Insert(index, val)`** | Вмъква текст на конкретна позиция | `sb.Insert(0, "Start: ");` |
| **`sb.Replace(old, new)`** | Заменя всички срещания директно в буфера | `sb.Replace("old", "new");` |
| **`sb.Remove(start, len)`** | Изтрива `len` символа от `start` индекс | `sb.Remove(0, 7);` |
| **`sb.Clear()`** | Изтрива цялото съдържание (запазва капацитета) | `sb.Clear();` |
| **`sb.ToString()`** | Превръща буфера в готов `string` | `string res = sb.ToString();` |

## 🔠 3. ПОЛЕЗНИ МЕТОДИ ЗА СИМВОЛИ (`char`)

Използват се при обхождане на текст символ по символ (`foreach (char ch in text)`):

* `char.IsDigit(ch)` — проверява дали е цифра (`'0'`–`'9'`).
* `char.IsLetter(ch)` — проверява дали е буква.
* `char.IsLetterOrDigit(ch)` — проверява дали е буква или цифра.
* `char.IsUpper(ch)` / `char.IsLower(ch)` — проверява дали е главна / малка буква.
* `char.IsWhiteSpace(ch)` — проверява дали е интервал, табулация или нов ред.
* `char.ToUpper(ch)` / `char.ToLower(ch)` — превръща символа в главна / малка буква.
* **Трик за цифра от `char`:** `int digit = ch - '0';` *(превръща `'5'` в числото `5`)*.

## 🎯 4. СПЕЦИФИКАТОРИ ЗА ФОРМАТИРАНЕ (STRING INTERPOLATION `$"..."`)

| Формат | Значение | Код | Резултат |
| :--- | :--- | :--- | :--- |
| **`:F2`** | Закръгляне до 2 знака след запетаята (Fixed-point) | `$"{5.6789:F2}"` | `"5.68"` |
| **`:D4`** | Допълване с водещи нули до 4 цифри (само за цели числа) | `$"{42:D4}"` | `"0042"` |
| **`:C`** | Валутен формат според регионалните настройки (Currency) | `$"{19.5:C}"` | `"19,50 лв."` / `"$19.50"` |
| **`:P1`** | Процент (умножава по 100 и добавя `%`) | `$"{0.256:P1}"` | `"25.6%"` |
| **`:N0`** | Разделител за хиляди без дробна част | `$"{1500000:N0}"` | `"1,500,000"` |
| **`:X`** | Шестнадесетичен запис (Hexadecimal) | `$"{255:X}"` | `"FF"` |
| **`{val,10}`** | Подравняване вдясно в поле от 10 символа | `$"|{42,5}|"` | `"|   42|"` |
| **`{val,-10}`** | Подравняване вляво в поле от 10 символа | `$"|{42,-5}|"` | `"|42   |"` |

## 🏃 5. ESCAPE ПОСЛЕДОВАТЕЛНОСТИ И LITERALS

* `\n` — Нов ред (Linux/Unix) | `\r\n` — Нов ред (Windows) | `Environment.NewLine` — Универсален нов ред.
* `\t` — Табулация | `\"` — Кавичка вътре в текст | `\\` — Една наклонена черта.
* `@"C:\Temp\file.txt"` — **Verbatim string** (игнорира escape символите `\`, полезен за пътища и Regex).
* `"""..."""` — **Raw string literal (C# 11+)** (позволява многоредов текст и кавички без никакво екраниране).
