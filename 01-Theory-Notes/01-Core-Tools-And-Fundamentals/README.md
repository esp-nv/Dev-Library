# 🛠️ 01. Инструменти, Контрол на Версиите и Алгоритми (Core Tools & Fundamentals)

Добре дошли в **Домейн 01** на **Dev-Library**. Този сектор обхваща универсалните инженерни основи, инструментите за разработка и алгоритмичното мислене, които са задължителни за всеки софтуерен инженер — независимо дали пише на **C#, Java, Python, TypeScript или PHP**.

## 🧭 Карта на Подмодулите

* **[01. Среда за разработка и Браузърна диагностика (`Course-Intro-And-Setup/`)](Course-Intro-And-Setup/README.md)**
  * *Обхваща:* Клиент-сървър архитектура, сравнение на 10-те водещи IDE среди (VS Code, Visual Studio, Rider, IntelliJ, PyCharm), Live Server и дълбок одит с Chrome DevTools.
  1. **[00-00. Intro to Web Ecosystem & Development Environments](Course-Intro-And-Setup/00-00-Intro.md):** Как работят браузърът, сървърът и инструментите за разработка.
  2. **[00-01. Уеб Екосистема & Сравнение на IDE средите](Course-Intro-And-Setup/00-01-00-Web-Ecosystem-And-IDEs.md):** Теория, матрица на 10-те IDE-та и конфигурация от нулата.
  3. **[00-02. Браузърна диагностика, Live Server & Мрежова интеграция](Course-Intro-And-Setup/00-02-00-Browser-Diagnostics-And-Network.md):** Network таб, Cache капани и DevTools одит.

* **[02. Контрол на версиите с Git & GitHub (`Git-And-GitHub/`)](Git-And-GitHub/README.md)**
  * *Обхваща:* Разпределен контрол на версиите, четирите зони на Git, работа с клонове, разрешаване на Merge Conflicts и сравнение между **Git CLI**, **GitHub Desktop** и **TortoiseGit („Костенурката“)**.
  1. **[01-00. Git & GitHub Архитектура, Клиенти & Капани](Git-And-GitHub/01-00-Git-And-GitHub-Architecture.md):** Вътрешен модел на Git, `.gitignore` хигиена и интервю въпроси (`fetch` vs `pull`, `merge` vs `rebase`).
  2. **[01-01. Практика от Нулата: CLI, GitHub Desktop & TortoiseGit](Git-And-GitHub/01-01-Syntax.md):** Команди в терминала, графични стъпки и разрешаване на конфликти за 30 секунди.

* **[03. Алгоритми и Структури от Данни (`Algorithms-And-Data-Structures/`)](Algorithms-And-Data-Structures/README.md)**
  * *Обхваща:* Анализ на алгоритмична сложност (**Big O**), рекурсия, търсене, сортиране, алчни алгоритми, графи и динамично програмиране с паралелни имплементации на **Python, C#, JavaScript и Java**.
  1. **[00-00. Intro & Big O Notation](Algorithms-And-Data-Structures/00-00-Intro-And-Big-O.md):** Времева и пространствена сложност ($O(1)$, $O(\log n)$, $O(n)$, $O(n \log n)$, $O(n^2)$).
  2. **[00-01. Recursion & Backtracking](Algorithms-And-Data-Structures/00-01-00-Recursion-And-Backtracking.md):** Рекурсивни дървета, Call Stack и търсене с връщане.
  3. **[00-02. Searching Algorithms](Algorithms-And-Data-Structures/00-02-00-Searching-Algorithms.md):** Линейно и двоично търсене (Binary Search).
  4. **[00-03. Sorting Algorithms](Algorithms-And-Data-Structures/00-03-00-Sorting-Algorithms.md):** Merge Sort, Quick Sort, Insertion/Selection Sort и стабилност.
  5. **[00-04. Greedy Algorithms](Algorithms-And-Data-Structures/00-04-00-Greedy-Algorithms.md):** Алчни стратегии и локален срещу глобален оптимум.
  6. **[00-05. Graphs & Traversal (BFS / DFS)](Algorithms-And-Data-Structures/00-05-00-Graphs-And-Traversal.md):** Представяне на графи, обхождане в ширина и дълбочина, най-кратки пътища.
  7. **[00-06. Dynamic Programming (DP)](Algorithms-And-Data-Structures/00-06-00-Dynamic-Programming.md):** Мемоизация (Top-Down), табулация (Bottom-Up) и класически задачи.

* **[04. Linux, Terminal & Bash Scripting (`Linux-And-Bash-Scripting/`)](Linux-And-Bash-Scripting/README.md)** *(Планирано разширение)*
  * *Обхваща:* Навигация във файловата система, права (`chmod`/`chown`), процеси, SSH и автоматизационни Bash скриптове.
