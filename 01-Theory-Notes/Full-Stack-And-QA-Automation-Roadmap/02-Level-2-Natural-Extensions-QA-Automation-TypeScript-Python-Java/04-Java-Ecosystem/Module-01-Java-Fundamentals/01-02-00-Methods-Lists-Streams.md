## 1. КАК ДА СЕ ЗАПОМНИ И ЧЕТЕ ПО-ЛЕСНО (МНЕМОНИКА)

*   **`ArrayList` в паметта (Разтеглив шкаф):** Под капака `ArrayList` е обикновен статичен масив `Object[]` с начален капацитет **10 клетки**. Когато запълниш и 10-тата клетка и добавиш 11-ти елемент, Java автоматично създава нов масив с **1.5 пъти по-голям размер (`10 -> 15 -> 22...`)** и прекопира всички стари елементи вътре.
*   **Stream API = Поточна линия във фабрика (Lazy Evaluation):**
    *   **Source (Източник):** Пускаш суровината на лентата (`list.stream()`).
    *   **Intermediate Operations (Междинни операции — `.filter()`, `.map()`, `.sorted()`):** Поставяш работници по лентата, но **лентата все още не се движи!** Те не правят нищо, докато не натиснеш зеления бутон.
    *   **Terminal Operation (Крайна операция — `.toList()`, `.forEach()`, `.count()`, `.sum()`):** Зеленият бутон, който пуска тока, прекарва елементите през всички работници наведнъж и затваря потока завинаги.

## 2. АРХИТЕКТУРА НА JAVA STREAM API (КОНВЕЙЕР И БЛОК-СХЕМА)

За разлика от циклите, Stream API обработва елементите **вертикално (един по един през целия конвейер)**, а не хоризонтално!

```text
Вход: List.of(1, 2, 3, 4, 5, 6)
          │
          ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ 1. .stream()          ➔ Създава поток (Source)                          │
└────────────────────────────────────┬────────────────────────────────────┘
                                     ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ 2. .filter(n -> n % 2 == 0) ➔ Междинна (Lazy: пропуска само 2, 4, 6)    │
└────────────────────────────────────┬────────────────────────────────────┘
                                     ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ 3. .map(n -> n * 10)        ➔ Междинна (Lazy: умножава 20, 40, 60)      │
└────────────────────────────────────┬────────────────────────────────────┘
                                     ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ 4. .toList()                ➔ КРАЙНА (Terminal: пуска тока и връща List)│
└─────────────────────────────────────────────────────────────────────────┘
```

## 3. АРХИТЕКТУРНО СРАВНЕНИЕ: JAVA LIST & STREAM API СРЕЩУ C# И PYTHON

| Концепция | Java 21+ (`List` & `Stream`) | C# 12+ (`List<T>` & `LINQ`) | Python 3.x (`list` & Comprehensions) |
| :--- | :--- | :--- | :--- |
| **Динамичен списък** | `List<Integer> list = new ArrayList<>();` | `var list = new List<int>();` | `items = []` |
| **Брой елементи** | `list.size()` (метод със скоби) | `list.Count` (Property) | `len(items)` |
| **Достъп / Промяна по индекс** | `list.get(i)` / `list.set(i, val)` | `list[i]` / `list[i] = val` | `items[i]` / `items[i] = val` |
| **Стартиране на заявка** | `list.stream()` (задължително!) | Директно `list.Where(...)` | `[x for x in items ...]` |
| **Филтриране** | `.filter(x -> x > 5)` | `.Where(x => x > 5)` | `[x for x in items if x > 5]` |
| **Трансформация** | `.map(x -> x * 2)` | `.Select(x => x * 2)` | `[x * 2 for x in items]` |
| **Материализиране в списък** | `.toList()` (Java 16+) | `.ToList()` | Директно връща `list` |
| **Първи елемент или Default** | `.findFirst().orElse(0)` | `.FirstOrDefault()` | `next((x for x in items), 0)` |

## 4. ПЛЮСОВЕ И МИНУСИ НА `ARRAYLIST` И STREAM API

### 🟢 Предимства (Pros):
*   **Светкавично четене по индекс в `ArrayList` ($O(1)$):** Благодарение на непрекъснатия масив под капака, `list.get(50000)` намира елемента за 1 процесорна инструкция.
*   **Кратък и декларативен код със Stream API:** Сложни вериги от филтриране, групиране и сортиране се четат като английско изречение, без вложени цикли и временни променливи.

### 🔴 Недостатъци (Cons):
*   **Бавно триене и вмъкване в началото/средата на `ArrayList` ($O(n)$):** Когато изтриеш елемент на индекс `0` (`list.remove(0)`), Java трябва да премести всички останали елементи с една позиция наляво.
*   **Еднократна употреба на Stream:** Веднъж затворен с терминална операция (`.toList()`), потокът умира — ако опиташ да го използваш втори път, хвърля `IllegalStateException: stream has already been operated upon or closed`.

## 5. КОДОВ ОДИТ: ПРАВИЛЕН СРЕЩУ ГРЕШЕН КОД

### ❌ ГРЕШЕН КОД (`list.remove(int)` капанът с претоварване и `ConcurrentModificationException`):
```java
List<Integer> numbers = new ArrayList<>(List.of(10, 20, 30));

// 🚨 ГРЕШКА 1 (Класически Java капан!):
// Искаш да изтриеш числото 20, но подаваш примитивен int!
// В List<Integer> има ДВА метода: remove(int index) и remove(Object o)!
// Java избира remove(int index) и се опитва да изтрие ИНДЕКС 20 -> IndexOutOfBoundsException!
numbers.remove(20); 

// 🚨 ГРЕШКА 2: Изтриване на елемент вътре в стандартен for-each цикъл -> ConcurrentModificationException!
for (Integer num : numbers) {
    if (num == 10) {
        numbers.remove(num);
    }
}
```
*   **Как да се избегне:** За да изтриеш конкретна цифра по стойност от `List<Integer>`, подай **`Integer.valueOf(20)`** или използвай модерния метод **`numbers.removeIf(n -> n == 20)`**, който трие безопасно без `ConcurrentModificationException`!

### 🟢 ПРАВИЛЕН КОД (Безопасно изтриване с `removeIf` и чист Stream конвейер):
```java
import java.util.ArrayList;
import java.util.List;

public class CleanListAndStream {
    public static void main(String[] args) {
        List<Integer> numbers = new ArrayList<>(List.of(10, 20, 30, 40, 50));

        // 1. Безопасно премахване на стойност 20 (без объркване с индекс)
        numbers.removeIf(n -> n == 20);

        // 2. Модерен Stream API конвейер (Java 16+)
        List<Integer> doubled = numbers.stream()
                .filter(n -> n > 15)
                .map(n -> n * 2)
                .toList(); // Връща непроменяем (Unmodifiable) списък: [60, 80, 100]

        System.out.println(doubled);
    }
}
```

## 6. ИНТЕРВЮ КАПАНИ, ВЪПРОСИ И УЛОВКИ

*   **Въпрос на интервюто:** *„Каква е разликата между `.collect(Collectors.toList())` и модерния метод `.toList()` (въведен в Java 16)?“*
*   **Уловката:** Кандидатите често ги мислят за напълно еднакви, но в продукция тази разлика води до `UnsupportedOperationException`!
*   **Точен Senior отговор:** 
    1.  **`stream.collect(Collectors.toList())`** връща стандартен, **изменяем `ArrayList`** — можеш спокойно да извикаш `.add()` или `.sort()` върху резултата по-късно в кода.
    2.  **`stream.toList()`** (Java 16+) връща **непроменяем (Unmodifiable) списък**, който **не позволява `null` елементи** и хвърля **`UnsupportedOperationException`**, ако някой опита да добави или премахне елемент от него. Ползвай `.toList()` за четене (Read-only), а `new ArrayList<>(stream.toList())`, ако ще го променяш.
