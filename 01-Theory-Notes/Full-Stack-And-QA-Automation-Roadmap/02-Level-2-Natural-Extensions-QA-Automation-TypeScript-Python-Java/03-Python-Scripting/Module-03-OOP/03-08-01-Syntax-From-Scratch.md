## 1. СТАНДАРТЕН ШАБЛОН ЗА ДЕКОРАТОР (КОПИРАЙ И ПОЛЗВАЙ)

Това е златният шаблон, който работи за всяка функция (с или без параметри и с или без `return`):

```python
from functools import wraps

def my_decorator(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        # 1. Код, който се изпълнява ПРЕДИ оригиналната функция
        print("--- Старт ---")
        
        # 2. Извикване на оригиналната функция
        result = func(*args, **kwargs)
        
        # 3. Код, който се изпълнява СЛЕД оригиналната функция
        print("--- Край ---")
        
        # 4. Връщане на оригиналния резултат
        return result
    return wrapper

@my_decorator
def greet(name: str):
    print(f"Здравей, {name}!")

greet("Елизабет")
```

## 2. ДЕКОРАТОР С ПАРАМЕТРИ (3 НИВА НА ФУНКЦИИ)

Когато искаш да подадеш настройка в самия декоратор (напр. `@repeat(times=3)`), обвиваш декоратора в още една външна функция:

```python
from functools import wraps

def repeat(times: int):                      # Ниво 1: Приема параметъра на декоратора
    def decorator(func):                     # Ниво 2: Приема самата функция
        @wraps(func)
        def wrapper(*args, **kwargs):        # Ниво 3: Приема аргументите на функцията
            result = None
            for _ in range(times):
                result = func(*args, **kwargs)
            return result
        return wrapper
    return decorator

@repeat(times=3)
def send_ping():
    print("PING!")

send_ping()  # Принтира "PING!" точно 3 пъти
```

## 3. ВГРАДЕНИ МОЩНИ ДЕКОРАТОРИ В СТАНДАРТНАТА БИБЛИОТЕКА (`@LRU_CACHE`)

Python има готови декоратори в модула `functools`, които спестяват писането на кеширащ код:

```python
from functools import lru_cache

# Автоматично кешира резултатите в RAM паметта според подадените аргументи!
@lru_cache(maxsize=128)
def fibonacci(n: int) -> int:
    if n < 2:
        return n
    return fibonacci(n - 1) + fibonacci(n - 2)

print(fibonacci(50))  # Изчислява се за 0.0001 сек. вместо да увисне за часове!
```

## 4. КЛАСОВ ДЕКОРАТОР (ИЗПОЛЗВАНЕ НА `__CALL__`)

Ако имплементираш магическия метод `__call__` в клас, инстанциите му могат да се извикват като функции и да служат като декоратори (удобно за броене на извиквания):

```python
class CallCounter:
    def __init__(self, func):
        self.func = func
        self.calls = 0

    def __call__(self, *args, **kwargs):
        self.calls += 1
        print(f"Извикване #{self.calls} на '{self.func.__name__}'")
        return self.func(*args, **kwargs)

@CallCounter
def save_record():
    print("Записано в базата.")

save_record()
save_record()
```

## 5. ОБОБЩЕНИЕ / БЪРЗ CHEAT SHEET

| Конструкция | Синтаксис | Какво прави |
| :--- | :--- | :--- |
| **Прилагане на декоратор** | `@my_decorator` над `def f():` | Заменя `f` с `my_decorator(f)` |
| **Запазване на метаданни** | `@functools.wraps(func)` | Запазва `__name__` и `__doc__` на оригинала |
| **Универсални аргументи** | `def wrapper(*args, **kwargs):` | Позволява декораторът да обвива всякакви функции |
| **Декоратор с аргументи** | `@retry(attempts=3)` | Изисква 3 вложени функции |
| **Вграден RAM кеш декоратор** | `@functools.lru_cache()` | Запомня резултатите от скъпи функции |
| **Обект, работещ като функция** | `def __call__(self, *args):` | Позволява на клас да бъде декоратор |
