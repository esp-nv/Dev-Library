## 1. ЗАПИСВАНЕ И ПРЕОБРАЗУВАНЕ НА ДВОИЧНИ ЧИСЛА

```python
# 1. Директно писане на двоично число (започва с префикс 0b)
binary_num = 0b1010         # В десетична система това е числото 10
print(binary_num)           # Изход: 10

# 2. Превръщане на обикновено число в двоичен текст чрез bin()
text_bits = bin(10)         # Изход: '0b1010'
clean_bits = bin(10)[2:]    # Изрязваме '0b' отпред -> '1010'

# 3. Превръщане на двоичен текст обратно в цяло число
number = int("1010", 2)     # Вторият аргумент (2) казва, че основата е двоична -> 10
```

## 2. ОСНОВНИТЕ 6 ПОБИТОВИ ОПЕРАТОРА В ДЕЙСТВИЕ

```python
a = 6   # Двоично: 0110
b = 3   # Двоично: 0011

print(a & b)    # AND (И):          0110 & 0011 = 0010 -> 2
print(a | b)    # OR (ИЛИ):         0110 | 0011 = 0111 -> 7
print(a ^ b)    # XOR (Различно):   0110 ^ 0011 = 0101 -> 5
print(~a)       # NOT (Обръщане):   -(6 + 1)          -> -7
print(a << 1)   # Left Shift:       0110 << 1   = 1100 -> 12 (умножава по 2)
print(a >> 1)   # Right Shift:      0110 >> 1   = 0011 -> 3  (дели на 2)
```

## 3. ГОТОВИ ШАБЛОНИ ЗА РАБОТА С КОНКРЕТЕН БИТ (ПОЗИЦИЯ P)

Позициите на битовете се броят **отдясно наляво, започвайки от `0`** (най-десният бит е на позиция `0`).

```python
number = 10     # Двоично: 1010 (Позиции: [3]=1, [2]=0, [1]=1, [0]=0)
pos = 1         # Искаме да проверим или променим бит на позиция 1

# 1. ВЗЕМАНЕ НА СТОЙНОСТТА НА БИТ (0 или 1) на позиция 'pos'
bit_value = (number >> pos) & 1
print(f"Битът на позиция {pos} е: {bit_value}")     # Изход: 1

# 2. ВДИГАНЕ НА БИТ (Setting a bit -> прави го 1)
set_bit = number | (1 << pos)

# 3. СВАЛЯНЕ НА БИТ (Clearing a bit -> прави го 0)
clear_bit = number & ~(1 << pos)                    # 1010 става 1000 -> числото 8

# 4. ОБРЪЩАНЕ НА БИТ (Toggling a bit -> от 0 в 1 или от 1 в 0)
toggle_bit = number ^ (1 << pos)
```

## 4. БЪРЗИ ПОБИТОВИ ТРИКОВЕ ЗА ЗАДАЧИ

```python
num = 7

# 1. Проверка за четно или нечетно число (гледа най-десния бит)
is_odd = (num & 1) == 1         # True за нечетно, False за четно

# 2. Размяна на две числа без трета променлива чрез XOR
x, y = 15, 25
x ^= y
y ^= x
x ^= y
print(f"x = {x}, y = {y}")      # Изход: x = 25, y = 15
```

## 5. ОБОБЩЕНИЕ / БЪРЗ CHEAT SHEET

| Операция | Синтаксис | Какво прави |
| :--- | :--- | :--- |
| **Число ➔ Двоичен текст** | `bin(x)[2:]` | Връща битовете без `'0b'` |
| **Двоичен текст ➔ Число** | `int("101", 2)` | Връща десетичното число `5` |
| **Проверка за нечетно** | `(n & 1) == 1` | Проверява последния бит |
| **Умножение / Деление на $2^k$** | `n << k` / `n >> k` | Измества битовете с `k` позиции |
| **Вземи бит на позиция `p`** | `(n >> p) & 1` | Връща `0` или `1` |
| **Направи бит `1` на позиция `p`** | `n \| (1 << p)` | Вдига бита на позиция `p` |
| **Направи бит `0` на позиция `p`** | `n & ~(1 << p)` | Нулира бита на позиция `p` |
| **Обърни бит на позиция `p`** | `n ^ (1 << p)` | Сменя `0 <-> 1` на позиция `p` |
