## 1. СЪЗДАВАНЕ И ДОСТЪП ДО СТОЙНОСТИ

Речниците се ограждат с **фигурни скоби `{}`**, а елементите се записват като двойки **`ключ: стойност`**, разделени със запетая.

```python
# Създаване на празен и запълнен речник
empty_dict = {}
student = {
    "name": "Мария",
    "age": 22,
    "courses": ["Python", "SQL"]
}

# 1. Директен достъп (ако ключът го няма -> гърми с KeyError)
print(student["name"])                  # Изход: Мария

# 2. Безопасен достъп с .get() (ако ключът го няма -> връща None или посочена стойност)
print(student.get("age"))               # Изход: 22
print(student.get("phone", "Няма"))     # Изход: Няма (вместо грешка!)
```

## 2. ДОБАВЯНЕ, ПРОМЯНА И ИЗТРИВАНЕ НА ЕЛЕМЕНТИ

```python
config = {"host": "localhost", "port": 8080}

# ДОБАВЯНЕ И ПРОМЯНА (Синтаксисът е напълно еднакъв!)
config["port"] = 5000           # Ключът 'port' съществува -> ПРЕЗАПИСВА стойността му
config["ssl"] = True            # Ключът 'ssl' липсва -> ДОБАВЯ нов ключ в речника

# ПРОВЕРКА ЗА НАЛИЧИЕ НА КЛЮЧ
if "ssl" in config:
    print("SSL е конфигуриран!")

# ИЗТРИВАНЕ
removed_port = config.pop("port")   # Изтрива ключа 'port' и връща стойността му (5000)
del config["host"]                  # Изтрива ключа 'host' директно от паметта
config.clear()                      # Изпразва целия речник -> {}
```

## 3. ОБХОЖДАНЕ С ЦИКЛИ (KEYS, VALUES, ITEMS)

```python
prices = {"кафе": 2.50, "чай": 1.80, "вода": 1.20}

# 1. Само по ключове
for product in prices.keys():
    print(product)

# 2. Само по стойности
for price in prices.values():
    print(price)

# 3. И ключ, и стойност едновременно (Най-използваният начин!)
for product, price in prices.items():
    print(f"Продукт: {product} -> Цена: {price:.2f} лв.")
```

## 4. ВЛОЖЕНИ РЕЧНИЦИ (NESTED DICTIONARIES) И COMPREHENSIONS

```python
# А. Вложен речник (изглежда точно като JSON структура)
users_db = {
    "user_1": {"name": "Иван", "role": "Admin"},
    "user_2": {"name": "Елена", "role": "User"}
}

# Достъп до вложена стойност (верижно с квадратни скоби)
print(users_db["user_1"]["role"])   # Изход: Admin

# Б. Dictionary Comprehension (бързо създаване на речник на един ред)
numbers = [1, 2, 3, 4]
squares_dict = {n: n ** 2 for n in numbers}
# Резултат: {1: 1, 2: 4, 3: 9, 4: 16}
```

## 5. ОБОБЩЕНИЕ / БЪРЗ CHEAT SHEET

| Действие | Синтаксис | Пример / Резултат |
| :--- | :--- | :--- |
| **Създаване на речник** | `d = {"k": "v"}` | Фигурни скоби `{}` и двоеточие `:` |
| **Безопасно четене** | `d.get("k", default)` | Не гърми при липсващ ключ |
| **Добавяне / Промяна** | `d["k"] = new_val` | Ако го има променя, ако го няма добавя |
| **Проверка за ключ** | `if "k" in d:` | Търси само сред ключовете (O(1)) |
| **Изтриване на ключ** | `d.pop("k")` | Трие ключа и връща стойността му |
| **Обхождане (Ключ + Стойност)** | `for k, v in d.items():` | Разопакова всяка двойка в цикъла |
| **Всички ключове / стойности** | `d.keys()` / `d.values()` | Връща изглед към ключовете или стойностите |
| **Обединяване на 2 речника** | `d1 \| d2` (Python 3.9+) | Връща нов обединен речник |
