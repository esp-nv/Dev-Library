## 1. ОСНОВНИ ТИПОВЕ ДАННИ (СЪЗДАВАНЕ)

```python
# 1. Числови типове
count = 42                  # int (цяло число)
big_number = 1_000_000      # Можеш да слагаш долни черти за по-лесно четене (равно на 1000000)
price = 12.50               # float (дробно число)

# 2. Текстов тип (str)
single_line = "Здравей"
multi_line = """Ред първи
Ред втори"""

# 3. Логически и празни типове
is_ready = True             # bool (True или False с главна буква)
nothing = None              # NoneType (празна стойност)
```

## 2. АРИТМЕТИЧНИ ОПЕРАТОРИ И СПЕЦИФИКИ

В Python делението има два различни оператора, което е много важно за запомняне:

```python
a = 10
b = 3

print(a + b)    # Събиране -> 13
print(a - b)    # Изваждане -> 7
print(a * b)    # Умножение -> 30
print(a / b)    # Обикновено деление (ВИНАГИ връща float!) -> 3.3333333333333335
print(a // b)   # Целочислено деление (отрязва дробната част) -> 3
print(a % b)    # Остатък от деление (модулно деление) -> 1
print(a ** b)   # Степенуване (10 на 3-та степен) -> 1000
```

## 3. ПРЕОБРАЗУВАНЕ НА ТИПОВЕ (TYPE CASTING)

Когато четеш данни от потребителя или от файл, те идват като текст (`str`). Ето как се преобразуват:

```python
text_num = "25"
number = int(text_num)          # Текст -> Цяло число (25)
decimal_num = float("25.75")    # Текст -> Дробно число (25.75)

age = 30
age_as_text = str(age)          # Число -> Текст ("30")

# Проверка какъв е типът в момента
print(type(number))             # Изход: <class 'int'>
print(isinstance(number, int))  # Изход: True
```

## 4. МНОЖЕСТВЕНО ПРИСВОЯВАНЕ И РАЗМЯНА НА СТОЙНОСТИ

Python позволява много елегантен синтаксис за работа с няколко променливи на един ред:

```python
# Едновременно задаване на различни стойности
x, y, z = 10, 20, "Готово"

# Задаване на една и съща стойност на няколко променливи
a = b = c = 0

# Размяна на стойностите на две променливи (без временна променлива temp!)
first = 5
second = 99
first, second = second, first
print(f"first = {first}, second = {second}")  # Изход: first = 99, second = 5
```

## 5. ВЛОЖЕНИ ПРОВЕРКИ С ТИПОВЕ И FALSY СТОЙНОСТИ

В Python следните стойности автоматично се считат за **`False`** в `if` проверка: `0`, `0.0`, `""` (празен текст), `[]` (празен списък) и `None`. Всичко останало е `True`.

```python
user_input = ""

if user_input is not None:
    # Ниво 1: Променливата не е None
    if user_input:
        # Ниво 2: Текстът не е празен (Truthy)
        print(f"Въведен текст: {user_input}")
    else:
        # Ниво 2: Текстът е празен "" (Falsy)
        print("Внимание: Полето е оставено празно!")
```

## 6. ОБОБЩЕНИЕ / БЪРЗ CHEAT SHEET

| Операция | Синтаксис | Резултат / Пример |
| :--- | :--- | :--- |
| **Обикновено деление** | `10 / 2` | `5.0` (винаги `float`) |
| **Целочислено деление** | `10 // 3` | `3` (цяло число `int`) |
| **Степенуване** | `2 ** 3` | `8` |
| **Превръщане в int / float / str** | `int(x)`, `float(x)`, `str(x)` | `int("5")` -> `5` |
| **Проверка за `None`** | `if x is None:` | Винаги с `is`, не с `==` |
| **Проверка на тип** | `isinstance(x, int)` | Връща `True` или `False` |
| **Размяна на 2 променливи** | `a, b = b, a` | Разменя стойностите на един ред |
| **Четливост на големи числа** | `1_000_000` | Равно на `1000000` |
