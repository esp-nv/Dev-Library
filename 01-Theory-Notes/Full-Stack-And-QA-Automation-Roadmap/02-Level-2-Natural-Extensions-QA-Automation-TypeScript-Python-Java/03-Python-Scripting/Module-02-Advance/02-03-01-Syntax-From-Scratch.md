## 1. СЪЗДАВАНЕ И ЧЕТЕНЕ НА МАТРИЦА ОТ КОНЗОЛАТА

```python
# 1. Ръчно дефиниране на матрица 3x3
grid = [,
 ,
    [7, 8, 9]
]

# 2. Създаване на празна матрица с размери R реда и C колони
rows, cols = 3, 4
zeros_matrix = [[0 for _ in range(cols)] for _ in range(rows)]

# 3. Стандартно четене на матрица от конзолата (най-честият изпитен шаблон!)
# Пример вход:
# 2
# 10 20 30
# 40 50 60
n = int(input())
matrix = []
for _ in range(n):
    row_data = [int(x) for x in input().split()]
    matrix.append(row_data)
```

## 2. ДОСТЪП И ПРОМЯНА НА КЛЕТКИ

```python
board = [
    ["X", "O", "X"],
    ["O", "X", "O"],
    ["-", "-", "X"]
]

# Четене: matrix[ред][колона]
center_cell = board[1][1]       # Изход: "X"
bottom_left = board[2][0]       # Изход: "-"

# Промяна на стойност в клетка
board[2][0] = "O"               # Заменя "-" с "O"
```

## 3. ВЛОЖЕНИ ЦИКЛИ ЗА ОБХОЖДАНЕ И ПРИНТИРАНЕ

```python
matrix = [,
    [30, 40]
]

# 1. Обхождане по индекси (когато ти трябват координатите row и col)
for row in range(len(matrix)):
    for col in range(len(matrix[row])):
        print(f"Клетка [{row}][{col}] = {matrix[row][col]}")

# 2. Чисто принтиране на матрицата ред по ред
for row in matrix:
    print(" ".join(str(x) for x in row))
```

## 4. ШАБЛОН ЗА ДВИЖЕНИЕ В 4 ПОСОКИ (ИГРИ И ЛАБИРИНТИ)

При задачи за движение на играч по дъска най-чистият начин е да използваш речник с посоки и функция за проверка дали новите координати са вътре в дъската.

```python
directions = {
    "up": (-1, 0),
    "down": (1, 0),
    "left": (0, -1),
    "right": (0, 1)
}

def is_inside(row, col, size):
    return 0 <= row < size and 0 <= col < size

# Примерна стъпка надолу от позиция (1, 1) в матрица 3x3
curr_r, curr_c = 1, 1
move_r, move_c = directions["down"]
next_r, next_c = curr_r + move_r, curr_c + move_c

if is_inside(next_r, next_c, 3):
    print(f"Валиден ход към [{next_r}, {next_c}]")
```

## 5. ОБОБЩЕНИЕ / БЪРЗ CHEAT SHEET

| Операция | Синтаксис | Пример / Бележка |
| :--- | :--- | :--- |
| **Създаване на матрица R x C** | `[[0 for _ in range(C)] for _ in range(R)]` | Избягва споделените референции |
| **Достъп до клетка** | `m[row][col]` | Първо редът, после колоната |
| **Брой редове / колони** | `len(m)` / `len(m[0])` | За квадратна или правоъгълна матрица |
| **Главен диагонал** | `m[i][i]` | За `i` от `0` до `n - 1` |
| **Второстепенен диагонал** | `m[i][n - 1 - i]` | От горе вдясно до долу вляво |
| **Изравняване (Flatten 2D ➔ 1D)** | `[x for row in m for x in row]` | Превръща матрицата в обикновен списък |
| **Транспониране (Ред ➔ Колона)** | `[list(r) for r in zip(*m)]` | Обръща редовете и колоните |
| **Проверка за валидни граници** | `0 <= r < rows and 0 <= c < cols` | Защита против `IndexError` |
