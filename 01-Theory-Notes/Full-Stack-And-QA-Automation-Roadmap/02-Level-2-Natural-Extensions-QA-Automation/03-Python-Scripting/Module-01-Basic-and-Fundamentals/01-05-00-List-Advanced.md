## 1. КАК ДА СЕ ЗАПОМНИ И ЧЕТЕ ПО-ЛЕСНО (МНЕМОНИКА)

*   **List Comprehension като мини-LINQ в C#:** Представи си го като обърнат `Select` и `Where` от C#, затворен в квадратни скоби `[]`. Формулата е: **`[какво_искам for елемент in списък if условие]`**. Чете се като изречение: *„Направи ми списък от `x * 2` за всяко `x` в числата, ако `x` е четно“*.
*   **Slicing (Рязане):** Синтаксисът `list[start:stop:step]` работи точно като `range()` — началото се включва, краят **никога не се включва**, а стъпката `-1` обръща целия списък наопаки.

## 2. ЕТАПИ НА ИЗПЪЛНЕНИЕ НА LIST COMPREHENSION И БЛОК-СХЕМА

Вътрешно List Comprehension не е просто синтактична захар, а се компилира до оптимизиран C-цикъл в паметта на Python, който избягва многократните извиквания на `.append()`.

```text
Израз: [x * 10 for x in nums if x > 5]

┌──────────────────────────┐
│ 1. Вземи следващ x от    │
│    колекцията 'nums'     │
└────────────┬─────────────┘
             │
             ▼
      ┌─────────────┐      НЕ (False)     ┌─────────────────────────┐
      │ Провери:    │ ──────────────────► │ Пропусни елемента       │
      │ if x > 5 ?  │                     │ (Върни се на Стъпка 1)  │
      └──────┬──────┘                     └─────────────────────────┘
             │ ДА (True)
             ▼
┌──────────────────────────┐     4. Добави в новия      ┌─────────────────────────┐
│ 3. Изчисли израза:       │ ─────────────────────────► │ 5. Готов нов списък     │
│    x * 10                │    резултатен списък       │    в RAM паметта        │
└──────────────────────────┘                            └─────────────────────────┘
```

## 3. АРХИТЕКТУРНО СРАВНЕНИЕ: PYTHON СРЕЩУ C# И JAVASCRIPT

| Операция | Python 3.x | C# (LINQ) | JavaScript (ES6+) |
| :--- | :--- | :--- | :--- |
| **Трансформация (Map)** | `[x * 2 for x in nums]` | `nums.Select(x => x * 2).ToList()` | `nums.map(x => x * 2)` |
| **Филтриране (Filter)** | `[x for x in nums if x > 0]` | `nums.Where(x => x > 0).ToList()` | `nums.filter(x => x > 0)` |
| **Изрязване (Slice)** | `nums[1:4]` | `nums.Skip(1).Take(3).ToList()` | `nums.slice(1, 4)` |
| **Обръщане на списък** | `nums[::-1]` | `nums.AsEnumerable().Reverse()` | `[...nums].reverse()` |
| **Проверка за всички** | `all(x > 0 for x in nums)` | `nums.All(x => x > 0)` | `nums.every(x => x > 0)` |

## 4. ПЛЮСОВЕ И МИНУСИ НА LIST COMPREHENSIONS

### 🟢 Предимства (Pros):
*   **По-висока скорост от стандартен `for` цикъл:** Изпълнява се на ниско ниво в C-ядрото на Python и е с около 20-30% по-бързо от ръчно пълнене с `.append()`.
*   **Кристална четимост при прости трансформации:** Заменя 5-6 реда код с един ясен, декларативен ред.

### 🔴 Недостатъци (Cons):
*   **Трудно четене при вложени конструкции:** Ако вкараш 2-3 вложени `for` цикъла и сложни `if-else` проверки в един Comprehension, кодът става неразчитаем и кошмарен за дебъгване.
*   **Заделя цялата памет веднага:** Създава целия нов списък в RAM паметта наведнъж. При милиони записи трябва да се използват Generator Expressions `(...)` вместо квадратни скоби `[...]`.

## 5. КОДОВ ОДИТ: ПРАВИЛЕН СРЕЩУ ГРЕШЕН КОД (И КОМЕНТАРИ)

### ❌ ГРЕШЕН КОД (Претрупан Comprehension и грешно място на `else`):
```python
nums =

# 🚨 ГРЕШКА 1: Грешен синтаксис при използване на 'else' (хвърля SyntaxError!)
# Когато има 'else', проверката се мести ПРЕДИ 'for', а не в края!
# wrong = [x for x in nums if x % 2 == 0 else 0]  -> SyntaxError!

# 🚨 ГРЕШКА 2: Сложен, нечетим вложен израз
unreadable = [x * y for x in range(10) if x % 2 == 0 for y in range(10) if y > 5 and x != y]
```
*   **Как да се избегне:** Правилото за `if` в Comprehension е:
    *   Само `if` (филтриране) ➔ отива **в края**: `[x for x in nums if x > 0]`
    *   `if` + `else` (трансформация) ➔ отива **в началото**: `[x if x > 0 else 0 for x in nums]`

### 🟢 ПРАВИЛЕН КОД (Чист Pythonic стандарт):
```python
raw_scores = [45, 82, 91, 30, 76, 100]

# 1. Филтриране на успешните оценки (само if -> в края)
passed_scores = [score for score in raw_scores if score >= 50]

# 2. Трансформация с if-else (заменяме слабите оценки с "Поправителен" -> в началото)
status_list = [f"Взел ({s})" if s >= 50 else "Поправителен" for s in raw_scores]

# 3. Изрязване на топ 3 резултата след сортиране в низходящ ред
top_three = sorted(passed_scores, reverse=True)[:3]

print(f"Успешни оценки: {passed_scores}")
print(f"Статуси:        {status_list}")
print(f"Топ 3 резултата: {top_three}")
```
*   **Изход в конзолата:**
    ```text
    Успешни оценки: [82, 91, 76, 100]
    Статуси:        ['Поправителен', 'Взел (82)', 'Взел (91)', 'Поправителен', 'Взел (76)', 'Взел (100)']
    Топ 3 резултата: [100, 91, 82]
    ```

## 6. ИНТЕРВЮ КАПАНИ, ВЪПРОСИ И УЛОВКИ

*   **Въпрос на интервюто:** *„Каква е разликата между Shallow Copy (`list.copy()` или `list[:]`) и Deep Copy (`copy.deepcopy(list)`) при вложени списъци (матрици)?“*
*   **Уловката:** Кандидатите знаят, че `.copy()` прави нов списък, но забравят, че вътрешните елементи са референции!
*   **Точен Senior отговор:** 
    *   **Shallow Copy (Повърхностно копие):** Създава нов външен списък, но **вътрешните вложени списъци продължават да сочат към абсолютно същите адреси в паметта**. Ако промениш `copy_matrix[0][0] = 999`, ще се промени и оригиналната матрица!
    *   **Deep Copy (Дълбоко копие):** Импортира се от вградения модул `import copy` (`copy.deepcopy(matrix)`). То обхожда рекурсивно цялото дърво и създава напълно нови, независими копия на всеки един вложен обект в RAM паметта.
