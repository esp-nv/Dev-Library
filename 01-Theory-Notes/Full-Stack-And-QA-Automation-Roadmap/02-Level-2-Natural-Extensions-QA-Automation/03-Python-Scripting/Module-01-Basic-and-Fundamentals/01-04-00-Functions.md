## 1. КАК ДА СЕ ЗАПОМНИ И ЧЕТЕ ПО-ЛЕСНО (МНЕМОНИКА)

*   **Ключовата дума `def`:** Съкращение от *define* (дефинирам). В C# пишеш `public int Add(int a, int b)`, в JS пишеш `function add(a, b)`, а в Python просто казваш `def add(a, b):`.
*   **Първокласни обекти (First-Class Citizens):** В Python функциите са обикновени обекти в паметта, точно като числата и текстовете. Можеш да ги запазиш в променлива, да ги сложиш в списък или да ги подадеш като аргумент на друга функция (като делегатите и `Func<>` в C#).

## 2. ЕТАПИ НА ТЪРСЕНЕ НА ПРОМЕНЛИВИ (LEGB SCOPE) И БЛОК-СХЕМА

Когато използваш име на променлива вътре във функция, Python я търси в оперативната памет строго в следния четиристепенен ред (**LEGB Rule**):

```text
┌─────────────────────────────────────────────────────────────┐
│ 1. L (Local)     ➔ Вътре в самата текуща функция            │
└──────────────────────────────┬──────────────────────────────┘
                               │ Ако я няма...
                               ▼
┌─────────────────────────────────────────────────────────────┐
│ 2. E (Enclosing) ➔ В обгръщащата външна функция (Nested)     │
└──────────────────────────────┬──────────────────────────────┘
                               │ Ако я няма...
                               ▼
┌─────────────────────────────────────────────────────────────┐
│ 3. G (Global)    ➔ На ниво файл / модул (най-отгоре)        │
└──────────────────────────────┬──────────────────────────────┘
                               │ Ако я няма...
                               ▼
┌─────────────────────────────────────────────────────────────┐
│ 4. B (Built-in)  ➔ Вградените имена на Python (print, len)  │
└─────────────────────────────────────────────────────────────┘
```

## 3. АРХИТЕКТУРНО СРАВНЕНИЕ: PYTHON СРЕЩУ C# И JAVASCRIPT

| Характеристика | Python 3.x | C# (.NET) | JavaScript (ES6+) |
| :--- | :--- | :--- | :--- |
| **Дефиниране** | `def func_name(a, b):` | `void FuncName(int a, int b)` | `function funcName(a, b)` |
| **Липсващ `return`** | Автоматично връща `None` | Изисква `void` (не връща нищо) | Автоматично връща `undefined` |
| **Подаване по име** | `func(b=10, a=5)` (Keyword args) | `Func(b: 10, a: 5)` (Named args) | Не се поддържа директно (ползват се обекти) |
| **Множество резултати** | `return x, y` (връща Tuple) | `return (x, y);` (ValueTuple) | `return [x, y];` или `{x, y}` |
| **Анонимна функция** | `lambda x: x * 2` (само 1 ред!) | `x => x * 2` (многоредови) | `x => x * 2` (многоредови) |

## 4. ПЛЮСОВЕ И МИНУСИ НА ФУНКЦИИТЕ В PYTHON

### 🟢 Предимства (Pros):
*   **Връщане на няколко стойности едновременно:** С `return status, message` лесно връщаш пакет от резултати без да пишеш специални DTO класове.
*   **Гъвкави аргументи (`*args` и `**kwargs`):** Една функция може да приеме неограничен брой позиционни или именувани параметри.

### 🔴 Недостатъци (Cons):
*   **Ограничени `lambda` функции:** За разлика от C# и JS, в Python анонимните ламбда функции могат да съдържат **само един-единствен израз** (не можеш да пишеш цикли или многоредови проверки вътре).
*   **Липса на Method Overloading:** Не можеш да дефинираш две функции с едно и също име и различен брой параметри във един файл — втората директно пренаписва и изтрива първата от паметта.

## 5. КОДОВ ОДИТ: ПРАВИЛЕН СРЕЩУ ГРЕШЕН КОД (И КОМЕНТАРИ)

### ❌ ГРЕШЕН КОД (Забравен return и модификация на глобална променлива):
```python
# 🚨 ГРЕШКА 1: Функция, която само печата, но не връща резултат
def add_numbers(a, b):
    print(a + b) # Извежда 15 на екрана, но функцията връща None!

result = add_numbers(10, 5)
# total = result + 10 -> Хвърля TypeError: unsupported operand type(s) for +: 'NoneType' and 'int'

# 🚨 ГРЕШКА 2: Промяна на глобална променлива без ключова дума global
counter = 0
def increment():
    # counter += 1 -> Хвърля UnboundLocalError: cannot access local variable 'counter'
    pass
```
*   **Как да се избегне:** Функциите за бизнес логика трябва винаги да връщат данни с `return`, а печатането с `print()` да се оставя извън тях. Избягвай глобални променливи — подавай данните като аргументи.

### 🟢 ПРАВИЛЕН КОД (Чист Pythonic стандарт с чисти функции):
```python
# Функция с Type Hints, стойност по подразбиране и ясен return
def calculate_final_price(price: float, discount_percent: float = 0.0) -> float:
    if price < 0:
        return 0.0
    
    discount_amount = price * (discount_percent / 100)
    return round(price - discount_amount, 2)

# Извикване с позиционни и именувани (Keyword) аргументи
price_standard = calculate_final_price(100.0)
price_promo = calculate_final_price(price=100.0, discount_percent=15.0)

print(f"Стандартна цена: {price_standard} лв.")
print(f"Промо цена:      {price_promo} лв.")
```
*   **Изход в конзолата:**
    ```text
    Стандартна цена: 100.0 лв.
    Промо цена:      85.0 лв.
    ```

## 6. ИНТЕРВЮ КАПАНИ, ВЪПРОСИ И УЛОВКИ

*   **Въпрос на интервюто:** *„Какъв е най-известният капан в Python при задаване на списък или речник като стойност по подразбиране в аргумент на функция (Mutable Default Arguments)?“*
*   **Уловката:** Програмистите пишат `def add_item(item, target_list=[]):`, очаквайки при всяко извикване без втори аргумент да се създава нов празен списък.
*   **Точен Senior отговор:** Стойностите по подразбиране в Python се изчисляват **само веднъж — в момента на дефиниране на функцията**, а не при всяко нейно извикване! Това означава, че празният списък `[]` се създава един-единствен път в RAM паметта и се споделя между всички бъдещи извиквания на функцията, трупайки стари данни като скрит кеш.
    *   **Правилен фикс:** Винаги слагай `None` по подразбиране и инициализирай списъка вътре в тялото:
        ```python
        def add_item_safe(item: str, target_list: list | None = None) -> list:
            if target_list is None:
                target_list = []
            target_list.append(item)
            return target_list
        ```
