# 01-00-a. Базов Синтаксис на Python от нулата (Първи стъпки & Cheat Sheet)

**Цел:** Точни шаблони за писане на първите редове код в Python от нулата, работа с вложени структури и бърза справочна таблица.

## 1. КОМЕНТАРИ В КОДА

Коментарите се игнорират от Python при изпълнение.

```python
# Това е едноредов коментар (започва с диез #)

"""
Това е многоредов коментар.
Използва се за по-дълги обяснения или документация.
"""
```

---

## 2. ДЕКЛАРИРАНЕ НА ПРОМЕНЛИВИ

В Python **няма** ключови думи като `var`, `let`, `const`, `int` или `string`. Просто пишеш името на променливата и слагаш стойност.

```python
# Име на променлива = стойност
name = "Елизабет"       # Текст (str) - може с двойни "" или единични '' кавички
age = 25                # Цяло число (int)
grade = 5.85            # Дробно число (float) - винаги с точка, не със запетая
is_student = True       # Булева стойност (bool) - ЗАДЪЛЖИТЕЛНО с главна буква (True / False)
empty_value = None      # Празно / липсващо значение (еквивалент на null в C# и JS)
```
* **Правило за именуване:** В Python променливите и функциите се пишат с малки букви и долна черта (`snake_case`), например `user_first_name = "Иван"`.

## 3. ВХОД И ИЗХОД В КОНЗОЛАТА (INPUT И PRINT)

```python
# 1. ПЕЧАТАНЕ В КОНЗОЛАТА (Изход)
print("Здравей, свят!")

# Форматиран текст (f-string) - слага се буквата f преди кавичките и {променлива} вътре
print(f"Име: {name}, Възраст: {age}")

# 2. ЧЕТЕНЕ ОТ КОНЗОЛАТА (Вход)
# ВАЖНО: input() ВИНАГИ връща текст (str), дори потребителят да напише число!
user_name = input("Въведи име: ")

# Ако искаш число от конзолата, трябва да го преобразуваш изрично с int() или float()
user_age = int(input("Въведи години: "))
product_price = float(input("Въведи цена: "))
```

## 4. УСЛОВНИ КОНСТРУКЦИИ (IF / ELIF / ELSE И ВЛОЖЕНИ ПРОВЕРКИ)

Вместо скоби `{ }`, Python използва **двоеточие `:`** в края на условието и **4 интервала отстъп (Tab)** за кода вътре.

### А. Стандартна проверка
```python
score = 85

if score >= 90:
    # 4 интервала навътре -> принадлежи на if
    print("Отличен (6)")
elif score >= 75:
    # elif означава "else if"
    print("Много добър (5)")
elif score >= 50:
    print("Добър (4)")
else:
    # Изпълнява се, ако нито едно горно условие не е вярно
    print("Слаб (2)")
```

### Б. Вложени условни конструкции (Nested `if`)
Когато имаш проверка вътре в друга проверка, вътрешният код получава **още 4 интервала отстъп** (общо 8 интервала от левия ръб).

```python
has_ticket = True
age = 20

if has_ticket:
    # 4 интервала навътре (Ниво 1)
    print("Билетът е валиден.")
    
    if age >= 18:
        # 8 интервала навътре (Ниво 2 - вложено условие)
        print("Достъпът до залата е разрешен.")
    else:
        # 8 интервала навътре
        print("Необходим е придружител.")
else:
    # 4 интервала навътре
    print("Нямате билет. Достъпът е отказан.")
```

## 5. ЦИКЛИ (FOR, WHILE И ВЛОЖЕНИ ЦИКЛИ)

### А. Цикъл `for` с числа (`range`)
```python
# Вариант 1: От 0 до 4 (общо 5 пъти). Числото 5 НЕ се включва!
for i in range(5):
    print(i)  # Извежда: 0, 1, 2, 3, 4

# Вариант 2: От 1 до 5 включително -> range(начало, край + 1)
for i in range(1, 6):
    print(i)  # Извежда: 1, 2, 3, 4, 5

# Вариант 3: Със стъпка (от 0 до 10 през 2) -> range(начало, край, стъпка)
for i in range(0, 11, 2):
    print(i)  # Извежда: 0, 2, 4, 6, 8, 10
```

### Б. Цикъл `for` върху текст или списък
```python
word = "Python"

# Взима буква по буква автоматично
for letter in word:
    print(letter)
```

### В. Цикъл `while` (върти, докато условието е True)
```python
count = 1

while count <= 3:
    print(f"Стъпка {count}")
    count += 1  # Увеличава count с 1 (в Python НЯМА count++)
```

### Г. Вложени цикли (Nested Loops)
Вътрешният цикъл се завърта изцяло за всяка една стъпка на външния цикъл. Отново се спазва правилото за **+4 интервала навътре** (общо 8 интервала за тялото на вътрешния цикъл).

```python
# Пример: Принтиране на координати (Ред и Колона)
for row in range(1, 3):          # Външен цикъл (Редове 1 и 2)
    for col in range(1, 4):      # Вътрешен цикъл (Колони 1, 2 и 3) - 4 интервала
        # 8 интервала навътре
        print(f"Клетка [{row}, {col}]")
```
*   **Изход в конзолата:**
    ```text
    Клетка [1, 1]
    Клетка [1, 2]
    Клетка [1, 3]
    Клетка [2, 1]
    Клетка [2, 2]
    Клетка [2, 3]
    ```

## 6. ОБОБЩЕНИЕ / БЪРЗ CHEAT SHEET

| Какво искаш да направиш | Синтаксис в Python | Пример |
| :--- | :--- | :--- |
| **Деклариране на променлива** | `име = стойност` | `total = 100` |
| **Булеви и празни стойности** | `True` / `False` / `None` | `is_valid = False` |
| **Четене на текст / число** | `input()` / `int(input())` | `age = int(input())` |
| **Печатане с променливи** | `print(f"... {променлива}")` | `print(f"Резултат: {total}")` |
| **Условие (If / Else if / Else)** | `if ...:` / `elif ...:` / `else:` | `if x > 0:` |
| **Логически оператори** | `and` / `or` / `not` | `if x > 0 and y > 0:` |
| **Цикъл от 0 до N-1** | `for i in range(N):` | `for i in range(5):` |
| **Цикъл от A до B включително** | `for i in range(A, B + 1):` | `for i in range(1, 6):` |
| **Увеличаване на брояч** | `x += 1` (няма `x++`) | `count += 1` |
| **Вложени блокове** | `+4 интервала` за всяко ниво | Ниво 1: `4`, Ниво 2: `8` интервала |
