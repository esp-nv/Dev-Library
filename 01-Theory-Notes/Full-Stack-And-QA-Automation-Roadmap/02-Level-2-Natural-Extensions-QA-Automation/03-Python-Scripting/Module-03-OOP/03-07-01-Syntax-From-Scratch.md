## 1. СЪЗДАВАНЕ НА ГЕНЕРАТОРНА ФУНКЦИЯ (`YIELD`)

Всяка функция, която съдържа ключовата дума **`yield`**, автоматично се превръща в генератор.

```python
def countdown(start: int):
    while start > 0:
        yield start         # Подава числото и замразява функцията тук
        start -= 1

# 1. Инициализиране на генератора
timer = countdown(3)

# 2. Ръчно извикване стъпка по стъпка с вградената функция next()
print(next(timer))          # Изход: 3
print(next(timer))          # Изход: 2
print(next(timer))          # Изход: 1
# print(next(timer))        # На 4-тия път ще хвърли StopIteration!
```

## 2. ГЕНЕРАТОРНИ ИЗРАЗИ (GENERATOR EXPRESSIONS С КРЪГЛИ СКОБИ)

Синтаксисът е същият като при List Comprehension, но вместо `[ ]` се слагат **кръгли скоби `( )`**. Не заделя памет за списък!

```python
# Създава генератор за квадратите на числата от 0 до 999 999 (заема 0 MB RAM!)
lazy_squares = (x ** 2 for x in range(1_000_000))

# Можеш да го подадеш директно на функции като sum(), max(), min()
total = sum(x for x in range(1, 101))   # Сумата от 1 до 100 -> 5050
```

## 3. СЪЗДАВАНЕ НА СОБСТВЕН КЛАСОВ ИТЕРАТОР (`__ITER__` И `__NEXT__`)

Когато искаш твой собствен клас да може да се върти в `for` цикъл, трябва да имплементираш двата метода на протокола.

```python
class EvenNumbers:
    def __init__(self, max_limit: int):
        self.max_limit = max_limit
        self.current = 0

    # 1. Връща самия обект итератор
    def __iter__(self):
        return self

    # 2. Връща следващия елемент или спира цикъла със StopIteration
    def __next__(self):
        self.current += 2
        if self.current > self.max_limit:
            raise StopIteration
        return self.current

for even in EvenNumbers(6):
    print(even)             # Извежда: 2, 4, 6
```

## 4. ДЕЛЕГИРАНЕ НА ГЕНЕРАТОРИ С `YIELD FROM`

Когато един генератор иска да изпрати всички елементи от друг генератор или списък, вместо да пишеш `for` цикъл, ползваш `yield from`.

```python
def combined_stream():
    yield from [10, 20]         # Подава 10, после 20
    yield from range(30, 33)    # Подава 30, 31, 32

print(list(combined_stream()))  # Изход: [10, 20, 30, 31, 32]
```

## 5. ОБОБЩЕНИЕ / БЪРЗ CHEAT SHEET

| Конструкция | Синтаксис | Какво прави |
| :--- | :--- | :--- |
| **Генераторна функция** | `def gen(): yield val` | Паузира изпълнението и връща `val` |
| **Взимане на следващ елемент** | `next(gen)` | Продължава до следващия `yield` |
| **Безопасно `next()` (без грешка)** | `next(gen, None)` | Връща `None` вместо `StopIteration` в края |
| **Генераторен израз** | `(x for x in data)` | Кръгли скоби `( )` — пести RAM памет |
| **Итератор от колекция** | `it = iter([1, 2, 3])` | Превръща списък в итератор |
| **Класов итератор** | `__iter__` + `__next__` | Позволява `for x in my_obj:` |
| **Делегиране на поток** | `yield from sub_gen()` | Препраща всички стойности от друг итератор |
