## 1. СИНТАКСИС НА КОРТЕЖ (TUPLE)

```python
# 1. Създаване на кортеж (кръгли скоби)
coordinates = (42.6977, 23.3219)
single_item = (100,)                # ЗАДЪЛЖИТЕЛНА запетая при 1 елемент!
empty_tuple = ()

# 2. Достъп по индекс и Slicing (само за четене!)
print(coordinates)               # Изход: 42.6977
print(coordinates[-1])              # Изход: 23.3219

# 3. Методи на кортежа (има само два!)
nums = (1, 2, 2, 3, 2)
print(nums.count(2))                # Колко пъти се среща 2 -> 3
print(nums.index(3))                # На кой индекс е числото 3 -> 3

# 4. Разопаковане (Unpacking)
lat, lon = coordinates
print(f"Ширина: {lat}, Дължина: {lon}")
```

## 2. СИНТАКСИС НА МНОЖЕСТВО (SET)

```python
# 1. Създаване на множество
empty_set = set()                   # НИКОГА с {}, защото това е празен dict!
unique_ids = {101, 102, 103, 101}   # Автоматично става {101, 102, 103}

# 2. Добавяне и премахване на елементи
unique_ids.add(104)                 # Добавя 104
unique_ids.remove(102)              # Изтрива 102 (ГЪРМИ с KeyError, ако го няма!)
unique_ids.discard(999)             # Безопасно триене (НЕ гърми, ако елементът липсва!)

# 3. Проверка за наличие (най-бързата операция в Python)
if 101 in unique_ids:
    print("ID 101 съществува!")
```

## 3. МАТЕМАТИЧЕСКИ ОПЕРАЦИИ С МНОЖЕСТВА

```python
a = {1, 2, 3, 4}
b = {3, 4, 5, 6}

# 1. Обединение (Union) -> Всички уникални елементи от двете
print(a | b)        # Или a.union(b)        -> {1, 2, 3, 4, 5, 6}

# 2. Сечение (Intersection) -> Само общите елементи
print(a & b)        # Или a.intersection(b) -> {3, 4}

# 3. Разлика (Difference) -> Елементи в A, които ги НЯМА в B
print(a - b)        # Или a.difference(b)   -> {1, 2}

# 4. Симетрична разлика -> Елементи, които са само в едното или само в другото
print(a ^ b)        # -> {1, 2, 5, 6}
```

## 4. ВЛОЖЕНИ ОПЕРАЦИИ (ПРЕМАХВАНЕ НА ДУБЛИКАТИ И FROZENSET)

```python
# 1. Най-бързият начин за изчистване на дубликати от списък
raw_emails = ["a@bg.com", "b@bg.com", "a@bg.com", "c@bg.com"]
clean_emails = list(set(raw_emails))

# 2. Вложено множество (frozenset) - неизменяемо множество, което може да стои в друг set
group_1 = frozenset(["Иван", "Мария"])
group_2 = frozenset(["Георги", "Елена"])
all_teams = {group_1, group_2}  # Обикновен set вътре в set би хвърлил TypeError!
```

## 5. ОБОБЩЕНИЕ / БЪРЗ CHEAT SHEET

| Действие | Синтаксис | Бележка / Резултат |
| :--- | :--- | :--- |
| **Кортеж с 1 елемент** | `t = (5,)` | Без запетаята е просто число `int` |
| **Разопаковане на кортеж** | `a, b = (10, 20)` | `a = 10`, `b = 20` |
| **Празно множество** | `s = set()` | `{}` създава празен речник (`dict`) |
| **Добавяне в множество** | `s.add(x)` | Игнорира ако `x` вече е вътре |
| **Безопасно триене от `set`** | `s.discard(x)` | Не хвърля грешка при липсващ елемент |
| **Обединение (A или B)** | `a \| b` | Всички уникални от двете |
| **Сечение (A и B)** | `a & b` | Само общите елементи |
| **Разлика (A без B)** | `a - b` | Само тези, които са в `a`, но не и в `b` |
