## 1. МНЕМОНИКА И ЗЛАТНИ ПРАВИЛА
* **Банкомат вместо трезор:** Клиентът използва контролиран интерфейс (`public void withdraw(...)`), вместо да бърка директно в полето с пари (`private double balance`).
* **Трите златни правила:** 
  1. Всички полета са `private` (или `private final`).
  2. Конструкторът вика сетърите (`this.setAge(age)`), за да не се дублира логиката.
  3. Гетърите за колекции никога не връщат оригинален списък, а `Collections.unmodifiableList(...)`.

---

## 2. МАТРИЦА НА ВИДИМОСТ (ACCESS MODIFIERS)
* `private`: Само в същия клас.
* `(default)`: Клас + същия пакет (`package-private`).
* `protected`: Клас + пакет + наследници.
* `public`: Навсякъде.

## 4. ПЛЮСОВЕ И МИНУСИ
* **Плюсове:** Гарантиране на валидно вътрешно състояние (инварианти) и свобода при вътрешно рефакториране.
* **Минуси:** Повече boilerplate код и писане на защитни проверки.

---

## 5. КОДОВ ОДИТ: ПРАВИЛЕН СРЕЩУ ГРЕШЕН КОД
* **Грешно:** Връщане на директна референция към вътрешен списък (`return this.players;`), което позволява външна манипулация (Reference Escape).
* **Правилно:** Използване на `Collections.unmodifiableList(this.players)` или валидация на входните параметри чрез сетъри и конструктори с хвърляне на `IllegalArgumentException`.

---

## 6. ИНТЕРВЮ УЛОВКИ И КАПАНИ
Разликата между **`Collections.unmodifiableList`** (жив Read-Only изглед, отразяващ бъдещи промени в оригиналния списък с O(1) памет) и **`List.copyOf`** (статично копие с O(n) памет, което не допуска `null` елементи) е класически въпрос за Senior интервюта.

---

## 7. АРХИТЕКТУРНО СРАВНЕНИЕ: JAVA 21+ СРЕЩУ C# 12+ (.NET)
* **По подразбиране:** В Java полетата/класовете без модификатор са `package-private`, докато в C# са `private` (за полета) или `internal` (за класове).
* **`protected`:** В Java включва целия пакет, докато в C# важи стриктно само за наследници (еквивалент на Java `protected` в C# е `protected internal`).
* **Properties и Read-Only:** Java разчита на конвенцията с гетъри/сетъри и `Collections.unmodifiableList`, докато C# поддържа езикови свойства (`get; init;`) и `IReadOnlyList<T>`.
