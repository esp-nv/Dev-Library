# 01. QA Automation & Software Engineering Quality (Пълен Справочник)

Пълен практически и архитектурен атлас по **Manual QA**, **Multi-Language Unit Testing**, **UI & Mobile Automation (Playwright, Selenium, AJAX/jQuery, Appium)**, **API & Performance Testing (RESTful, GraphQL, Postman, RestSharp, REST Assured, K6, JMeter)** и **Индустриални платформи (Jira, JQL, MS Project, TestRail, GitHub Actions)**.

## 🧭 Съдържание на Модула

*   **[01-00. QA Automation And Selenium Basics](01-00-QA-Automation-And-Selenium-Basics.md)** — *Обхваща:* Архитектура на Selenium WebDriver, инсталация, базови команди на браузъра и първи автоматизирани тестове в C#.

*   **[01-01. DOM Selectors And XPath Strategies](01-01-DOM-Selectors-And-XPath-Strategies.md)** — *Обхваща:* Дълбочинно намиране на елементи чрез CSS селектори и XPath оси (`following-sibling`, `ancestor`, `contains`), и стратегии за устойчиво локализиране.

*   **[01-02. Advanced QA Traps And Snippets](01-02-Advanced-QA-Traps-And-Snippets.md)** — *Обхваща:* Explicit Waits (`WebDriverWait`), Page Object Model (POM), работа с `<iframe>`, Alerts, прозорци и готови кодови снипети.

*   **[01-03. QA Cheat Sheet And Reference Guide](01-03-QA-Cheat-Sheet-And-Reference-Guide.md)** — *Обхваща:* Бърза синтактична справка за Selenium WebDriver, NUnit Assertions и основни QA концепции.

*   **[01-04. Manual QA & Test Design Techniques](01-04-Manual-QA-And-Test-Design-Techniques.md)** — *Обхваща:* Тестовата пирамида, нива и видове тестване (Static/Dynamic, Black/White-Box, Smoke/Regression), 4-те златни Test Design техники (EP, BVA, Decision Tables, State Transition) и шаблони за Test Case и Bug Report.

*   **[01-05. Multi-Language Unit Testing](01-05-Multi-Language-Unit-Testing.md)** — *Обхваща:* Писане на изолирани компонентни тестове по шаблона AAA и Mocking в 4 езика: C# (`NUnit` + `Moq`), Java (`JUnit 5` + `Mockito`), TypeScript (`Vitest`) и Python (`pytest`).

*   **[01-06. Modern UI Automation: Playwright, AJAX/jQuery & Appium](01-06-Modern-UI-Automation-Playwright-And-AJAX.md)** — *Обхваща:* Архитектура на Playwright срещу Selenium, тестване на AJAX и jQuery динамични приложения (`waitForResponse`, Network Mocking), Page Object Model в TS и C#, и Appium основи за Android/iOS.

*   **[01-07. Back-End API (RESTful & GraphQL) & Performance Testing](01-07-API-And-Performance-Testing.md)** — *Обхваща:* Тестване на RESTful и GraphQL API-та (`200 OK` с `errors[]` уловката) чрез Postman, RestSharp, REST Assured и Mocha/Chai, плюс Performance & Load тестване с Grafana K6 и Apache JMeter.

*   **[01-08. Индустриални QA Платформи: Jira, JQL, MS Project & CI/CD](01-08-Jira-JQL-TestRail-And-CICD-Platforms.md)** — *Обхваща:* Ежедневна работа в Jira Software (Projects, Schemes, Workflows, Scrum/Kanban Boards, Quick Filters, Dashboards, JQL заявки, Automations), Xray/TestRail/Azure DevOps, планиране на графици в Microsoft Project (WBS, Gantt, Critical Path) и GitHub Actions CI/CD.

*   **[01-96. QA Performance & Optimizations (с Блок-схеми)](01-96-Performance-And-Optimizations.md)** — *Обхваща:* Ускоряване на тестови пакети с над 80% чрез API Login + `storageState`, паралелни Workers & Sharding, Event-Driven чакане и блокиране на тежки медийни ресурси.

*   **[01-97. QA Category Cheat Sheet & Инструменти](01-97-Category-Cheat-Sheet.md)** — *Обхваща:* Подредена справка по 5 категории — йерархия на локаторите, HTTP статус кодове, Test Design формули, таблица с важните QA библиотеки и CLI команди.

*   **[01-98. QA Common Errors, Edge Cases & Fixes (Каталог на грешките)](01-98-Common-Errors-And-Fixes.md)** — *Обхваща:* Диагностика на `StaleElementReferenceException`, `ElementClickInterceptedException`, `StrictModeViolation`, `401`/`415` API грешки, гранични случаи в CI/CD и таблица по фази на възникване.

*   **[01-99. QA & SDET Interview Q&A, Скрити Капани & Debugging](01-99-Interview-QA-Traps-And-Debugging.md)** — *Обхваща:* Топ QA/SDET интервю въпроси (Flaky тестове, Implicit vs Explicit Wait, GraphQL, Load vs Stress vs Soak), капани и дебъгване с Playwright Trace Viewer, HAR файлове и DevTools Console (`$$` / `$x`).
