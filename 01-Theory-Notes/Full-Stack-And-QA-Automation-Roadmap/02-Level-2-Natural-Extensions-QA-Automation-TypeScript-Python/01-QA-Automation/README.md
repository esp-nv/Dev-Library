# Модул 1: QA Automation & Automated Testing (Инженерен Интервю Справочник)

Тази директория съдържа декуплиран на подпапки практически и теоретичен атлас за автоматизирано софтуерно тестване на уеб приложения (UI & API Automation). Структурата е развита изцяло под формата на технически въпроси за интервю, софтуерни капани и кодови решения, разпределени в три самостоятелни нива.

## 🧭 Навигация на Автоматизационните Слоеве

### 📂 Секция 1: Темите от лекциите (Атомарни подточки в /Lectures)

    *   *Обхваща:* Нисконивова архитектура на Selenium и Playwright среди, управление на браузърни сесии и стартиране на headless нишки.
*   **[01-01. DOM Селектори: Стратегии за сигурно улавяне през CSS и XPath](01-01-DOM-Selectors-And-XPath-Strategies.md)**
    *   *Обхваща:* Локализиране на уеб обекти през DOM дървото, абсолютни срещу относителни пътища и навигация по осите на XPath.
