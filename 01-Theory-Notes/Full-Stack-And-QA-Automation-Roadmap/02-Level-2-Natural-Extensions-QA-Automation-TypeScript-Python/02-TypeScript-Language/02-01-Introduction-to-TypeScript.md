# 02-01. Въведение в TypeScript и Конфигурация на среди

**Модул 02:** TypeScript | **Лекционна тема 01:** Статичен анализ, архитектура на компилатора (`tsc`), примитивни типове и структура на `tsconfig.json`.

---

## 1. АРХИТЕКТУРЕН АНАЛИЗ & ПРЕДИМСТВА И НЕДОСТАТЪЦИ

TypeScript е строго типизирано надмножество (Superset) на JavaScript, разработено от Microsoft. Тъй като браузърите не разбират нативно TypeScript код, той преминава през софтуерен процес на **Транспилация** (превеждане от един софтуерен език към друг) чрез компилатора `tsc`, превръщайки се в чист JavaScript (ES6+).

### 🟢 Предимства (Pros):
*   **Улавяне на грешки при компилация (Compile-time Errors):** Спира бъгове (напр. подаване на стринг вместо число, несъществуващи свойства) още докато пишеш във VS Code, вместо системата да гръмне в продукция пред клиента.
*   **Сеньор автодопълнение (IntelliSense):** Индексира обектите в паметта и предоставя кристална документация в реално време.

### 🔴 Недостатъци (Cons):
*   **Изисква допълнителна стъпка за билд:** Налага се използването на компилатори или Vite за обръщане на кода до чист JS.
*   **Липса на типизация по време на изпълнение (No Runtime Type Enforcement):** Типовете съществуват само по време на разработка и се изтриват напълно след компилация.

## 2. КОДОВ ОДИТ: ПРАВИЛЕН СРЕЩУ ГРЕШЕН КОД

### ❌ ГРЕШЕН КОД (Анти-патърн в суров JavaScript):
```javascript
function calculateTax(amount) {
    return amount * 0.20;
}
// Браузърът не сигнализира грешка при писане, но изходът е NaN!
console.log(calculateTax("петстотин лева")); 
```
*   **Изход в браузъра:** `NaN` (Not a Number) — тиха логическа грешка, която чупи финансовите калкулации на бекенда без изключение в конзолата.

### 🟢 ПРАВИЛЕН КОД (Строг TypeScript стандарт):
```typescript
// Изрично дефиниране на входящия параметър и типа на връщания резултат
function calculateTaxSecure(amount: number): number {
    return amount * 0.20;
}

const safeAmount: number = 500;
const finalTax = calculateTaxSecure(safeAmount);

console.log(`Калкулиран данък: ${finalTax} лв.`);
```
*   **Коментар към кода:** Компилаторът заковава типа `number`. Ако се опиташ да му подадеш стринг, VS Code ще светне в червено веднага и ще блокира билда с грешка: *Argument of type 'string' is not assignable to parameter of type 'number'*.
*   **Очакван компилационен изход (JS):** `Калкулиран данък: 100 лв.`

## 3. СИСТЕМНА КОНФИГУРАЦИЯ: TSCONFIG.JSON Blueprints

Файлът `tsconfig.json` контролира поведението на компилатора `tsc`. За изпити и реално софтуерно инженерство се използва следният строг предпазен шаблон:

```json
{
  "compilerOptions": {
    "target": "ES2022",                          /* Модерна версия на изходния JavaScript */
    "module": "NodeNext",                        /* Съвременна модулна система за резолюция */
    "strict": true,                              /* Активира ВСИЧКИ строги проверки за сигурност */
    "noImplicitAny": true,                       /* Забранява оставянето на елементи без тип */
    "skipLibCheck": true,                        /* Ускорява компилацията чрез пропускане на d.ts файлове */
    "forceConsistentCasingInFileNames": true     /* Защита на пътищата между Windows и Linux среди */
  }
}
```
