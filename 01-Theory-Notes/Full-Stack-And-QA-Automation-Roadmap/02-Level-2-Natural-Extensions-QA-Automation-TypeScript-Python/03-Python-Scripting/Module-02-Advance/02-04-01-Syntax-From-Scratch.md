## 1. СИНТАКСИС НА `*ARGS` (НЕОГРАНИЧЕНИ ПОЗИЦИОННИ АРГУМЕНТИ)

```python
# Вътре във функцията 'numbers' пристига като обикновен tuple
def sum_all(*numbers):
    total = 0
    for n in numbers:
        total += n
    return total

print(sum_all(10, 20))              # Изход: 30
print(sum_all(1, 2, 3, 4, 5))       # Изход: 15
print(sum_all())                    # Изход: 0 (празен кортеж)
```

## 2. СИНТАКСИС НА `**KWARGS` (НЕОГРАНИЧЕНИ ИМЕНУВАНИ АРГУМЕНТИ)

```python
# Вътре във функцията 'settings' пристига като обикновен dict
def configure_server(**settings):
    for key, value in settings.items():
        print(f"Настройка {key} = {value}")

configure_server(host="127.0.0.1", port=8080, debug=True)
```

## 3. РАЗОПАКОВАНЕ ПРИ ИЗВИКВАНЕ НА ФУНКЦИЯ (`*` И `**`)

Операторите `*` и `**` работят и в обратна посока — могат да „разпакетират“ готов списък или речник и да подадат елементите му като отделни аргументи на функция.

```python
def register_user(username, email, role):
    print(f"Регистрация: {username} | {email} | Роля: {role}")

# 1. Разопаковане на списък с една звездичка *
user_list = ["Елизабет", "eli@softuni.bg", "Admin"]
register_user(*user_list)

# 2. Разопаковане на речник с две звездички ** (ключовете трябва да съвпадат с имената на параметрите!)
user_dict = {"username": "Георги", "email": "geo@softuni.bg", "role": "User"}
register_user(**user_dict)
```

## 4. ВЛОЖЕНИ ФУНКЦИИ С `NONLOCAL` И CLOSURES

Когато вътрешна функция иска не само да чете, но и да **променя** променлива на външната функция, се използва ключовата дума **`nonlocal`**.

```python
def create_counter():
    count = 0  # Променлива в обхвата на външната функция (Enclosing)

    def increment():
        nonlocal count  # Позволява промяна на 'count' от външната функция
        count += 1
        return count

    return increment  # Връщаме самата функция БЕЗ скоби ()

counter_a = create_counter()
print(counter_a())  # Изход: 1
print(counter_a())  # Изход: 2
```

## 5. ОБОБЩЕНИЕ / БЪРЗ CHEAT SHEET

| Конструкция | Синтаксис | Какво прави |
| :--- | :--- | :--- |
| **`*args` в дефиниция** | `def f(*args):` | Събира позиционни аргументи в `tuple` |
| **`**kwargs` в дефиниция** | `def f(**kwargs):` | Събира `key=val` аргументи в `dict` |
| **Задължителен ред на параметри** | `def f(a, *args, b=1, **kwargs):` | Строга йерархия при дефиниране |
| **Разопаковане на списък** | `func(*my_list)` | Подава елементите поотделно |
| **Разопаковане на речник** | `func(**my_dict)` | Подава ключовете като именувани аргументи |
| **Промяна на външна променлива** | `nonlocal x` | Позволява запис във външна (неглобална) функция |
| **Лимит на рекурсията** | `sys.getrecursionlimit()` | По подразбиране е `1000` нива в стека |
