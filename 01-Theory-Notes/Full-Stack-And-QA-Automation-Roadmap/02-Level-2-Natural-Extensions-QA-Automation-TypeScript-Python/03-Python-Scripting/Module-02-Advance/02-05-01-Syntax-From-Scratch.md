## 1. ОСНОВЕН СИНТАКСИС НА `TRY` И `EXCEPT`

```python
try:
    # Код, който може да хвърли грешка
    age = int(input("Въведи години: "))
    result = 100 / age
    print(f"Резултат: {result}")

except ValueError:
    # Хваща грешката, ако потребителят напише текст вместо число
    print("Грешка: Моля, въведете валидно цяло число!")

except ZeroDivisionError as error_details:
    # Ключовата дума 'as' запазва текста на грешката в променлива
    print(f"Грешка: Не може да се дели на нула! ({error_details})")
```

## 2. ПЪЛНА КОНСТРУКЦИЯ С `ELSE` И `FINALLY`

```python
try:
    data = {"user": "Елизабет"}
    username = data["user"]
except KeyError:
    print("Ключът липсва в речника!")
else:
    # Изпълнява се САМО ако try блокът НЕ е хвърлил грешка
    print(f"Добре дошла, {username}!")
finally:
    # Изпълнява се ВИНАГИ (за почистване на ресурси)
    print("Проверката приключи.")
```

## 3. ВДИГАНЕ НА ГРЕШКИ (`RAISE`) И CUSTOM EXCEPTIONS

```python
# 1. Създаване на собствена грешка (наследява вградения клас Exception)
class InvalidEmailError(Exception):
    pass

# 2. Функция, която сама хвърля грешка при невалидни данни
def validate_email(email: str):
    if "@" not in email:
        raise InvalidEmailError(f"Имейлът '{email}' не съдържа символа '@'!")
    return True

try:
    validate_email("invalid-email.bg")
except InvalidEmailError as e:
    print(f"Валидационна грешка: {e}")
```

## 4. НАЙ-ЧЕСТИТЕ ВГРАДЕНИ ГРЕШКИ В PYTHON

*   **`ValueError`**: Правилен тип, но грешна стойност (напр. `int("abc")`).
*   **`TypeError`**: Операция между несъвместими типове (напр. `"5" + 2` или викане на нещо, което не е функция).
*   **`IndexError`**: Опит за достъп до несъществуващ индекс в списък (напр. `my_list` при списък с 3 елемента).
*   **`KeyError`**: Опит за четене на липсващ ключ в речник (`my_dict["missing"]`).
*   **`AttributeError`**: Опит за извикване на несъществуващ метод или свойство (често върху `None`).
*   **`FileNotFoundError`**: Опит за отваряне на файл, който липсва на диска.

## 5. ОБОБЩЕНИЕ / БЪРЗ CHEAT SHEET

| Конструкция | Синтаксис | Кога се изпълнява |
| :--- | :--- | :--- |
| **Защитен блок** | `try:` | Винаги първи — съдържа рисковия код |
| **Хващане на 1 грешка** | `except ValueError as e:` | Само при възникване на `ValueError` |
| **Хващане на няколко грешки** | `except (ValueError, TypeError):` | При коя да е от изброените грешки |
| **Блок при успех** | `else:` | Само ако `try` завърши **без** грешки |
| **Финален блок** | `finally:` | **Винаги**, независимо дали има грешка или `return` |
| **Хвърляне на грешка** | `raise ValueError("Текст")` | Ръчно спира изпълнението и вдига изключение |
| **Собствена грешка** | `class MyError(Exception): pass` | Дефинира нов тип бизнес грешка |
