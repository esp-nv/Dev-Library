## 1. ОСНОВЕН СИНТАКСИС НА ФУНКЦИЯ (DEF И RETURN)

Функцията се дефинира с `def`, име с малки букви и долна черта (`snake_case`), скоби `()` и двоеточие `:`. Кодът вътре е с 4 интервала отстъп.

```python
# 1. Функция без параметри и без връщане на стойност
def say_hello():
    print("Здравей от Python!")

# Извикване на функцията (задължително със скоби!)
say_hello()

# 2. Функция с параметри и връщане на резултат (return)
def multiply(a, b):
    result = a * b
    return result  # Прекратява функцията и връща стойността

answer = multiply(6, 7)
print(f"Отговор: {answer}")  # Изход: Отговор: 42
```

## 2. ВИДОВЕ АРГУМЕНТИ (ПОЗИЦИОННИ, ИМЕНУВАНИ И ПО ПОДРАЗБИРАНЕ)

```python
# Параметърът 'role' има стойност по подразбиране ("User")
def create_profile(username, age, role="User"):
    print(f"Потребител: {username}, Години: {age}, Роля: {role}")

# 1. Позиционно извикване (редът има значение!)
create_profile("Иван", 28)                  # Използва role="User" по подразбиране
create_profile("Мария", 32, "Admin")        # Презаписва role на "Admin"

# 2. Именувано извикване (Keyword arguments - редът НЯМА значение)
create_profile(age=25, username="Елизабет", role="Moderator")
```

## 3. ВРЪЩАНЕ НА МНОЖЕСТВО СТОЙНОСТИ И РАЗОПАКОВАНЕ

```python
def get_min_max(numbers):
    lowest = min(numbers)
    highest = max(numbers)
    return lowest, highest  # Връща двете числа едновременно

# Директно разопаковане в две отделни променливи
min_val, max_val = get_min_max([10, 5, 88, 23])
print(f"Най-малко: {min_val}, Най-голямо: {max_val}")
```

## 4. ВЛОЖЕНИ ФУНКЦИИ И АНОНИМНИ LAMBDA ФУНКЦИИ

```python
# А. Вложена функция (Nested Function) - вижда се само вътре във външната
def outer_calculator(x):
    def inner_double(n):
        return n * 2
    
    return inner_double(x) + 10

print(outer_calculator(5))  # (5 * 2) + 10 -> 20

# Б. Lambda функция (едноредова анонимна функция)
# Синтаксис: lambda аргументи : израз
square = lambda x: x ** 2
print(square(4))            # Изход: 16
```

## 5. ОБОБЩЕНИЕ / БЪРЗ CHEAT SHEET

| Конструкция | Синтаксис | Пример |
| :--- | :--- | :--- |
| **Дефиниране на функция** | `def име(параметри):` | `def get_total(price, tax):` |
| **Връщане на стойност** | `return стойност` | `return price + tax` |
| **Стойност по подразбиране** | `def f(x=10):` | Ако не подадеш `x`, става `10` |
| **Извикване по име** | `f(param=стойност)` | `get_total(tax=5, price=20)` |
| **Връщане на 2 стойности** | `return a, b` | `x, y = my_func()` |
| **Lambda израз (1 ред)** | `lambda x: x + 1` | `add_one = lambda x: x + 1` |
| **Неограничени аргументи** | `def f(*args, **kwargs):` | Приема всякакъв брой параметри |
