# 01-01. Basic Syntax, Conditional Statements and Loops

**Модул 01:** Basic and Fundamentals | **Лекционна тема 01:** Синтактични правила, условни конструкции (`if-elif-else`), цикли (`for`, `while`) и контрол на потока.

---

## 1. КАК ДА СЕ ЗАПОМНИ И ЧЕТЕ ПО-ЛЕСНО (МНЕМОНИКА)

*   **Логически оператори:** В Python не пишем символи като `&&`, `||` и `!`. Пишем чисти английски думи: **`and`**, **`or`**, **`not`**.
*   **Условни разклонения:** Вместо дългото `else if` от C# и JS, Python съкращава думата на **`elif`**.
*   **Циклите:** Представи си `for item in collection:` като нативния `foreach` от C#. Когато ти трябват числа, използваш функцията **`range(start, stop, step)`**, като краят (`stop`) **никога не се включва** в броенето (Exclusive).

---

## 2. ЕТАПИ НА ИЗПЪЛНЕНИЕ НА ЦИКЪЛ И БЛОК-СХЕМА

В Python циклите имат уникална конструкция `for ... else` или `while ... else`. Блокът `else` се изпълнява **само ако цикълът е завършил естествено, без да бъде прекъснат насила с командата `break`**.

```text
┌──────────────────────────┐
│  Начало на цикъл         │
│  (for / while)           │
└────────────┬─────────────┘
             │
             ▼
      ┌─────────────┐      НЕ (Край на елементите)     ┌─────────────────────────┐
      │ Има ли още  │ ───────────────────────────────► │ Изпълни блок 'else:'    │
      │ елементи?   │                                  │ (Само ако няма 'break') │
      └──────┬──────┘                                  └────────────┬────────────┘
             │ ДА                                                   │
             ▼                                                      ▼
┌──────────────────────────┐     ДА (break)            ┌─────────────────────────┐
│ Изпълни тялото на цикъла │ ────────────────────────► │ Изход от цикъла         │
│ Проверка за 'break'?     │                           │ (Прескача 'else:')      │
└────────────┬─────────────┘                           └─────────────────────────┘
             │ НЕ
             └───────────────────► (Обратно към проверка)
```

## 3. АРХИТЕКТУРНО СРАВНЕНИЕ: PYTHON СРЕЩУ C# И JAVASCRIPT

| Конструкция | Python 3.x | C# (.NET) | JavaScript (ES6+) |
| :--- | :--- | :--- | :--- |
| **Логическо И / ИЛИ** | `and` / `or` / `not` | `&&` / `\|\|` / `!` | `&&` / `\|\|` / `!` |
| **Else If** | `elif condition:` | `else if (condition)` | `else if (condition)` |
| **Тернарен оператор** | `a if cond else b` | `cond ? a : b` | `cond ? a : b` |
| **Обхождане (Foreach)** | `for x in list:` | `foreach (var x in list)` | `for (const x of list)` |
| **Брояч цикъл** | `for i in range(0, 5):` | `for (int i = 0; i < 5; i++)` | `for (let i = 0; i < 5; i++)` |

## 4. ПЛЮСОВЕ И МИНУСИ НА СИНТАКСИСА

### 🟢 Предимства (Pros):
*   **Верижно сравняване (Chained Comparisons):** Можеш да пишеш чиста математика като `10 < age <= 65`, вместо тромавото `age > 10 && age <= 65`.
*   **Мощен `range()` генератор:** Не заделя памет за целия масив от числа предварително, а ги генерира едно по едно в реално време.

### 🔴 Недостатъци (Cons):
*   **Липса на класически `do-while` цикъл:** Налага се симулиране чрез безкраен `while True:` и изрична проверка с `if ... break` в края на тялото.
*   **Липса на `++` и `--` оператори:** Изразът `i++` хвърля `SyntaxError`. Използва се единствено `i += 1`.

## 5. КОДОВ ОДИТ: ПРАВИЛЕН СРЕЩУ ГРЕШЕН КОД (И КОМЕНТАРИ)

### ❌ ГРЕШЕН КОД (Безкраен цикъл и грешна логика в range):
```python
# 🚨 ГРЕШКА 1: Искаме числата от 1 до 5, но range(1, 5) спира на 4!
for num in range(1, 5):
    print(num) # Извежда 1, 2, 3, 4 (липсва 5)

# 🚨 ГРЕШКА 2: Безкраен while цикъл поради липсващ инкремент
counter = 0
while counter < 3:
    print("Обработка...")
    # Забравено counter += 1 -> програмата зависва завинаги!
```
*   **Как да се избегне:** Винаги добавяй `+1` към горната граница на `range(1, 6)`, ако искаш числото 5 да бъде включено. При `while` цикли първо пиши условието за изход (`counter += 1`), и чак след това бизнес логиката.

### 🟢 ПРАВИЛЕН КОД (Чист Pythonic стандарт с for-else търсене):
```python
# Списък с активни сървърни портове
server_ports = [80, 443, 5000, 8080]
target_port = 5000

# Обхождане с вграден механизъм за откриване без булеви флагове (is_found = False)
for port in server_ports:
    # Верижна проверка на диапазон
    if 1024 <= port <= 65535 and port == target_port:
        print(f"[✅ НАМЕРЕН] Порт {port} е валиден потребителски порт.")
        break  # Прекъсва цикъла и директно прескача 'else' блока
else:
    # Този блок се изпълнява САМО ако цикълът не е намерил порта и не е ударил break
    print(f"[❌ ГРЕШКА] Порт {target_port} липсва в конфигурацията.")
```
*   **Изход в конзолата:**
    ```text
    [✅ НАМЕРЕН] Порт 5000 е валиден потребителски порт.
    ```

## 6. ИНТЕРВЮ КАПАНИ, ВЪПРОСИ И УЛОВКИ

*   **Въпрос на интервюто:** *„Каква е разликата между ключовите думи `break`, `continue` и `pass` в Python циклите?“*
*   **Уловката:** Начинаещите често бъркат `continue` и `pass`, мислейки, че и двете прескачат текущата итерация.
*   **Точен Senior отговор:** 
    1.  **`break`**: Убива и прекратява целия цикъл незабавно.
    2.  **`continue`**: Прекратява **само текущата итерация** и връща изпълнението веднага горе в началото на цикъла за следващия елемент (прескачайки редовете след себе си).
    3.  **`pass`**: Това е **празна операция (Null Operation / Placeholder)**. Тя не прави абсолютно нищо и не прескача нищо — кодът продължава да се изпълнява на следващия ред веднага след `pass`. Използва се единствено за запълване на празни блокове код (напр. празна функция или `if` блок), за да не хвърли компилаторът `IndentationError`, докато разработчикът все още пише архитектурата.
