## 1. ОСНОВНИ СИМВОЛИ И КЛАСОВЕ (КАКВО ТЪРСИМ)

```python
import re

# \d -> Всяка цифра от 0 до 9
# \w -> Буква (a-z, A-Z, кирилица), цифра (0-9) или долна черта (_)
# \s -> Празно пространство (интервал, табулация, нов ред)
# .  -> Всеки един символ (освен нов ред)

# Квадратни скоби [] -> Дефинират собствен набор от разрешени символи
# [a-z]    -> Всяка малка латинска буква
# [A-Z0-9] -> Всяка главна латинска буква или цифра
# [^0-9]   -> Символът ^ вътре в [] означава ОТРИЦАНИЕ (всичко, което НЕ е цифра)
```

## 4. ОСНОВНИТЕ 4 ФУНКЦИИ В МОДУЛА `RE`

```python
import re

sample = "Поръчка #104 на стойност 45 лв. и Поръчка #209 на стойност 120 лв."

# 1. re.findall() -> Връща СПИСЪК с всички намерени съвпадения
all_numbers = re.findall(r"\d+", sample)
print(all_numbers)          # Изход: ['104', '45', '209', '120']

# 2. re.search() -> Търси ПЪРВОТО съвпадение и връща Match обект (или None)
first_order = re.search(r"#(\d+)", sample)
if first_order:
    print(first_order.group(0))  # Цялото съвпадение -> '#104'
    print(first_order.group(1))  # Само първата група в скобите () -> '104'

# 3. re.sub() -> Заменя намерените съвпадения с нов текст
censored = re.sub(r"\d+", "***", sample)
print(censored)             # Изход: 'Поръчка #*** на стойност *** лв. и Поръчка #*** на стойност *** лв.'

# 4. re.split() -> Разделя текста по шаблон
parts = re.split(r"\s+и\s+", sample)
print(parts)                # Изход: ['Поръчка #104 на стойност 45 лв.', 'Поръчка #209 на стойност 120 лв.']
```

## 5. ОБОБЩЕНИЕ / БЪРЗ CHEAT SHEET

| Символ / Функция | Значение | Пример |
| :--- | :--- | :--- |
| **`r"..."`** | Суров стринг (задължителен за Regex) | `r"\d+\w+"` |
| **`\d` / `\w` / `\s`** | Цифра / Буква-цифра / Интервал | `r"\w+@\w+\.\w+"` |
| **`+` / `*` / `?`** | 1+ пъти / 0+ пъти / 0 или 1 път | `r"colou?r"` (color или colour) |
| **`{n,m}`** | Повторение от `n` до `m` пъти | `r"\d{4}"` (година от 4 цифри) |
| **`^` и `$`** | Начало и край на целия текст | `r"^\d+$"` (само цифри от край до край) |
| **`(...)`** | Група за извличане с `.group(1)` | `r"ID: (\d+)"` |
| **`re.findall(pat, txt)`** | Връща списък с всички съвпадения | `['12', '34']` |
| **`re.search(pat, txt)`** | Връща първото съвпадение или `None` | `if m: print(m.group())` |
| **`re.sub(pat, new, txt)`** | Търси и заменя по шаблон | Заменя чувствителни данни |
