## 1. LIST COMPREHENSION (СИНТАКСИС СТЪПКА ПО СТЪПКА)

```python
numbers =

# 1. Базов вид: [израз for елемент in списък]
doubled = [n * 2 for n in numbers]              # Резултат:

# 2. С филтър (само if -> в края): [израз for елемент in списък if условие]
evens = [n for n in numbers if n % 2 == 0]      # Резултат:
```

## 2. РЯЗАНЕ НА СПИСЪЦИ (LIST SLICING)

Синтаксисът е **`списък[начало : край : стъпка]`**. Връща нов списък, без да променя оригинала.

```python
letters = ['a', 'b', 'c', 'd', 'e', 'f']

print(letters[1:4])     # От индекс 1 до 3 (4 не се включва) -> ['b', 'c', 'd']
print(letters[:3])      # От началото до индекс 2 -> ['a', 'b', 'c']
print(letters[3:])      # От индекс 3 до края -> ['d', 'e', 'f']
print(letters[::2])     # Всеки втори елемент -> ['a', 'c', 'e']
print(letters[::-1])    # Обръща целия списък наопаки -> ['f', 'e', 'd', 'c', 'b', 'a']
```

## 3. СОРТИРАНЕ С КЛЮЧОВЕ (SORT И SORTED С LAMBDA)

```python
words = ["банан", "киви", "ябълка", "нар"]

# 1. Стандартно сортиране по азбучен ред (връща нов списък)
alphabetical = sorted(words)                    # ['банан', 'киви', 'нар', 'ябълка']

# 2. Обратно сортиране (reverse=True)
descending = sorted(words, reverse=True)        # ['ябълка', 'нар', 'киви', 'банан']

# 3. Сортиране по специален критерий (напр. по дължина на думата с key=len)
by_length = sorted(words, key=lambda w: len(w)) # ['киви', 'нар', 'банан', 'ябълка']
```

## 5. ОБОБЩЕНИЕ / БЪРЗ CHEAT SHEET

| Операция | Синтаксис | Пример / Резултат |
| :--- | :--- | :--- |
| **Базов Comprehension** | `[x * 2 for x in arr]` | Умножава всеки елемент по 2 |
| **Филтриране (`if`)** | `[x for x in arr if x > 5]` | Оставя само по-големите от 5 |
| **Замяна (`if-else`)** | `[x if x > 0 else 0 for x in arr]` | Заменя отрицателните с `0` |
| **Изрязване (Slice)** | `arr[1:4]` | Взима индекси 1, 2 и 3 |
| **Първите N елемента** | `arr[:N]` | `arr[:3]` взима първите 3 |
| **Последните N елемента** | `arr[-N:]` | `arr[-2:]` взима последните 2 |
| **Обръщане на списък** | `arr[::-1]` | Връща обърнато копие |
| **Сортиране по критерий** | `sorted(arr, key=lambda x: ...)` | Сортира без да пипа оригинала |
