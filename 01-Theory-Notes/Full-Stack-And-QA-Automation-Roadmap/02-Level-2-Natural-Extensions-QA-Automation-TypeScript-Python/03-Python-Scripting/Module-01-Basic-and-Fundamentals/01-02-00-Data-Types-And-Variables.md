## 1. КАК ДА СЕ ЗАПОМНИ И ЧЕТЕ ПО-ЛЕСНО (МНЕМОНИКА)

*   **Кутия срещу Етикет:** В C# променливата е **кутия** с твърд размер в паметта (напр. `int x = 5` заделя 4 байта кутия). В Python променливата е просто **хартиен етикет (Reference)**, залепен върху обект в RAM паметта. Можеш да отлепиш етикета `x` от числото `5` и да го залепиш върху текста `"Здравей"` по всяко време.
*   **Истински константи няма:** В Python няма ключова дума `const`. Ако искаш да кажеш на другите програмисти „не пипай тази стойност“, пишеш името с **ГЛАВНИ БУКВИ** (напр. `MAX_USERS = 100`).

## 2. ЕТАПИ НА ЗАДЕЛЯНЕ НА ПАМЕТ И БЛОК-СХЕМА

В Python **абсолютно всичко е обект** (дори простите числа и булевите стойности). Паметта се управлява автоматично чрез броене на референциите (**Reference Counting**) и Garbage Collector.

```text
Код: x = 10          Код: y = x          Код: x = "Текст"

┌─────────┐          ┌─────────┐          ┌─────────┐
│ x (Име) │──┐       │ x (Име) │──┐       │ x (Име) │───► [ Обект: "Текст" ]
└─────────┘  │       └─────────┘  │       └─────────┘
             ▼                    ▼
     [ Обект: 10 ]        [ Обект: 10 ]   ┌─────────┐
     (RefCount: 1)        (RefCount: 2)   │ y (Име) │───► [ Обект: 10 ] (RefCount: 1)
                                          └─────────┘
```

## 3. АРХИТЕКТУРНО СРАВНЕНИЕ: PYTHON СРЕЩУ C# И JAVASCRIPT

| Характеристика | Python 3.x | C# (.NET) | JavaScript (ES6+) |
| :--- | :--- | :--- | :--- |
| **Цели числа (`int`)** | **Безкрайна прецизност** (няма Overflow!) | Ограничени (32-bit `Int32` до 2.14 млрд.) | Ограничени (`Number` до \(2^{53}-1\) или `BigInt`) |
| **Дробни числа (`float`)** | 64-bit (еквивалент на `double` в C#) | `float` (32-bit), `double` (64-bit), `decimal` | 64-bit IEEE 754 (`Number`) |
| **Празно значение** | `None` (единствен обект `NoneType`) | `null` | `null` и `undefined` |
| **Константи** | Няма (конвенция `UPPER_CASE`) | `const` и `readonly` | `const` |
| **Проверка на тип** | `type(x)` или `isinstance(x, int)` | `x.GetType()` или `x is int` | `typeof x` |

## 4. ПЛЮСОВЕ И МИНУСИ НА ТИПОВАТА СИСТЕМА

### 🟢 Предимства (Pros):
*   **Няма Integer Overflow:** Можеш да изчислиш \(1000^{1000}\) директно с обикновен `int`, без програмата да превърти в отрицателни числа, както се случва в C#.
*   **Бързо прототипиране:** Не губиш време в писане на дълги типови декларации и каствания.

### 🔴 Недостатъци (Cons):
*   **По-висок разход на RAM:** Тъй като дори едно просто число `5` е цял обект с метаданни и брояч на референции, то заема около 28 байта в паметта (вместо 4 байта в C#).
*   **Грешки с плаваща запетая:** Както в JS и C#, `0.1 + 0.2` дава `0.30000000000000004`. За парични сметки трябва изрично да се импортира модулът `decimal`.

## 5. КОДОВ ОДИТ: ПРАВИЛЕН СРЕЩУ ГРЕШЕН КОД (И КОМЕНТАРИ)

### ❌ ГРЕШЕН КОД (Капан с Truthy/Falsy и грешно кастване):
```python
# 🚨 ГРЕШКА 1: Опит за директно обръщане на дробен текст в цяло число
price_text = "19.99"
# price = int(price_text) -> Хвърля ValueError: invalid literal for int() with base 10: '19.99'

# 🚨 ГРЕШКА 2: Грешна проверка за bool от конзолен вход
# В Python bool("False") връща True, защото всеки непразен текст е Truthy!
user_input = "False"
is_active = bool(user_input) # Става True вместо False!
```
*   **Как да се избегне:** Дробен стринг първо се обръща във `float("19.99")` и чак след това в `int()`. Булев вход от потребител се проверява чрез сравнение: `is_active = (user_input == "True")`.

### 🟢 ПРАВИЛЕН КОД (Чист Pythonic стандарт за работа с типове):
```python
from decimal import Decimal  # Вграден модул за точни финансови изчисления

# 1. Безопасно преобразуване на дробен текст
raw_price = "19.99"
exact_price = Decimal(raw_price)  # Избягва грешката 0.1 + 0.2
rounded_int = int(float(raw_price))  # Първо float, после int -> 19

# 2. Препоръчителна проверка на тип в продукция
def process_payment(amount: Decimal | int) -> str:
    # Използваме isinstance(), защото уважава и наследяването
    if isinstance(amount, (Decimal, int)):
        return f"Плащането от {amount} лв. е прието."
    return "Невалиден формат на сумата."

print(process_payment(exact_price))
print(f"Цяла част: {rounded_int}")
```
*   **Изход в конзолата:**
    ```text
    Плащането от 19.99 лв. е прието.
    Цяла част: 19
    ```

## 6. ИНТЕРВЮ КАПАНИ, ВЪПРОСИ И УЛОВКИ

*   **Въпрос на интервюто:** *„Каква е разликата между операторите `==` и `is` в Python?“*
*   **Уловката:** Много кандидати използват `if x is 1000:` вместо `if x == 1000:`, което работи при малки числа, но се чупи при големи!
*   **Точен Senior отговор:** 
    1.  **`==` (Equality):** Проверява дали **стойностите** на два обекта са еднакви (еквивалент на `.Equals()` в C#).
    2.  **`is` (Identity):** Проверява дали двете имена сочат към **абсолютно същия физически адрес в RAM паметта** (еквивалент на `Object.ReferenceEquals()` в C#).
    *   *Скритата уловка (Integer Interning):* Python кешира в паметта числата от `-5` до `256`. Затова `a = 10; b = 10; a is b` връща `True`. Но при `a = 500; b = 500; a is b` Python създава два отделни обекта в паметта и `is` връща **`False`**! Затова `is` се използва **единствено** за проверка срещу `None` (`if data is None:`).
