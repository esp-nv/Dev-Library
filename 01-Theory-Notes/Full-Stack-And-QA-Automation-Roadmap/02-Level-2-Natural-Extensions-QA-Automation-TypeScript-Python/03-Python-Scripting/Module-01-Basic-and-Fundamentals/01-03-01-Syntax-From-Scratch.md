## 1. СЪЗДАВАНЕ И ДОСТЪП ПО ИНДЕКС

Списъците се ограждат с **квадратни скоби `[]`**, а елементите се разделят със запетая.

```python
# Създаване на списъци
empty_list = []
fruits = ["ябълка", "банан", "череша", "киви"]
mixed = [10, "текст", True, 3.14]

# Достъп по индекс (броенето започва от 0!)
print(fruits[0])    # Първи елемент -> "ябълка"
print(fruits[1])    # Втори елемент -> "банан"
print(fruits[-1])   # Последен елемент -> "киви"
print(fruits[-2])   # Предпоследен елемент -> "череша"

# Промяна на елемент по индекс
fruits[1] = "портокал"
print(fruits)       # ['ябълка', 'портокал', 'череша', 'киви']
```

## 2. ОСНОВНИ МЕТОДИ ЗА ДОБАВЯНЕ И ИЗТРИВАНЕ

```python
tasks = ["код", "тест"]

# ДОБАВЯНЕ
tasks.append("деплой")          # Добавя в КРАЯ -> ['код', 'тест', 'деплой']
tasks.insert(1, "ревю")         # Вмъква на индекс 1 -> ['код', 'ревю', 'тест', 'деплой']

# ИЗТРИВАНЕ
tasks.remove("ревю")            # Търси и трие ПЪРВОТО срещане на стойността "ревю"
last_item = tasks.pop()         # Премахва и ВРЪЩА последния елемент ("деплой")
first_item = tasks.pop(0)       # Премахва и ВРЪЩА елемента на индекс 0 ("код")
tasks.clear()                   # Изпразва целия списък -> []
```

## 3. ПРОВЕРКИ, ДЪЛЖИНА И СЪЕДИНЯВАНЕ (SPLIT И JOIN)

```python
numbers = [5, 10, 15, 10, 20]

# Дължина и броене
print(len(numbers))             # Брой елементи -> 5
print(numbers.count(10))        # Колко пъти се среща 10 -> 2

# Проверка дали елемент съществува (in / not in)
if 15 in numbers:
    print("Числото 15 е в списъка!")

# Превръщане на текст в списък (split) и списък в текст (join)
raw_input = "10, 20, 30"
parts = raw_input.split(", ")   # Резултат: ['10', '20', '30'] (списък от текстове)

joined_text = " - ".join(parts) # Резултат: "10 - 20 - 30" (работи само ако елементите са str!)
```

## 4. ОБХОЖДАНЕ НА СПИСЪК С ЦИКЪЛ И ВЛОЖЕНИ ПРОВЕРКИ

```python
grades = [6, 4, 5, 2, 6]

# Вариант 1: Директно по елементи (най-често използваният начин)
for grade in grades:
    if grade >= 5:
        print(f"Висока оценка: {grade}")

# Вариант 2: Когато ти трябват И индексът, И стойността едновременно (enumerate)
for index, grade in enumerate(grades):
    print(f"Позиция {index} -> Оценка: {grade}")
```

## 5. ОБОБЩЕНИЕ / БЪРЗ CHEAT SHEET

| Действие | Синтаксис | Пример / Резултат |
| :--- | :--- | :--- |
| **Създаване на списък** | `arr = [1, 2, 3]` | Квадратни скоби `[]` |
| **Първи / Последен елемент** | `arr[0]` / `arr[-1]` | Връща стойността на индекса |
| **Брой елементи** | `len(arr)` | Връща `int` (дължината) |
| **Добавяне в края** | `arr.append(x)` | Добавя `x` отдясно |
| **Вмъкване на позиция** | `arr.insert(idx, x)` | Вмъква `x` на индекс `idx` |
| **Изтриване по стойност** | `arr.remove(x)` | Трие първото `x` (гърми ако го няма) |
| **Изтриване по индекс** | `arr.pop(idx)` | Без аргумент трие последния |
| **Проверка за наличие** | `if x in arr:` | Връща `True` или `False` |
| **Текст ➔ Списък** | `text.split(" ")` | Разделя текста по интервал |
| **Списък ➔ Текст** | `", ".join(arr)` | Слепва списък от `str` в един текст |
