## 1. КАК ДА СЕ ЗАПОМНИ И ЧЕТЕ ПО-ЛЕСНО (МНЕМОНИКА)

*   **Еквивалент в C# и JS:** Списъкът в Python (`list`) не е обикновен статичен масив (`int[]`), а е пълният аналог на **`List<object>` в C#** или **`Array` в JavaScript**. Той може да расте, да се свива и да пази различни типове данни едновременно.
*   **Отрицателни индекси:** Представи си списъка като затворен кръг. Индекс `0` е първият елемент отляво, а индекс `-1` е последният елемент отдясно (`-2` е предпоследният и т.н.).

---

## 2. ЕТАПИ НА РАБОТА В ПАМЕТТА И БЛОК-СХЕМА

Списъкът в Python е **изменяем (Mutable)** референтен обект. Вътре в RAM паметта той не пази самите стойности една до друга, а пази масив от указатели (Pointers) към реалните обекти.

```text
Списък: items = ["A", 42, True]

┌───────────────────────────────┐
│   List Обект (Mutable)        │
├───────────┬───────────┬───────┤
│ Индекс 0  │ Индекс 1  │ Индекс 2 │
│ (Индекс -3)│ (Индекс -2)│ (Индекс -1)│
└─────┬─────┴─────┬─────┴───┬───┘
      │           │         │
      ▼           ▼         ▼
  [ "A" ]      [ 42 ]    [ True ]   (Отделни обекти в RAM)
```

## 3. АРХИТЕКТУРНО СРАВНЕНИЕ: PYTHON СРЕЩУ C# И JAVASCRIPT

| Операция | Python `list` | C# `List<T>` | JavaScript `Array` |
| :--- | :--- | :--- | :--- |
| **Смесени типове** | Да (`[1, "a", True]`) | Не (освен `List<object>`) | Да (`[1, "a", true]`) |
| **Добавяне в края** | `list.append(x)` | `list.Add(x)` | `array.push(x)` |
| **Премахване от края** | `list.pop()` | `list.RemoveAt(Count - 1)` | `array.pop()` |
| **Дължина на списъка** | `len(list)` (функция!) | `list.Count` (свойство) | `array.length` (свойство) |
| **Отрицателен индекс** | `list[-1]` (последният) | `list[^1]` (C# 8.0+) | `array.at(-1)` (ES2022) |

## 4. ПЛЮСОВЕ И МИНУСИ НА СПИСЪЦИТЕ

### 🟢 Предимства (Pros):
*   **Светкавично четене по индекс O(1):** Достъпът до `items[5000]` отнема константно време, независимо колко е голям списъкът.
*   **Изключително гъвкави:** Поддържат вградени операции за обръщане, сортиране, броене и рязане (Slicing).

### 🔴 Недостатъци (Cons):
*   **Бавно вмъкване в началото O(n):** Ако вмъкнеш елемент на позиция `0` (`insert(0, x)`), Python трябва да премести всички останали елементи с една позиция надясно в паметта.
*   **По-висок разход на памет:** Заделя допълнителен буфер (Over-allocation) при растеж, за да не преоразмерява паметта при всяко `append()`.

## 5. КОДОВ ОДИТ: ПРАВИЛЕН СРЕЩУ ГРЕШЕН КОД (И КОМЕНТАРИ)

### ❌ ГРЕШЕН КОД (Капан с референтно копиране и премахване в цикъл):
```python
# 🚨 ГРЕШКА 1: Повърхностно присвояване (не създава копие!)
original = [1, 2, 3]
fake_copy = original
fake_copy.append(99)  # Променя И original! Вече и двата са [1, 2, 3, 99]

# 🚨 ГРЕШКА 2: Изтриване на елементи докато въртим цикъл върху същия списък
numbers = [10, 20, 30, 40]
for num in numbers:
    if num % 20 == 0:
        numbers.remove(num)  # Пропуска елементи, защото индексите се изместват!
```
*   **Как да се избегне:** Копирай списък само с `.copy()` или `[:]`. Никога не трий елементи директно в цикъл — обхождай копие на списъка (`for num in numbers.copy():`).

### 🟢 ПРАВИЛЕН КОД (Безопасно копиране и филтриране):
```python
# 1. Истинско независимо копиране в паметта
base_ports = [80, 443, 8080, 3000]
backup_ports = base_ports.copy()
backup_ports.append(5432)

print(f"Оригинал: {base_ports}")
print(f"Копие:    {backup_ports}")

# 2. Безопасно премахване чрез итерация върху копие
for port in backup_ports.copy():
    if port < 1000:
        backup_ports.remove(port)

print(f"Филтрирани високи портове: {backup_ports}")
```
*   **Изход в конзолата:**
    ```text
    Оригинал: [80, 443, 8080, 3000]
    Копие:    [80, 443, 8080, 3000, 5432]
    Филтрирани високи портове: [8080, 3000, 5432]
    ```

## 6. ИНТЕРВЮ КАПАНИ, ВЪПРОСИ И УЛОВКИ

*   **Въпрос на интервюто:** *„Каква е разликата между методите `list.sort()` и вградената функция `sorted(list)` в Python?“*
*   **Уловката:** Кандидатите често пишат `new_list = my_list.sort()` и получават `None`!
*   **Точен Senior отговор:** 
    1.  **`my_list.sort()`:** Сортира списъка **на място (In-Place)** в паметта, променяйки оригинала директно, и **връща `None`**.
    2.  **`sorted(my_list)`:** Не докосва оригиналния списък, а създава и **връща изцяло нов сортиран списък** (работи и върху всякакви други колекции, не само списъци).
