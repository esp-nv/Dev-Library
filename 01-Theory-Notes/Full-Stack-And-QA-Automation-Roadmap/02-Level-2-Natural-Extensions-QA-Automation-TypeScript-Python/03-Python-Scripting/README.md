# Модул 3: Python Scripting & Software Engineering (Пълен Архитектурен Справочник)

Тази директория съдържа декуплиран на модули и атомарни подточки практически и теоретичен атлас за езика Python 3.x. Всеки отделен файл е разработен като пълноценно инженерно ръководство, включващо синтактичен код с коментари и изход, анализ на грешки, ASCII блок-схеми, сравнителни таблици спрямо C# и JavaScript, както и скрити капани и въпроси за технически интервюта.

## 🧭 Навигация на Модулите

### 📂 [Module 01: Basic and Fundamentals](Module-01-Basic-and-Fundamentals/README.md)
*   **Обхваща:** Уводен Roadmap (`01-00`), базов синтаксис и цикли (`01-01`), типове данни (`01-02`), списъци (`01-03`, `01-05`), функции (`01-04`), речници (`01-06`), побитови операции (`01-07`), текстообработка (`01-08`) и регулярни изрази (`01-09`).

### 📂 [Module 02: Advance](Module-02-Advance/README.md)
*   **Обхваща:** Увод (`02-00`), стекове и опашки (`02-01`), кортежи и множества (`02-02`), многомерни матрици (`02-03`), напреднали функции (`02-04`), управление на грешки (`02-05`) и работа с файлова система (`02-06`).

### 📂 [Module 03: OOP (Object-Oriented Programming)](Module-03-OOP/README.md)
*   **Обхваща:** Увод в ООП (`03-00`), класове и обекти (`03-01`), наследяване (`03-02`), капсулация (`03-03`), статични методи (`03-04`), полиморфизъм и абстракция (`03-05`), SOLID принципи (`03-06`), итератори и генератори (`03-07`), декоратори (`03-08`), автоматизирано тестване (`03-09`) и дизайн патерни (`03-10`).
