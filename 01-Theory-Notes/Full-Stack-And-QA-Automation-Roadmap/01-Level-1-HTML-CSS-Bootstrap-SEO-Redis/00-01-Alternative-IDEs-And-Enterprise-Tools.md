## 1. MICROSOFT VISUAL STUDIO (ТЕЖКИЯТ АРТИЛЕРИЙСКИ МОНОЛИТ)

*   **Философия:** Пълнофункционална, тежка среда за разработка (Heavyweight IDE), създадена от Microsoft специално за .NET средите. За разлика от VS Code, Visual Studio идва с всичко инсталирано по подразбиране — компилатори, SQL мениджъри, профилири за памет и Docker поддръжка.
*   **Кога се използва:** Златен стандарт за изграждане на мащабни Enterprise Monolith MVC системи и Clean Architecture решения.
*   **Плюсове:** Най-мощният бекенд дебъгер в света, перфектна native интеграция с MS SQL Server и Entity Framework Core миграции.

---

## 2. JETBRAINS СРЕДИ: RIDER, WEBSTORM И INTELLIJ IDEA

Компанията **JetBrains** създава среди, които се задвижват от изключително мощни вградени алгоритми за статичен анализ на кода (IntelliSense).

*   **JetBrains Rider:** Крос-платформено IDE за .NET, което работи еднакво бързо на Windows, Linux и Mac (изключително популярно сред програмисти, които пишат C# на MacBook).
*   **JetBrains WebStorm:** Специализирано IDE единствено за **Фронтенд разработка (JavaScript, TypeScript, Angular, React, Node.js)**. Притежава най-мощното автодопълнение за HTML5 тагове, CSS Box Model изчисления и Tailwind класове в движение.
*   **IntelliJ IDEA:** Първоначално създадена като №1 среда за Java, но благодарение на разширената си екосистема поддържа перфектно HTML5, JavaScript и SQL. Тя автоматично засича дублирани кодови фрагменти в паметта и извършва дълбок одит на данните (Data Flow Analysis).

---

## 3. ТРАДИЦИОННИ И ОЛЕКОТЕНИ СРЕДИ: NETBEANS И SUBLIME TEXT 3

*   **Apache NetBeans:** Напълно безплатна среди с отворен код. Притежава интуитивен графичен интерфейс с влачене и пускане (Drag-and-Drop). Силната ѝ страна е в **Семантичното подчертаване на кода** (Highlighting не просто правописа, а логическата роля на уеб елементите), което помага за писане на код без уеб бъгове (FindBug интеграция).
*   **Sublime Text 3:** Свръхбърз, изключително лек и гъвкав текстов редактор. Не товари процесора и RAM паметта. Притежава вградена поддръжка за Macros и готови софтуерни Snippets. Идеален избор, когато ти трябва спешно отваряне и бърза козметична поправка на тежък HTML или CSS файл.

## 5. СИСТЕМНИ КАПАНИ: ПРЕТОВАРВАНЕ НА RAM ПАМЕТТА И СРИВОВЕ ПРИ ЛИЦЕНЗИ

### 🚨 Капан №1: Лаптопът забива и затваря Kestrel сървъра при старт на Visual Studio
*   **Какво правиш:** Имаш компютър с 8 GB RAM памет. Стартираш Visual Studio 2022, за да пуснеш твоя DbContext, пускаш Docker контейнер за Redis и едновременно с това отваряш Chrome браузъра с 10 таба за проверка на CSS дизайна.
*   **Точен софтуерен краш (Exception Message) в Windows:**
    ```text
    Your computer is low on memory. To restore enough memory for programs to work correctly, save your files and close all open windows.
    (Process terminated due to StackOverflowException or OutOfMemoryException)
    ```
*   **Защо се случва:** За разлика от лекия VS Code или Sublime Text, традиционното Visual Studio заделя насила между 2 GB и 4 GB от твоята RAM памет веднага при стартиране само за поддръжка на вътрешния си компилационен индекс. Паметта свършва и операционната система убива уеб нишките.
*   **Как да го избегнеш (Инженерно решение):** Ако хардуерът ти е ограничен, спазвай **декуплиран изпитен режим**: пиши HTML/CSS и фронтенд единствено в лекия VS Code, а тежките среди като Visual Studio или Rider ги пускай само тогава, когато се налага да правиш EF Core миграции или дебъгване на базата данни.
