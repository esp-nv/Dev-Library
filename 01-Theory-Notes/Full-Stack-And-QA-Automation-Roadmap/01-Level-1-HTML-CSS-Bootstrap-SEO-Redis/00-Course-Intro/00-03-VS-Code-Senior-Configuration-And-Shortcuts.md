## 1. ТОП 5 ЗАДЪЛЖИТЕЛНИ РАЗШИРЕНИЯ (EXTENSIONS) ЗА ЕФЕКТИВНОСТ

Инсталирай тези инструменти директно от Extensions таба (`Ctrl+Shift+X`) за бърза работа:
1.  **Live Server:** Най-критичното разширение. Вдига моментално локален уеб сървър и отваря сайта ти в браузъра. **При всяко натискане на Запис (Save), страницата в браузъра се опреснява автоматично на мига.**
2.  **Auto Rename Tag:** Когато промениш името на отварящия HTML таг (напр. от `<div>` на `<section>`), това разширение автоматично пренаписва и затварящия таг, елиминирайки правописните грешки.
3.  **Prettier - Code formatter:** Професионален софтуерен разкрасител. Подрежда автоматично отстъпите, скобите и подравняванията на кода при запис.
4.  **Tailwind CSS IntelliSense:** Добавя автодопълнение, подсказки и пикселни обяснения за абсолютно всеки атомарен клас на Tailwind, докато пишеш в HTML документа.
5.  **Path Intellisense:** Автодопълва пътищата до снимки или CSS файлове, предпазвайки те от грешно изписване на адреси.

| Прек Път (Windows) | Прек Път (Mac) | Какво прави в софтуера? (Ефект за скорост) |
| :--- | :--- | :--- |
| `Alt + Up / Down` | `Option + Up / Down` | **Премества целия текущ ред** нагоре или надолу, без рязане. |
| `Shift + Alt + Down`| `Shift + Option + Down`| **Двойно мултиплициране / Копиране** на редове веднага надолу. |

## 3. НАСТРОЙКА НА РЪЧНИ СНИПЕТИ ПРЕЗ JSON (CUSTOM SNIPPETS)

Emmet е вграден инструмент, който ти позволява да пишеш бързо (напр. написваш `!` и натискаш `Tab` ➔ генерира се цял HTML скелет). Какво правим обаче, ако искаме да си направим наш собствен, персонализиран изпитен Snippet за бърза форма или бутони?

### ⚙️ Инструкция за настройка:
1. Отиди на `File` ➔ `Preferences` ➔ `Configure User Snippets` (или `Code` ➔ `Settings` на Mac).
2. Избери тип на файла: **`html.json`**.
3. Изтрий коментарите и постави следния софтуерен JSON код:

```json
{
  "SoftUni Perfect Form Reset": {
    "prefix": "softuni-form",
    "body": [
      "<div class=\"form-group-card shadow-sm p-4 rounded border\">",
      "\t<form action=\"/api/v1/\${1:endpoint}\" method=\"POST\">",
      "\t\t<label for=\"\({2:fieldId}\" class=\"form-label\">\){3:LabelText}:</label>",
      "\t\t<input type=\"text\" id=\"\({2:fieldId}\" name=\"\){2:fieldId}\" class=\"form-control\" required placeholder=\"Въведете данни...\">",
      "\t\t<button type=\"submit\" class=\"btn btn-primary mt-3\">\${4:SubmitText}</button>",
      "\t</form>",
      "</div>"
    ],
    "description": "Генерира защитена HTML уеб форма с готови name и class атрибути за изпити"
  }
}
```

### 🧱 Как се вика в кода?
Отвори произволен HTML файл, напиши в празен ред късата дума **`softuni-form`** и натисни клавиша **`Tab`**. Снапсетът ще изплюе целия готов кодов блок за частица от секундата, а курсорът ти автоматично ще застане на полето `${1:endpoint}`, позволявайки ти да скачаш между параметрите с бутона `Tab`!

## 4. СИСТЕМНИ КАПАНИ: КОНФЛИКТИ С AUTO-SAVE И СЧУПЕНА EMMET ПОДДРЪЖКА

### 🚨 Капан №1: Live Server не отразява промените в браузъра (The Missing Save)
*   **Какво правиш:** Пишеш код, гледаш към Chrome браузъра, но екранът стои бял или не се променя.
*   **Защо се случва:** По подразбиране VS Code изисква изрично да натиснеш комбинацията `Ctrl + S`, за да запише промените на хард диска. Докато файлът не е записан, Live Server няма как да знае за новия код. На изпити под стрес лесно се забравя за записването.
*   **Как да го поправиш:** Включи автоматичното записване на файлове. Отиди на най-горното меню `File` и кликни върху отметката **`Auto Save`**. Сега, в същата милисекунда, в която спреш да пишеш, VS Code записва кода сам и Live Server опреснява браузъра незабавно.
