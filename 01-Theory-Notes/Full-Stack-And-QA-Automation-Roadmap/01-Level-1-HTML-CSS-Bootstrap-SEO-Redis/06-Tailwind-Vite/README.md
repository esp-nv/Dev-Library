# Подмодул: Напреднал Tailwind CSS v4 с компилация през Vite

Този сектор съдържа детайлно структуриран, сертифициран архитектурен атлас за работа с Tailwind CSS v4, интегриран през свръхбързия кеширащ софтуер Vite. Документацията е разделена на атомарни подточки по категории от официалната спецификация, снабдени с готови производствени конфигурации, капани и кодови фрагменти.

## 🧭 Официална Навигация на Подмодулите

*   **[06-00. Инсталация и Конфигурация: Комплексно ръководство за Tailwind + Vite](06-00-Tailwind-Vite-Installation-Guide.md)**
    *   *Обхваща:* Инициализиране на Vite проект, инсталиране на `@tailwindcss/vite` плъгин, `@import` директиви и отстраняване на компилационни сривове.
*   **[06-01. Справочник Категория 1: Структура, Концепции и Подредба (Layout, Flexbox & Grid)](06-01-Core-Concepts-Layout-Flexbox-Grid.md)**
    *   *Обхваща:* Styling с utility класове, интерактивни състояния (:hover, :focus), адаптивен дизайн, Box-Sizing, Display, Flex-basis, Grid-Templates, Gap и подравнявания.
*   **[06-02. Справочник Категория 2: Декорации и Спецификации (Spacing, Sizing, Typography, Borders, Effects)](06-02-Spacing-Sizing-Typography-Borders-Effects.md)**
    *   *Обхваща:* Матрица на вътрешните и външните отстояния (`p-`, `m-`), пропорции на широчина и височина (`w-full`, `h-screen`), типография и размери на шрифтове (`font-semibold`, `leading-relaxed`), заобляне на рамки (`rounded-xl`), сенки, прозрачност и коригиране на сривове при произволни пикселни размери през квадратни скоби `[...]`.
