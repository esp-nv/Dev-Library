## 1. СВОЙСТВА НА ШРИФТОВЕТЕ: ФАМИЛИИ И РЕЗЕРВНИ ПЛАНОВЕ

Свойството `font-family` задължително изисква резервен софтуерен заден ход (Fallback font):
```css
body {
    font-family: 'Poppins', Arial, sans-serif; /* Ако Poppins липсва, чете Arial. Ако и той липсва - пуска дефолтния sans-serif */
}
```

---

## 2. УЕБ МЕРНИ ЕДИНИЦИ ПОД ЛУПА (PX VS. EM VS. REM)

*   **`px` (Pixels):** Абсолютна мерна единица. Текстът си остава твърдо закован, без да го интересува големината на екрана.
*   **`em`:** Относителна единица. Изчислява размера спрямо шрифта на **директния родителски контейнер** (води до риск от неконтролируемо каскадно натрупване).
*   **`rem` (Root EM):** **Златен архитектурен стандарт.** Изчислява размерите на целия сайт чисто, спрямо една обща основа — шрифта на най-външния таг `<html>` (по подразбиране 1rem = 16px).

---

## 3. СИГУРНО ИМПОРТИРАНЕ НА ИЗПИТНИ УЕБ ШРИФТОВЕ

За да застраховаш кода си пред headless браузъра на Judge (който няма твоите локални операционни шрифтове), винаги импортирай стила направо от CDN сървърите в първия ред на CSS файла:

```css
@import url('https://googleapis.com');
```
