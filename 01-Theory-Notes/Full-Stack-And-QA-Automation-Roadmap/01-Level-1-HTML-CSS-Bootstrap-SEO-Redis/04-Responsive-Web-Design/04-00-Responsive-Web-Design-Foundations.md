## 1. ЕВОЛЮЦИЯ НА ДОСТЪПА: КАКВО Е RESPONSIVE WEB DESIGN?

В зората на мобилния интернет, софтуерните инженери изграждаха изцяло отделни уеб страници за мобилни телефони, хоствани на поддомейни от типа `://mysite.com`. Този модел изискваше поддръжка на два дублиращи се проекта и пренасочване на потребителския трафик на базата на сървърни логове.

**Responsive Web Design (Отзивчив/Адаптивен дизайн)** въвежда коренно различен подход: един единствен HTML документ и един общ CSS файл обслужват абсолютно всички хардуерни устройства в света. Браузърът на клиента получава същите байтове памет, но графичният двигател автоматично преоразмерява, свива и пренарежда елементите на екрана в реално време.

---

## 2. ПРИНЦИПЪТ НА ФЛУИДНИТЕ ОФОРМЛЕНИЯ (FLUID LAYOUTS)

Основата на всеки адаптивен сайт е замяната на твърдите, статични пикселни размери с **относителни и флуидни измерватели**:
*   Вместо широчина `width: 960px;`, контейнерите приемат процентови стойности (`width: 100%;` или `width: 50%;`).
*   Елементите започват да се държат като течност — те заемат точно толкова пространство, колкото им заделя родителският контейнер, напасвайки се плавно при разтягане на уеб прозореца.

---

## 3. КОНЦЕПЦИЯТА ЗА АДАПТИВНОСТ (ADAPTIVE) СРЕЩУ ОТЗИВЧИВОСТ (RESPONSIVE)

Официалната теория разграничава двата подхода по начина, по който реагират на промяната на екрана:
*   **Adaptive Layout (Адаптивен):** Разчита на фиксирани кутии, които се подменят рязко на „стъпки“ само тогава, когато прозорецът на браузъра премине определена граница. Между тези граници дизайнът остава напълно статичен.
*   **Responsive Layout (Отзивчив):** Стъпва на флуидни мрежи, които се свиват плавно до последния пиксел, комбинирани с контролни точки за пренареждане на елементите, осигурявайки плавен визуален преход.
