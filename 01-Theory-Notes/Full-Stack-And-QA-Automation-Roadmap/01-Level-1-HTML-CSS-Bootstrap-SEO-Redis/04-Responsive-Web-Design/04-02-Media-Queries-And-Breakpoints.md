## 1. СИНТАКСИС И АНАТОМИЯ НА УЕБ MEDIA QUERIES

**Медийните заявки (`@media`)** представляват мощен декларативен механизъм в CSS3, който позволява прилагането на специфични стилови правила само тогава, когато устройството на потребителя отговаря на определени технически критерии (като вид на екрана или широчина на изгледа в пиксели).

Анатомията на една класическа медийна заявка се състои от дефиниране на медиен тип (`Media Type`) и медийна характеристика (`Media Feature`), затворена в скоби:

```css
/* Базовият стил се прилага по подразбиране */
.site-sidebar {
    width: 300px;
}

/* Изричен филтриращ прозорец за екрани с малка широчина */
@media screen and (max-width: 768px) {
    .site-sidebar {
        width: 100%; /* Пренаписва предходното правило, ако условието е вярно */
    }
}
```

## 2. ЛОГИЧЕСКИ ОПЕРАТОРИ ЗА ФИЛТРАЦИЯ НА УЕБ СТИЛОВЕ

За изграждане на комплексни и прецизни медийни граници, CSS осигурява поддръжка на логически оператори:
*   **`and`**: Комбинира няколко условия заедно. Свойството се задейства само ако всички критерии са верни едновременно (напр. `@media (min-width: 768px) and (max-width: 1024px)` за прецизно изолиране на таблети).
*   **`not`**: Негира (обръща) смисъла на медийната заявка, прилагайки стиловете над абсолютно всички екрани, освен над дефинирания тип.
*   **`,` (Запетая / Логическо ИЛИ)**: Изпълнява ролята на оператора OR. Стилът се прилага, ако поне едно от изброените условия е вярно.

---

## 3. СТАНДАРТНИ ИНДУСТРИАЛНИ КОНТРОЛНИ ТОЧКИ (BREAKPOINTS)

За да се избегне писането на отделни стилове за стотиците съществуващи модели смартфони и лаптопи, софтуерната индустрия е наложила пет стандартни и заковани **Контролни точки (Breakpoints)**, базирани на масовите хардуерни категории:

1.  **`576px`**: Мобилни телефони в хоризонтален (Landscape) режим или по-големи смартфони.
2.  **`768px`**: Таблети (в портретен режим).
3.  **`992px`**: Големи таблети, хоризонтални екрани и малки преносими компютри (Лаптопи).
4.  **`1200px`**: Стандартни десктоп монитори.
5.  **`1400px`**: Широкоекранни и високорезолюционни Enterprise дисплеи.
