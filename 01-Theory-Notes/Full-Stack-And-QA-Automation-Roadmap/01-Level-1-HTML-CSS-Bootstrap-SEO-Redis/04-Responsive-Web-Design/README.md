# Глава 04. Адаптивен дизайн (Responsive Web Design — Спецификация)

Тази директория съдържа декуплиран на подточки архитектурен атлас за изграждане на мобилно-оптимизирани уеб интерфейси. Структурата следва плътно хронологията на лекциите, обособявайки инженерните интервюта и бързите пищови в специализирани производствени модули.
