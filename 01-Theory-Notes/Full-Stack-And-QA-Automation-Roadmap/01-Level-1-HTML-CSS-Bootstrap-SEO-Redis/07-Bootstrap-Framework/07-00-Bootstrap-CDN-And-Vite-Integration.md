## 1. КАКВО Е BOOTSTRAP V5.3 И УВОР В ЕКОСИСТЕМАТА

**Bootstrap v5.3** е най-използваната в света уеб рамка (Framework) с отворен код за бързо изграждане на адаптивни, мобилно-оптимизирани уеб сайтове. Той предоставя огромна база данни от предварително компилирани CSS стилове, решетки, типографски правила и интерактивни JavaScript компоненти. 

За разлика от Tailwind (който изисква да сглобяваш всичко от нулата), Bootstrap работи по модела на **Компонентния дизайн** — той ти дава готови, готови за употреба класове за цели интерфейси (напр. `class="btn btn-primary"`).

---

## 2. БЪРЗА CDN ИНТЕГРАЦИЯ ЧРЕЗ JSDELIVR

Най-простият и бърз начин за включване на Bootstrap v5.3 е чрез връзка към **CDN (Content Delivery Network)** сървърите на jsDelivr. При този модел не изтегляш файлове на диска, а браузърът ги чете директно от облака:

```html
<head>
    <!-- 1. Свързване на компилирания суров Bootstrap CSS стил -->
    <link href="https://jsdelivr.net" rel="stylesheet">
</head>
<body>
    <!-- 2. Свързване на пакетирания JavaScript за интерактивност преди затварящия body таг -->
    <script src="https://jsdelivr.net"></script>
</body>
```

## 3. ПРОФЕСИОНАЛНО СГЛОБЯВАНЕ И КОМПИЛАЦИЯ ПРЕЗ VITE

При реални софтуерни проекти и напреднали Full-Stack среди, Bootstrap се инсталира като локален Node модул и се компилира от двигателя **Vite**:

### 🛠️ Стъпка 1: Инсталация през терминала:
```bash
npm install bootstrap @popperjs/core
```
*(Пакетът `@popperjs/core` е задължителна нисконивова зависимост за правилното изчисляване на координатите на падащите менюта и подсказките).*

### 🛠️ Стъпка 2: Импортиране в софтуерния поток:
*   В твоя главен JavaScript файл (напр. `src/main.js`):
    ```javascript
    import 'bootstrap/dist/css/bootstrap.min.css';
    import 'bootstrap/dist/js/bootstrap.bundle.min.js';
    ```

След стартиране на `npm run dev`, Vite хваща тези нишки, оптимизира суровия обем и отваря проекта на локален порт за разработка.
