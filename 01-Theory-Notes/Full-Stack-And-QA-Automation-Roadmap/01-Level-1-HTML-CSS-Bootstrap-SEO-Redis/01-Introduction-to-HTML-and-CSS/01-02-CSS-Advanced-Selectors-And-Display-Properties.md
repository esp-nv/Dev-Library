## 1. НАПРЕДНАЛИ СЕЛЕКТОРИ: АТРИБУТИ И КОМБИНАТОРИ

Освен по клас и ID, CSS ни позволява да филтрираме елементите въз основа на техните HTML атрибути или софтуерни релации:
*   **Атрибутен селектор:** `input[type="password"]` ➔ Насочва се единствено към полетата за парола, спестявайки ни писането на допълнителни класове.
*   **Директен наследник (Child Combinator):** `div > p` ➔ Стилизира само параграфите, които са *директни деца* на дива, пропускайки по-дълбоко вложените (Grandchildren).
*   **Съседен елемент (Adjacent Sibling):** `h2 + p` ➔ Таргетира първия параграф, който се намира *непосредствено след* заглавие `<h2>`.

---

## 2. ПСЕВДО-КЛАСОВЕ И ПСЕВДО-ЕЛЕМЕНТИ

*   **Псевдо-класове (Pseudo-classes):** Стилизират елемента при промяна на софтуерното му състояние.
    *   `:focus` ➔ Активира се, когато потребителят кликне вътре в даден инпут за писане.
    *   `:nth-child(odd)` / `:nth-child(even)` ➔ Автоматично филтрира само нечетните или четните редове в таблица (идеално за изпитни Judge задачи с редуващи се цветове).
*   **Псевдо-елементи (Pseudo-elements):** Генерират изкуствено съдържание на екрана през CSS, без да променят HTML документа.
    *   `::before` и `::after` ➔ Инжектират козметични елементи (иконки, линии, декорации) съответно най-отпред или най-отзад на текста. **Задължително изискват свойството `content: "";`**, иначе браузърът ги игнорира.

---

## 3. РАЗГЛОБЯВАНЕ НА ДИСПЛЕЯ: BLOCK VS. INLINE VS. INLINE-BLOCK VS. NONE

Свойството **`display`** определя софтуерното поведение на кутията в DOM структурата:

1.  **`display: block;`** ➔ Елементът заема 100% от широчината на контейнера и винаги започва на нов ред насила. Приема `width`, `height`, `margin` и `padding`. (напр. `<div>`, `<p>`, `<h1>`).
2.  **`display: inline;`** ➔ Елементът заема само толкова място, колкото е дълъг самият му текст, и стои на една линия със съседните елементи. **Закон: Напълно игнорира вертикален `height`, `width` и горни/долни `margins`!** (напр. `<span>`, `<a>`, `<strong>`).
3.  **`display: inline-block;`** ➔ Хибриден изпитен контекст. Елементът стои на един ред със съседните обекти (като inline), но приема свободно `width`, `height` и вертикални отстъпи (като block).
4.  **`display: none;`** ➔ Скрива елемента напълно от уеб екрана и го изтрива от графичното пространство. Съседните елементи се свиват и заемат мястото му.

## 4. СИСТЕМНИ КАПАНИ: СЧУПЕНИ ВЕРТИКАЛНИ РАЗМЕРИ НА INLINE ЕЛЕМЕНТИ

### 🚨 Капан №1: Опит за налагане на padding/margin над inline таг `<span>` или `<a>`
*   **Какво правиш:** Искаш да направиш красив бутон от уеб линк `<a>`. Налагаш му `width: 200px; height: 50px; margin-top: 30px;`.
*   **Визуален капан:** Браузърът напълно игнорира размерите ти. Бутонът си остава малък, а горното разстояние не избутва нищо, счупвайки изпитната спецификация.
*   **Защо се случва:** По закон елементите с `display: inline` нямат право да променят вертикалното пространство на уеб потока.
*   **Как да го поправиш:** Променете контекста на дисплея към `inline-block`:
    ```css
    a.my-action-btn {
        display: inline-block; /* 🟢 Отключва размерите и вертикалните margins */
        width: 200px;
        height: 50px;
        margin-top: 30px;
    }
    ```

## 5. CHEAT SHEET & SNIPPETS ХЪБ

### 🛠️ Бърз Изпитен Пищов (Cheat Sheet):
*   `tr:nth-child(even) { background-color: #f2f2f2; }` ➔ Златен фикс за **Zebra-striping таблици** (редуващи се сиви и бели редове за лесно четене).
*   `input:focus { border: 2px solid #3b82f6; outline: none; }` ➔ Прави красива синя рамка около полето, в което потребителят пише в момента, и премахва грозния дефолтен черен аутлайн.

### 💾 Готов за директно ползване Snippet: "Таблица с редуващи се редове и Ховър ефект"
```html
<table class="softuni-exam-table">
    <thead>
        <tr><th>ID</th><th>Студент</th><th>Статус</th></tr>
    </thead>
    <tbody>
        <tr><td>101</td><td>Виктор</td><td>Активен</td></tr>
        <tr><td>102</td><td>Мария</td><td>Завършил</td></tr>
        <tr><td>103</td><td>Георги</td><td>Активен</td></tr>
    </tbody>
</table>

<style>
    .softuni-exam-table {
        width: 100%;
        border-collapse: collapse; /* Премахва двойните рамки */
        font-family: sans-serif;
    }
    .softuni-exam-table th, .softuni-exam-table td {
        padding: 12px;
        border: 1px solid #ddd;
        text-align: left;
    }
    /* Автоматично оцветява ЧЕТНИТЕ редове в леко сиво */
    .softuni-exam-table tbody tr:nth-child(even) {
        background-color: #f8fafc;
    }
    /* Ефект при посочване с мишката */
    .softuni-exam-table tbody tr:hover {
        background-color: #f1f5f9;
        cursor: pointer;
    }
</style>
```
