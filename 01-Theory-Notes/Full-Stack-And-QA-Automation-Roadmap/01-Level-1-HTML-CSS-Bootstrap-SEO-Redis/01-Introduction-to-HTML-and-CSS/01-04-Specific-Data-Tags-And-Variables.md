## 1. СЕМАНТИЧНИ ТАГОВЕ ЗА СПЕЦИАЛНИ ТЕКСТОВЕ

На изпитите се изисква прецизно форматиране на специфични текстови данни:
*   **`<blockquote cite="URL">`** ➔ Използва се за дълги, мащабни цитати, извлечени от друг източник. Автоматично добавя голям отстъп отляво и отдясно.
*   **`<pre>` (Preformatted Text)** ➔ Изключително важен таг. Спира автоматичното изчистване на интервали и нови редове от браузъра. Рендерира текста абсолютно точно така, както е написан в C# или HTML файла (използва фиксиран Monospace шрифт).
*   **`<code>`** ➔ Маркира софтуерни фрагменти, програмни променливи или кодове. Обикновено се влага вътре в `<pre>` тага.

## 2. ГЛОБАЛНО КАПСУЛИРАНЕ ПРЕЗ CSS ПРОМЕНЛИВИ (:ROOT)

За да не пишем един и същ цвят (`#2563eb`) на 50 места в CSS файла, модерният стандарт налага използването на **CSS Custom Properties (Променливи)**. Те се дефинират в псевдо-селектора **`:root`** (който представлява най-високото възможно ниво — целия HTML документ) и се викат чрез функцията **`var(--име)`**:

```css
/* 1. ДЕФИНИРАНЕ НА ЦЕНТРАЛНИТЕ ЦВЕТОВЕ: */
:root {
    --primary-color: #2563eb;
    --success-color: #10b981;
    --border-radius-base: 8px;
}

/* 2. ИЗВИКВАНЕ В КОДА: */
.action-button {
    background-color: var(--primary-color);
    border-radius: var(--border-radius-base);
}
```

## 3. СИСТЕМНИ КАПАНИ: ИЗТИЧАНЕ НА НЕВАЛИДНИ ПРОМЕНЛИВИ (THE PROPERTY CRASH)

### 🚨 Капан №1: Грешно име при извикване на var() функцията (The Invisible Color)
*   **Какво правиш:** Написала си `--main-bg: #ff0000;`. По-надолу в кода викаш променливата, но правиш правописна грешка в името: `background-color: var(--man-bg);`.
*   **Визуален капан:** Браузърът не хвърля грешка в конзолата. Той просто засича невалидна стойност, анулира цялото CSS свойство и елементът ти става прозрачен, чупейки дизайна в Judge.
*   **Как да го поправиш:** Проверете дали името вътре в скобите на `var()` съдържа задължителното двойно тире напред и съвпада буква по буква с дефиницията в `:root` секцията.

## 4. СПАСИТЕЛНИ ИЗПИТНИ SNIPPETS

### 💾 Готов за директно ползване Snippet: "Блок за Специфични данни и Код"
```html
<div class="data-display-container">
    <!-- Семантичен цитат -->
    <blockquote cite="https://softuni.bg">
        "Софтуерният инженеринг изисква желязна хигиена на паметта и слоевете."
    </blockquote>
    
    <!-- Сглобен софтуерен кодов блок -->
    <div class="code-wrapper">
        <pre><code>public void CleanMemory() 
{
    GC.Collect(); // Изчиства хлабавата памет
}</code></pre>
    </div>
</div>

<style>
    :root {
        --bg-code-panel: #1e1e1e;
        --text-code-color: #9cdcfe;
    }
    .code-wrapper {
        background-color: var(--bg-code-panel);
        padding: 16px;
        border-radius: 6px;
    }
    .code-wrapper code {
        font-family: 'Consolas', 'Courier New', monospace;
        color: var(--text-code-color);
    }
</style>
```
