## 1. УВОР В УЕБ ЕКОСИСТЕМАТА: КЛИЕНТ СРЕЩУ СЪРВЪР

Всяко съвременно уеб приложение работи въз основа на двупосочния модел **Client-Server Architecture**:
*   **Клиент (Client / Frontend):** Уеб браузърът (Chrome, Firefox), който получава суров текст, интерпретира го и го рендерира визуално на екрана.
*   **Сървър (Server / Backend):** Отдалечена мощна машина, която обработва бизнес логиката, удържа сигурността, комуникира с бази данни и връща готови ресурси обратно към клиента при поискване.

## 3. VS CODE: СЕНЬОР КОНФИГУРАЦИЯ, БЪРЗИ КЛАВИШИ И CUSTOM СНИПЕТИ

Инсталирай разширенията **Live Server**, **Auto Rename Tag** и **Prettier** за максимална скорост под изпитен стрес. Включи **`Auto Save`** от най-горното софтуерно меню `File` [1.53, 1.168].

### 🛠️ Изпитна матрица на Бързите клавиши (Short-keys):
*   `Alt + Up / Down` ➔ Премества целия текущ ред нагоре или надолу, без рязане.
*   `Shift + Alt + Down` ➔ Двойно мултиплициране / Копиране на редове веднага надолу.
*   `Ctrl + /` ➔ Автоматично коментира или разкоментира маркирания код.

### ⚙️ Ръчен Снипет (User Snippets) във файла `html.json`:
```json
{
  "SoftUni Perfect Form Reset": {
    "prefix": "softuni-form",
    "body": [
      "<div class=\"form-group-card shadow-sm p-4 rounded border\">",
      "\t<form action=\"/api/v1/\${1:endpoint}\" method=\"POST\">",
      "\t\t<label for=\"\({2:fieldId}\" class=\"form-label\">\){3:LabelText}:</label>",
      "\t\t<input type=\"text\" id=\"\({2:fieldId}\" name=\"\){2:fieldId}\" class=\"form-control\" required>",
      "\t\t<button type="submit" class="btn btn-primary mt-3">\${4:SubmitText}</button>",
      "\t</form>",
      "</div>"
    ]
  }
}
```

## 4. БРАУЗЪРНА ДИАГНОСТИКА В CHROME DEVTOOLS И МРЕЖОВА ИНТЕГРАЦИЯ

Live Server вдига локален порт `http://127.0.0`. Сплитни екрана си **Side-by-Side** (VS Code отляво, Chrome отдясно) за работа в реално време. Натисни **F12** за отваряне на DevTools:
*   **Табът Console:** Твоят мрежов радар за JS грешки и липсващи файлове.
*   **Табът Elements:** Показа живото DOM дърво в RAM паметта на компютъра ти.

## 5. СИСТЕМНИ КАТАНИ: СРИВОВЕ НА RAM ПАМЕТТА И БРАУЗЪРНИЯ КЕШ

### 🚨 Капан №1: Браузърът показва стария дизайн, въпреки че кодът е записан
*   **Защо се случва:** Браузърът заключва CSS стиловете на твърдия диск в своята **Cache памет** с цел икономия на трафик.
*   **Как да го поправиш:** Отвори DevTools с `F12`. Задръж десен бутон върху бутона Refresh (горе вляво) и избери **`Empty Cache and Hard Reload`**. Браузърът ще изчисти паметта насила и ще изтегли новия код.

### 🚨 Капан №2: Срив OutOfMemoryException при старт на тежки среди (Visual Studio / Rider)
*   **Решение:** На компютри с под 16 GB RAM избягвай тежките софтуерни среди по време на дизайн. Пиши HTML/CSS единствено в олекотения VS Code, а Visual Studio го пускай само за SQL миграции и бекенд.
