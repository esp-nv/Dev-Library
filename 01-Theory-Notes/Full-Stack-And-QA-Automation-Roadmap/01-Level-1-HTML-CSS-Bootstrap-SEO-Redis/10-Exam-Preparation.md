## 1. ИЗПИТНИЯТ АЛГОРИТЪМ: 4 СТЪПКИ ЗА БЪРЗО РАЗПИСВАНЕ ПОД СТРЕС

Когато изпитният таймер стартира, най-голямата софтуерна грешка е да започнеш да пишеш стилове веднага. СЛЕДВАЙ този строго дефиниран 4-стъпков алгоритъм, за да си гарантираш спокойствие:

*   **Стъпка 1: Чисто семантично скелетиране (HTML Първо):** Изгради пълната HTML структура на документа, без да отваряш CSS файла. Използвай изцяло семантични тагове (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`). Сложи `id` и `name` на уеб формите.
*   **Стъпка 2: Глобално CSS нулиране (Reset):** Преди какъвто и да е дизайн, заковай `box-sizing: border-box;`, нулирай `margin` и `padding` и инжектираш шрифтовете в секция `body`.
*   **Стъпка 3: Изграждане на скелетния Layout:** Наложи структурата на големите блокове на екрана. Използвай **Flexbox** за редици, навигации и подравнявания.
*   **Стъпка 4: Микро-декорации (Детайли накрая):** Чак когато уеб сайтът стои стабилно хоризонтално и вертикално без размествания, премини към фините настройки — заоблени ръбове (`border-radius`), сенки (`box-shadow`), цветове и ховър ефекти.

## 2. КАКВО ПРОВЕРЯВА JUDGE ПОД КАПАКА? (КРИТЕРИИ ЗА 100/100)

За разлика от хората, Judge системата не гледа дали сайтът ти е красив. Тя рендерира твоя код в скрит headless браузър и извършва пикселен и структурен одит:
1.  **DOM съответствие:** Проверява дали текстовете ти са в правилните тагове (напр. ако в условието пише, че заглавието на статията трябва да е `<h2>`, а ти си сложила `<h3>` или `<strong>` — тестът ти ще хвърли червена грешка).
2.  **Подравняване по пиксели:** Измерва разстоянията. Ако по спецификация `gap` или `padding` трябва да е `20px`, а ти си заложила `15px` или си разчитала на случайни външни `margins`, Judge ще регистрира визуално разминаване и ще ти отреже точки.

## 3. СИСТЕМНИ КАПАНИ: ГРЕШКИ ПРИ СЧУПЕНИ ШРИФТОВЕ И РАЗМЕСТВАНИЯ

### 🚨 Капан №1: Локално инсталиран шрифт чупи Judge тестовете (The Font Ghost)
*   **Какво правиш:** В условието на изпита се изисква специфичен шрифт (напр. *Poppins*). Ти го имаш инсталиран локално на твоя Windows компютър. Написваш в CSS: `font-family: 'Poppins', sans-serif;`, без да инжектираш външен линк към Google Fonts, защото браузърът ти го чете директно от твоята операционна система.
*   **Точен изход:** На твоя екран всичко изглежда съвършено. Качваш кода в Judge и системата ти връща грешни пиксели и счупени тестове.
*   **Защо се случва:** Сървърът на Judge, на който се тества кодът ти, няма инсталиран твоя локален шрифт. Той автоматично превключва на стандартния `sans-serif` (който има съвсем различни пикселни размери и дължини на буквите). Текстовете ти стават по-дълги, излизат от кутиите и одитът се проваля.
*   **Как да го избегнеш:** Винаги импортирайте външните уеб шрифтове чисто в самия връх на твоя CSS файл чрез директивата `@import`, гарантирайки, че Judge ще изтегли същите байтове памет:
    ```css
    /* 🟢 ПРАВИЛЕН ИЗПИТЕН СТАНДАРТ (Импорт в началото на CSS): */
    @import url('https://googleapis.com');
    
    body {
        font-family: 'Poppins', sans-serif;
    }
    ```

## 4. ГЛОБАЛЕН ИЗПИТЕН CHEAT SHEET И СПАСИТЕЛНИ SNIPPETS

### 🛠️ Бърз Спасителен Пищов (Cheat Sheet):
*   `box-sizing: border-box;` ➔ **Абсолютна застраховка №1**. Спира насилственото раздуване на кутиите от вътрешни разстояния.
*   `display: flex; flex-direction: column;` ➔ Най-бързият начин да подредиш уеб форми или карти вертикално, без размествания.
*   `vertical-align: middle;` ➔ Прикачи това свойство към всички иконки или малки снимки, които стоят до текстове, за да се изравнят в перфектна хоризонтална линия по средата.
*   `text-align: justify;` ➔ Подравнява големи текстови блокове (articles) едновременно отляво и отдясно, изглеждайки корпоративно чист.

### 💾 Готов за директно ползване Snippet: "Желязната Изпитна Сглобка (The Perfect Reset)"
Копирай и постави този тестван, валидиран CSS блок в самия връх на всеки твой изпитен софтуерен файл, за да нулираш мрежовите аномалии на браузърите и да подсигуриш чисти пиксели за Judge:

```css
/* 🏆 СЪВЪРШЕН ИЗПИТЕН RESET И ОПТИМИЗАЦИЯ */
@import url('https://googleapis.com');

*, *::before, *::after {
    box-sizing: border-box; /* Защита от раздуване */
    margin: 0;
    padding: 0;
}

html {
    scroll-behavior: smooth; /* Плавна уеб навигация */
    font-size: 16px; /* Базова изпитна основа */
}

body {
    font-family: 'Inter', sans-serif;
    line-height: 1.6; /* Чисто, неблокиращо междуредие */
    background-color: #f8fafc;
    color: #0f172a;
    -webkit-font-smoothing: antialiased; /* Изглажда пикселите на буквите в Chrome */
}

/* Изпитен фикс за снимки */
img {
    max-width: 100%;
    height: auto;
    display: block; /* Спира инцидентните празни пиксели отдолу */
}

/* Изпитен фикс за уеб линкове */
a {
    color: inherit;
    text-decoration: none; /* Премахва долното подчертаване */
}

/* Изпитен фикс за форми */
input, button, select, textarea {
    font-family: inherit;
    font-size: inherit;
}
```
