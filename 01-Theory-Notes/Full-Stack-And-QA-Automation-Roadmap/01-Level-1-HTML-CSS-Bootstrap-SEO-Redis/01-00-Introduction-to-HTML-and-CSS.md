## 1. АНАТОМИЯ НА HTML5 И ЗАДЪЛЖИТЕЛНИЯТ BOILERPLATE СКЕЛЕТ

Всяка уеб страница в интернет е обикновен текстов документ, чиято структура се дефинира чрез **Тагове (Tags)**. Браузърът чете тези тагове отгоре-надолу и изгражда **DOM дървото** в паметта си.

Всеки изпитен проект задължително стартира със следния чист Boilerplate скелет:
```html
<!DOCTYPE html>
<html lang="bg">
<head>
    <meta charset="UTF-8"> <!-- 🔒 Критично за Кирилицата -->
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>HTML & CSS Основи</title>
</head>
<body>
    <!-- Видимото съдържание се пише единствено ТУК -->
</body>
</html>
```

## 2. СЕМАНТИЧЕН УЕБ ДИЗАЙН (SEMANTIC HTML)

В старите версии на уеб разработката, страниците се изграждаха изцяло от безсъдържателни кутии `<div>`. Модерният HTML5 налага използването на **Семантични тагове**, които с името си описват каква е бизнес ролята на съдържанието вътре в тях. Това е критично за Google търсачките (SEO) и за вярното рендериране:

*   `<header>` ➔ Горна заглавна част на сайта или секцията.
*   `<nav>` ➔ Навигационно меню (съдържа уеб линковете).
*   `<main>` ➔ Централното, основно и уникално съдържание на текущата уеб страница.
*   `<section>` ➔ Логическа глава или подтема в документа.
*   `<article>` ➔ Напълно самостоятелна, независима текстова единица (напр. новина, пост).
*   `<aside>` ➔ Странична лента (Sidebar) със спомагателна информация или реклами.
*   `<footer>` ➔ Долен край на страницата (права, контакти).

## 3. ПЪРВИ СТЪПКИ В CSS3: СЕЛЕКТОРИ И КАСКАДНОСТ

**CSS (Cascading Style Sheets)** отговаря за дизайна. Връзката между HTML елементите и CSS правилата се налага през **Селектори**:

1.  *Елементен селектор:* Насочва се директно към тага: `p { color: red; }` (Променя всички параграфи).
2.  *Класов селектор (Златен стандарт):* Използва точка `.` пред името: `.card-title { font-size: 20px; }`. Преизползва се неограничено.
3.  *ID селектор:* Използва решетка `#`: `#main-submit { display: none; }`. Може да се появи само веднъж на страницата.

> **Законът за Каскадността (Cascading & Specificity):** Ако над един и същ HTML елемент са наложени две противоречиви CSS правила, компилаторът изчислява тяхната тежест. **ID селекторът е по-тежък от Класа, а Класът е по-тежък от Елемента.** Ако тежестта им е еднаква, печели правилото, което е написано **най-долу във файла** (последно по ред).

## 4. СИСТЕМНИ КАПАНИ: РАЗВАЛЕНА КОДИРОВКА И СРИВОВЕ В JUDGE

На изпитите в SoftUni, автоматизираната система Judge проверява HTML структурата и стиловете много строго.

### 🚨 Капан №1: Получаване на 0 точки в Judge поради липсващ или грешен мета таг
*   **Какво се случва:** Разписваш перфектен дизайн, в браузъра ти всичко свети, но при качване на кода в Judge системата получаваш твърдо `0/100` с грешки при компилация на тестовете.
*   **Защо се случва:** Judge чете уеб файловете ти като суров байтов поток. Ако си забравила да сложиш тага `<meta charset="UTF-8">` най-отгоре в `<head>` секцията, или ако си написала буквите малки/грешни, Judge не може да разчете текстовете на Кирилица, енкодингът се чупи, паметта се фрагментира и тестовете умират.
*   **Как да го поправиш:** Винаги, преди да почнеш да пишеш дизайн, подсигурявай присъствието на `<meta charset="UTF-8">` веднага след отварящия таг `<head>`.

## 5. ИНДИВИДУАЛЕН CHEAT SHEET И ГОТОВИ УЕБ SNIPPETS

### 🛠️ Бърз Изпитен Пищов (Cheat Sheet):
*   `<a href="URL" target="_blank">` ➔ Отваря линка в **нов самостоятелен прозорец** на браузъра.
*   `<ul type="square">` + `<li>` ➔ Неномериран списък (Bullet points).
*   `<ol>` + `<li>` ➔ Номериран списък (1, 2, 3...).
*   `font-style: italic;` ➔ Накланя текста (Курсив).
*   `text-decoration: none;` ➔ Изключително важен CSS трик — премахва грозното долно подчертаване на уеб линковете (`<a>` таговете).

### 💾 Готов за директно ползване Snippet: "Семантична HTML Страница със стилизирано меню"
Копирай този готов, валиден уеб код директно във твоя проект, за да имаш готова семантична структура със стилизирана навигация без подчертаване:

```html
<!-- Суров, готов софтуерен HTML & CSS фрагмент за изпити -->
<!DOCTYPE html>
<html lang="bg">
<head>
    <meta charset="UTF-8">
    <title>Семантичен уеб компонент</title>
    <style>
        /* CSS Почистване и стил на навигацията */
        nav ul {
            list-style-type: none; /* Премахва точките от списъка */
            padding: 0;
            margin: 0;
            background-color: #333;
            overflow: hidden;
        }

        nav li {
            float: left;
        }

        nav li a {
            display: block;
            color: white;
            text-align: center;
            padding: 14px 16px;
            text-decoration: none; /* 🟢 Бърз фикс: Премахва подчертаването */
        }

        nav li a:hover {
            background-color: #111; /* Ефект при посочване с мишката */
        }

        main {
            padding: 20px;
            background-color: #f4f4f4;
        }
    </style>
</head>
<body>

    <header>
        <nav>
            <ul>
                <li><a href="#home">Начало</a></li>
                <li><a href="#courses">Курсове</a></li>
                <li><a href="#profile">Профил</a></li>
            </ul>
        </nav>
    </header>

    <main>
        <section>
            <h2>Добре дошли в Модул: HTML and CSS</h2>
            <p>Този софтуерен компонент е напълно валидиран и съобразен с изпитните изисквания.</p>
        </section>
    </main>

    <footer>
        <p>© 2026 Dev-Library / Всички права запазени.</p>
    </footer>

</body>
</html>
```
