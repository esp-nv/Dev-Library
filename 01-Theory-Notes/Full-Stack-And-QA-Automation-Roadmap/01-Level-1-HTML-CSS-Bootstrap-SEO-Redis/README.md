# Модул: HTML and CSS

Добре дошли в официалния практически и теоретичен атлас по фронтенд основи. Този сектор съдържа детайлно структурирани материали, съответстващи на 100% на изпитната програма, разделени на атомарни подточки. Всеки модул съдържа теоретична диагностика на паметта, реални капани, индивидуален изпитен Cheat Sheet и готови кодови кубчета (Snippets) в края.

## 🧭 Официален Индекс на Подмодулите



*   **[00. Въведение в курса и инсталация на среди](00-Course-Introduction.md)**
    *   *Обхваща:* Пълен сравнителен одит на 10 среди според GeeksforGeeks, предимства, недостатъци, лицензи (MIT, Shareware), сеньор VS Code shortcuts, автоматични JSON снипети, Side-by-Side организация на екрана и трикове против пропадане на браузърния кеш.

*   **[01. Въведение в HTML и CSS (Теория и Упражнения)](01-Introduction-to-HTML-and-CSS.md)**
    *   *Обхваща:* Анатомия на HTML таговете, базов Boilerplate скелет, семантични елементи, първи стъпки в CSS и изпитни Judge задачи.

*  *   **[02. CSS Box Model и Типография (Пълен Справочник)](02-Box-Model-And-Typography/README.md)**
    *   *Обхваща:* Декуплиран пакет от 4 наръчника (`02-00` до `02-03`) — пикселна анатомия на кутиите, предпазители против визуални сривове през `border-box`, закони на `rem` типографията, Chrome DevTools инспекция и готови продуктови Snippets.


*   **[03. CSS Layout — Flexbox (Теория и Упражнения)](03-CSS-Layout-Flexbox.md)**
    *   *Обхваща:* Двуизмерно подреждане на елементи през Flex Container и Flex Items, свойства за подравняване и готови CSS структури.

*   **[04. Адаптивен дизайн (Responsive Web Design): Интервю Cheat Sheet & Reference Guide](04-Responsive-Web-Design.md)**
    *   *Обхваща:* Медийни заявки (`@media queries`), флуидни решетки, четирите стандартни контролни точки (Breakpoints), конфигурация на Viewport мета тагове, адаптивни снимки и избягване на хоризонтален скрол на мобилни телефони.*  



*   **[05. Работа с Уеб Форми (Working with Forms)](05-Working-with-Forms.md)**
    *   *Обхваща:* Анатомия на уеб формулярите (`action` и `method` глаголи), типове HTML5 инпути, достъпност през Label-Input връзка, критичното значение на атрибута `name` за .NET средите и избягване на GET изтичания.

*   **[06. Модерен Tailwind CSS (Теория и Упражнения)](06-Tailwind-CSS.md)**
    *   *Обхваща:* Философия на Utility-First дизайна, бързи класове за Box Model, Flexbox и оформление, Mobile-first адаптивни представки (`md:`), интерактивни ховър състояния, капани на статичния анализатор и Purge конфигуриране за олекотяване на производствени файлове.


*   **[07. Подготовка за Изпит и Изпитни задачи (Exam Preparation)](07-Exam-Preparation.md)**
    *   *Обхваща:* 4-стъпковия алгоритъм за бързо писане под изпитен стрес, анализ на скритите критерии на Judge системата, предотвратяване на грешки при липсващи уеб шрифтове (@import), пикселно съответствие и глобален спасителен CSS Reset за 100/100 точки.
