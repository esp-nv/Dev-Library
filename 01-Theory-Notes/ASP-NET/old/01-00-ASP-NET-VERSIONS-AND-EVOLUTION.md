## 1. ИСТОРИЧЕСКА ХРОНОЛОГИЯ: ОТ КЛАСИЧЕСКО ASP ДО .NET 11

Уеб технологиите на Microsoft преминаха през три основни еволюционни етапа:

1.  **Classic ASP (1998 - 2002):** Стара технология, при която HTML кодът и логиката (обикновено дефинирана чрез VBScript) се пишеха смесено на едно място. Изключително трудна за поддръжка.
2.  **ASP.NET ( .NET Framework 1.0 до 4.8 ) (2002 - 2016):** Първата голяма уеб революция на Microsoft. 
    *   *Web Forms:* Симулираше поведението на десктоп приложения в браузъра (със събития като бутон-клик), но генерираше огромен и бавен HTML код.
    *   *ASP.NET MVC (версии 1 до 5):* Въведе правилния архитектурен модел Model-View-Controller, давайки пълен контрол над HTML и заявките.
3.  **ASP.NET Core ( от .NET Core 1.0 през .NET 5/8 до днешния .NET 11 ) (2016 - Настояще):** Пълно пренаписване на софтуерния двигател от нулата. Платформата стана напълно независима от Windows, с отворен код (Open-source) и оптимизирана за работа в облака (Cloud-ready).

## 2. ГОЛЕМИЯТ СБЛЪСЪК: ASP.NET СРЕЩУ ASP.NET CORE

Разликите между старата и новата архитектура са фундаментални:

| Архитектурен критерий | Старото ASP.NET (до v4.8) | Модерното ASP.NET Core (.NET 5+) |
| :--- | :--- | :--- |
| **Крос-платформеност** | **Работи само под Windows.** Обвързано е твърдо с IIS (Internet Information Services) сървъра. | **100% Крос-платформено.** Работи и се деплоява безпроблемно под Windows, Linux и macOS. |
| **Уеб сървър под капака** | Използва тежкия системен IIS уеб сървър. | Включва вграден, лек и свръхбърз уеб сървър, наречен **Kestrel**. |
| **Dependency Injection** | Липсва фабрично. Изисква инсталиране на външни библиотеки (напр. Autofac, Ninject). | **Вградено на системно ниво (Native DI).** Цялата архитектура се върти около него. |
| **Продукционен деплой** | Големи пакети, изискващи инсталиран .NET по целия Windows сървър. | **Изолирани Docker контейнери** или леки Self-contained изпълними файлове (всичко нужно е вътре). |

## 3. ЗАЩО ASP.NET CORE Е ТОЛКОВА БЪРЗ? (TECHEMPOWER БЕНЧМАРК)

След премахването на тежките Windows зависимости, софтуерният двигател на ASP.NET Core стана един от най-производителните в света. В независимите глобални тестове на **TechEmpower**, ASP.NET Core редовно побеждава останалите големи платформи:

*   **ASP.NET Core (Minimal APIs):** Преработва над **2.05 милиона** JSON отговора в секунда (RPS).
*   **Java Servlet:** Преработва ~328 хиляди заявки в секунда.
*   **Node.js:** Преработва ~224 хиляди заявки в секунда.

Тази бързина се дължи на премахването на излишните слоеве памет и обработката на нишките директно през нативно оптимизирания сървър Kestrel.
