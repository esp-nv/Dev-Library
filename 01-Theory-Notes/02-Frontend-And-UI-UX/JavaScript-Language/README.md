# 🟨 JavaScript Language (Модерен Уеб Език & Browser Runtime)

Добре дошли в официалния практически и теоретичен атлас на **JavaScript (ES2025+)**. Този сектор изгражда фундамента на динамичното уеб програмиране и подготвя директния преход към **TypeScript** — обхващайки архитектурата на **V8 енджина**, типовата система и Type Coercion, Closures и контекста `this`, прототипното наследяване, асинхронния модел с **Event Loop**, манипулацията на DOM и сравнението с Node.js.

Всяка тема е разделена на **теоретична лекция (`-00`)** с дълбока архитектура, мнемоника и капани, и **практически наръчник (`-01`)** със синтаксис от нулата и табличен Cheat Sheet.
