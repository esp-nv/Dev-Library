## 1. ФИЛОСОФИЯ НА BOOTSTRAP 5: COMPONENT-FIRST & VANILLA JS

Докато Tailwind CSS дава малки атомарни тухлички, **Bootstrap 5** предоставя готови сглобени стаи и мебели — бутони (`.btn`), навигационни ленти (`.navbar`), карти (`.card`), модални прозорци (`.modal`) и известия (`.alert`).

* **Без зависимост от jQuery:** От версия 5 насам Bootstrap изцяло премахна остарялата библиотека jQuery и използва чист, модерен **JavaScript (ES6+)** чрез `bootstrap.bundle.min.js` (който включва и библиотеката *Popper.js* за позициониране на падащи менюта и подсказки).
* **CSS Custom Properties (Променливи):** Всички цветове и отстояния се контролират през `:root` променливи (`--bs-primary`, `--bs-body-bg`), което позволява лесна смяна на темата (включително вграден Dark Mode чрез `data-bs-theme="dark"`).

## 2. АРХИТЕКТУРА НА 12-КОЛОННАТА GRID СИСТЕМА (CONTAINER -> ROW -> COL)

В основата си решетката на Bootstrap 5 е изградена върху **Flexbox** и разделя екрана на точно **12 равни вертикални колони**. За да работи без хоризонтално препълване, тя изисква три строго подредени нива:

```text
 ┌─────────────────────────────────────────────────────────────────────────┐
 │  1. .container (или .container-fluid за 100% ширина)                    │
 │     Осигурява центриране и ляв/десен буфер (padding).                   │
 │  ┌───────────────────────────────────────────────────────────────────┐  │
 │  │  2. .row (Flexbox контейнер с отрицателни странични margins)      │  │
 │  │     Неутрализира външния padding на крайните колони.              │  │
 │  │  ┌───────────────────────────┐ ┌───────────────────────────────┐  │  │
 │  │  │  3. .col-md-6 (6/12 = 50%)│ │  3. .col-md-6 (6/12 = 50%)    │  │  │
 │  │  │  Реалното съдържание      │ │  Реалното съдържание          │  │  │
 │  │  └───────────────────────────┘ └───────────────────────────────┘  │  │
 │  └───────────────────────────────────────────────────────────────────┘  │
 └─────────────────────────────────────────────────────────────────────────┘
```

## 3. ОТЗИВЧИВИ КЛАСОВЕ И РАЗПРЕДЕЛЕНИЕ НА ШИРИНАТА (BREAKPOINTS)

Bootstrap 5 следва принципа **Mobile-First**. Когато напишеш `class="col-12 col-md-6 col-lg-4"`, браузърът прилага следните правила:
* **На телефон (`< 768px`):** Елементът заема `12/12` колони (100% ширина — 1 карта на ред).
* **На таблет (`>= 768px`, префикс `md`):** Елементът заема `6/12` колони (50% ширина — 2 карти на ред).
* **На лаптоп/десктоп (`>= 992px`, префикс `lg`):** Елементът заема `4/12` колони (33.33% ширина — 3 карти на ред).
* **Автоматично разпределение (`.col` без число):** Ако сложиш три блока с клас `.col` в един `.row`, всеки автоматично получава `4/12` ширина.

## 4. СИСТЕМНИ КАПАНИ: СЧУПЕНА GRID ЙЕРАРХИЯ, ПОСТАВЯНЕ НА СЪДЪРЖАНИЕ В .ROW И !IMPORTANT ХАКОВЕ

### 🚨 Капан №1: Поставяш текст или фон директно върху `.row`, вместо вътре в `.col-*`
* **Какво правиш:** Пишеш `<div class="row bg-primary">Текст</div>` без вложен `<div class="col">`.
* **Визуален капан:** Елементът `.row` има отрицателни странични отстъпи (`margin-left: -12px; margin-right: -12px;`), за да компенсира вътрешния `padding` на колоните. Без вложена колона текстът излиза извън контейнера и предизвиква хоризонтален скролбар!
* **Правило:** Директни деца на `.row` могат да бъдат **единствено** елементи с клас `.col*`. Цялото визуално съдържание и фонове се поставят вътре в колоната.

### 🚨 Капан №2: Зареждаш собствения си `style.css` ПРЕДИ `bootstrap.min.css`
* **Защо се чупи:** Ако твоят файл е сложен по-нагоре в `<head>`, стиловете на Bootstrap го презаписват и те принуждават да пишеш грозни `!important` правила.
* **Как да го поправиш:** Винаги поставяй `<link href="style.css" rel="stylesheet">` **след** линка към `bootstrap.min.css`.

### 🚨 Капан №3: Интерактивните компоненти (Modal, Dropdown, Navbar Toggler) не реагират при клик
* **Защо се случва:** Включил си само `bootstrap.min.css`, но си забравил да добавиш `<script src="...bootstrap.bundle.min.js"></script>` преди затварящия таг `</body>`.
