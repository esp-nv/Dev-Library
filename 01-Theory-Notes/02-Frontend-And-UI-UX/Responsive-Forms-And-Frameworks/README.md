# 02. Responsive Design, Forms & CSS Frameworks

Вторият инженерен раздел от **Ниво 1 (The Quick Wins)**. Тук надграждаме статичните уеб страници до напълно адаптивни, интерактивни и мащабируеми потребителски интерфейси чрез **Responsive Web Design (Media Queries & Mobile-First)**, семантични **HTML5 форми и клиентска валидация**, както и двете водещи CSS рамки в индустрията — **Tailwind CSS (Utility-First)** и **Bootstrap 5 (Component & 12-Column Grid)**.
